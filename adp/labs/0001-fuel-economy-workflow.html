가이드 · ADP 실기

실기 전체 지도 · 통계 40 + 머신러닝 60

ADP 실기, 4시간 안에 무엇을 하는가연비 예측 사례 하나로 전 과정을 관통합니다.

ADP 실기의 사례연구는 데이터도 기법도 제각각이지만, 속뼈대는 하나입니다. 이 페이지는 그 뼈대 전체를 한눈에 보여주는 지도입니다. 먼저 시험이 어떻게 생겼는지, 4시간을 어떻게 나눠 쓰는지 보고, 통계 파트를 유형별로 훑은 뒤, 가장 단순한 사례 — 변수 하나로 연비를 예측하는 문제 — 로 머신러닝 6단계를 몸에 새깁니다. 마지막에는 전처리·평가지표·결론 문장까지, 답안을 쓸 때 그대로 꺼내 쓸 틀을 모아 두었습니다.

1. 시험은 이렇게 생겼습니다

항목내용
시간4시간 연속
환경리눅스 가상환경에서 실데이터로 직접 코딩(오픈북)
언어파이썬과 R 중 택일 — 이 과정은 파이썬으로 갑니다
배점통계분석 40점 + 머신러닝 60점 = 100점
합격75점 이상
답안코드 실행 결과(표·그림) + 결론 서술

통계 파트는 검정 대문제가 여러 개 나옵니다. 머신러닝 파트는 대문제 2개에 소문제 5개씩이 딸려 나오는 구조가 일반적입니다 — 탐색 → 전처리 → 모델링 → 평가 → 해석의 순서입니다.

2. 4시간을 어떻게 쓰는가

  1. 통계 파트 · 60~90분 — 유형이 정해져 있어 가장 확실하게 점수를 챙기는 구간입니다.
  2. 머신러닝 파트 · 120분 — 시간이 가장 많이 새는 곳은 모델링이 아니라 전처리입니다.
  3. 마지막 30분 — 결론 서술을 다듬고, 표·그림을 정리하고, 제출 전 점검합니다.
기억할 것 코드는 돌아가는데 결론 문장이 없으면 점수가 깎입니다.

3. 통계 파트 지도 — 무엇을 물으면 무엇을 고르는가

묻는 것고르는 방법
특정 횟수가 나올 확률이항분포(binomial distribution) 확률 계산(필요하면 정규근사)
범주 두 개가 서로 관련 있는가카이제곱(chi-square) 독립성 검정
두 집단 평균 차이독립표본 t검정(짝지어졌으면 대응표본 t검정)
세 집단 이상 평균 차이일원배치 분산분석 + 사후검정
두 요인이 함께 작용하는가이원배치 분산분석(교호작용, interaction)
두 집단 비율 차이두 모집단 비율검정
정규성이 깨졌을 때비모수(non-parametric) 검정(부호검정·크러스칼-월리스)
다른 변수 영향을 걷어낸 상관편상관계수(partial correlation)
새 정보로 확률을 갱신베이즈 정리(Bayes' theorem)
시간이 지나며 사건이 일어날 확률생존분석(survival analysis)
제약 아래 최대·최소선형계획법(linear programming)
통계 파트 만점 공식 어떤 검정이든 ①가설 ②전제 확인 ③검정통계량 ④판정 ⑤결론 서술, 이 다섯 단계를 그대로 밟습니다.

4. 연비 사례로 보는 머신러닝 6단계

가장 단순한 사례로 흐름을 몸에 익힙니다. 설명변수(predictor)는 엔진 배기량(리터) 하나, 반응변수(response)는 고속도로 연비(MPG)입니다. 반응변수가 수치이므로 회귀(regression) 문제입니다.

숫자로 잡는 감각 훈련 자료 1,107대, 봉인한 테스트 245대. 직선(선형회귀) 하나를 적합했더니 10-겹 교차검증(cross validation) RMSE ≈ 4.6 MPG — 예측이 평균적으로 약 4.6 연비만큼 빗나갔습니다.

그런데 산점도를 보면 배기량이 아주 크거나 아주 작은 양 끝에서 점들이 직선을 벗어나 휘어집니다. 관계가 직선이 아니라 곡선이었던 겁니다. 배기량의 제곱 항을 하나 더한 이차 모델로 바꾸자 그 휘어짐을 잡아내 오차가 줄었습니다. 이 작은 사건에 예측모델링의 핵심 교훈이 들어 있습니다.

핵심 통찰 모델이 좋은지는 훈련 자료에 얼마나 잘 붙었나로 판단하지 않습니다. 보지 않은 데이터에서의 성능(교차검증·테스트)으로 판단합니다. "직선으로 충분한가?"의 답도 눈대중이 아니라 교차검증 RMSE가 줄었는가로 확정했습니다.
  1. 문제 정의·데이터 이해 — 반응변수=고속도로 연비(수치)→회귀. 산점도로 관계를 먼저 본다.
  2. 데이터 분할 — 1,107 훈련 / 245 테스트. 테스트는 끝까지 봉인.
  3. 전처리 — 이 사례는 변수 하나라 가볍다(척도화·변환 정도). 사례가 커지면 여기가 커진다.
  4. 모델 적합 — 먼저 직선(선형회귀)을 적합.
  5. 리샘플링 검증 — 10-겹 교차검증으로 RMSE≈4.6 추정. 직선 vs 이차를 여기서 비교해 이차 선택.
  6. 성능 평가·결론 서술 — 봉인한 245대로 최종 확인 → "배기량으로 연비를 평균 약 □ 오차로 예측한다"로 문장화.

실기 답안은 이 흐름을 코드로 그대로 옮기면 됩니다. 아래는 그대로 복사해 쓰는 뼈대입니다.

import pandas as pd, numpy as np
from sklearn.model_selection import train_test_split, KFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler, PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

df = pd.read_csv('data.csv')
X, y = df[['engine']], df['mpg']

# 1) 분할 — 테스트는 마지막까지 봉인
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=42)

# 2) 후보 모형 두 개
lin  = make_pipeline(StandardScaler(), LinearRegression())
quad = make_pipeline(PolynomialFeatures(2, include_bias=False),
                     StandardScaler(), LinearRegression())

# 3) 교차검증으로 '보지 않은 성능' 비교 → 여기서 모형을 고른다
cv = KFold(n_splits=10, shuffle=True, random_state=42)
for name, m in [('직선', lin), ('이차', quad)]:
    rmse = -cross_val_score(m, X_tr, y_tr, cv=cv,
                            scoring='neg_root_mean_squared_error').mean()
    print(name, round(rmse, 3))

# 4) 고른 모형만 테스트로 최종 확인
best = quad.fit(X_tr, y_tr)
pred = best.predict(X_te)
print('테스트 RMSE', round(np.sqrt(mean_squared_error(y_te, pred)), 3))
print('테스트 R²  ', round(r2_score(y_te, pred), 3))

5. 전처리 점검표 — 시간이 가장 많이 새는 곳

무엇을어떻게
결측값수치는 중앙값·평균, 범주는 최빈값. 비율이 크면 그 변수 자체를 버릴지 판단
이상값사분위범위(IQR) 1.5배 밖을 표시하고, 실제 오류인지 자연스러운 극단값인지 구분
치우친 분포로그·제곱근 변환으로 대칭에 가깝게
척도 차이표준화(standardization). 거리·정규화를 쓰는 모형에 필수
범주형 변수원-핫 인코딩. 순서가 있으면 순서대로 숫자 부여
클래스 불균형오버샘플링(SMOTE)이나 가중치 조정(class_weight='balanced')
변수 간 강한 상관분산팽창계수(VIF)로 확인하고 하나를 제거하거나 주성분분석(PCA)
기억할 것 모든 처리에는 이유를 한 줄씩 적습니다. 답안은 처리 자체가 아니라 판단 근거로 채점됩니다.

6. 성능은 무엇으로 말하는가

문제지표언제 이 지표를 앞세우나
회귀RMSE · MAE · R²큰 오차를 특히 피해야 하면 RMSE
분류정확도 · 정밀도 · 재현율 · F1 · AUC놓치면 안 되는 문제(불량·질병)는 재현율, 클래스가 불균형이면 AUC
군집실루엣 계수(silhouette)군집 수를 정할 때
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import confusion_matrix, classification_report, roc_auc_score

clf = RandomForestClassifier(n_estimators=300, random_state=42).fit(X_tr, y_tr)
proba = clf.predict_proba(X_te)[:, 1]
print(confusion_matrix(y_te, clf.predict(X_te)))
print(classification_report(y_te, clf.predict(X_te)))
print('AUC', round(roc_auc_score(y_te, proba), 3))

7. 결론 문장 틀

그대로 채워 쓰는 문형

검정 — 유의수준 5%에서 검정통계량은 ○, 유의확률(p-value)은 ○입니다. p가 0.05보다 작으므로 귀무가설을 기각하며, ○○ 사이에 차이가 있다고 판단합니다. 사후검정 결과 차이는 ○와 ○ 사이에서 나타났습니다.

회귀 — 최종 모형은 ○이며 교차검증 RMSE ○, 테스트 RMSE ○입니다. ○가 1 늘어날 때 ○는 평균 ○만큼 변합니다.

분류 — ○ 모형의 AUC는 ○, 재현율은 ○입니다. 놓쳤을 때 비용이 큰 문제이므로 재현율을 우선해 판정 기준을 ○으로 두었습니다.

자기설명 (Self-explanation)

화면을 보지 말고, 머신러닝 6단계와 통계 5단계를 순서대로 소리 내어 말해 보세요. 머신러닝은 2단계에서 테스트를 봉인하는 이유와 5단계에서 모델을 고르는 이유를, 통계는 ②전제 확인과 ⑤결론 서술이 왜 빠지면 안 되는지 한 문장씩 말해 보세요.

말한 뒤 펼쳐서 대조

머신러닝 — 정의·이해 → 분할(테스트 봉인: 일반화를 정직하게 재려고) → 전처리 → 적합 → 리샘플링 검증(보지 않은 성능으로 모델 선택) → 평가·결론. 봉인과 선택, 이 둘이 과적합을 막는 두 빗장입니다.

통계 — 가설 → 전제 확인(어긋나면 검정 자체를 바꿔야 하니까) → 검정통계량 → 판정 → 결론 서술(숫자를 사람 말로 옮기지 않으면 채점되지 않으니까).
