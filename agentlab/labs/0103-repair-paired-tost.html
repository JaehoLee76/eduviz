같은 점을 전후로 잰 자료는 점별 차이로 비교해야 날카로워지고, “달라지지 않았다”를 말하려면 “유의하지 않다”로는 모자라서 허용폭을 먼저 정한 뒤 동등성 검정을 써야 합니다.

지난 실험실과의 다리. 0102 에서는 불량 스틱을 바꾸기 전 유리 20장과 바꾼 뒤 유리 20장을 비교했습니다. 두 묶음이 서로 다른 유리였으니 독립 두 표본이었고, 평균이 아니라 산포가 달라졌는지를 물었습니다. 이번에는 같은 마스크의 같은 77개 점을 리페어 전과 후에 두 번 쟀습니다. 짝이 지어진 자료라는 이 한 가지 차이가 검정을 바꿉니다. 이 실험실의 데이터는 학습용 가상 데이터입니다.

이미 아시는 것 — 평균·표준편차와 3σ 관리 한계, Welch t검정과 p값·신뢰구간(0101), 순위로 바꿔 비교하는 맨-휘트니(0102), 정규성을 확인하는 Q-Q 그림.

p 가 0.05 보다 훨씬 큽니다. 세정 전후 차이를 찾지 못했습니다.
막힘: 유의하지 않다는 같다는 말이 아닙니다. p = 는 “차이가 있다는 증거가 모자란다” 일 뿐 “차이가 없다는 증거”가 아닙니다. 점 수가 적거나 산포가 크면 큰 차이도 p 가 큽니다. 지금 평균은 µm 올랐고 95% 신뢰구간은 ~ µm 입니다. 이 구간 안의 어떤 값도 데이터와 모순되지 않습니다. 우리가 보이고 싶은 것은 “차이가 허용 범위 안이다” 입니다. 방향이 반대입니다.

이름과 순서: 허용폭을 먼저 정합니다

그래서 “차이가 있다”를 증명하는 대신 “차이가 작다”를 증명합니다. 이를 동등성 검정(equivalence test)이라 합니다. 이 검정에는 먼저 허용폭 δ가 필요합니다. 평균 차이가 −δ 와 +δ 사이이면 같다고 보겠다는 폭입니다.

δ 는 데이터를 보기 전에 정합니다. 데이터를 본 뒤에 δ 를 고르면 어떤 결과든 “동등”으로 만들 수 있기 때문입니다. 아래 슬라이더로 직접 확인하실 수 있습니다. 이 실험실에서는 데이터를 보기 전에 공정 쪽이 “평균 변화 µm 까지는 품질에 영향이 없다”고 정했다고 가정하며, 이 값을 기준값으로 둡니다.

답안 1단계가설이 뒤집힙니다. 지금까지는 “차이가 없다”를 버리려 했습니다. 동등성 검정에서는 버리려는 쪽이 “평균 차이의 크기가 δ 이상이다”이고, 증명하려는 쪽이 “평균 차이가 −δ 와 +δ 사이다”입니다.

TOST: 단측검정 두 번

단측검정은 한쪽 방향만 묻는 검정입니다. 동등성은 두 방향을 모두 막아야 하므로 단측검정을 두 번 합니다. 이름이 TOST(Two One-Sided Tests)입니다. d = 후 − 전 의 평균을 μ차 라 하면 이렇습니다.

검정 A: “μ차 ≤ −δ” (오차가 δ 이상 줄었다)는 주장을 기각할 수 있는가.
검정 B: “μ차 ≥ +δ” (오차가 δ 이상 늘었다)는 주장을 기각할 수 있는가.

두 단측 검정통계량 t(A)=d¯+δse, t(B)=d¯−δse se 는 대응 비교의 표준오차 µm 입니다. 검정 A 의 p 는 t(A) 의 위쪽 꼬리 확률, 검정 B 의 p 는 t(B) 의 아래쪽 꼬리 확률입니다.

두 검정을 모두 통과해야 동등이므로 TOST 의 p 는 두 p 중 큰 쪽입니다. 이 p 가 0.05 보다 작으면 동등이라고 판정합니다.

같은 말을 신뢰구간으로. 평균 차이의 90% 신뢰구간이 −δ ~ +δ 안에 완전히 들어오면 TOST 가 5% 수준에서 동등을 판정하는 것과 같습니다. 95%가 아니라 90%인 이유는, 단측검정 하나가 한쪽 꼬리 5%만 쓰기 때문에 두 꼬리를 합쳐 양쪽에서 5%씩 버린 구간이 90% 구간이기 때문입니다.

세정 후 점 오차 평균은 µm 달라졌고, 90% 신뢰구간 ~ µm 가 허용폭 ± µm 안에 있어 세정 전후 평균 오차는 허용폭 안에서 같다고 판정합니다. “정확히 같다”는 뜻이 아니라 “ µm 보다 큰 차이는 없다”는 뜻입니다. 이 결론은 허용폭이 µm 이상일 때 성립합니다.

통계가 정하는 값이 아니라 공정과 품질 spec 이 정하는 값입니다. 예를 들어 “평균 오차가 이만큼 움직여도 증착 겹침 마진에서 불량이 늘지 않는다”는 근거를 공정 담당과 합의하고, 측정 전에 날짜와 함께 기록해 둡니다. 과거 측정의 재현성(같은 점을 두 번 재면 얼마나 다른가)을 하한 참고로 쓰기도 합니다. 분석 뒤에 δ 를 고르면 결론이 결과에 맞춰지는 것이므로 하지 않습니다.

“차이가 허용폭 ±δ 안이다”라고 말씀하십시오. “같다”는 표현은 δ 가 0 이라는 뜻처럼 읽혀 과합니다. 보고서에는 δ 값, 평균 차이, 90% 신뢰구간을 함께 적으면 읽는 사람이 판단할 수 있습니다.

됩니다. 한쪽만 막으면 되는 질문(오차가 δ 이상 늘지 않았다)은 검정 B 하나로 충분하며, 이것을 비열등성 검정(non-inferiority)이라 합니다. 이 실험실에서는 “좋아졌을 수도 있다”까지 포함해 “변하지 않았다”를 보이려고 양쪽을 모두 막았습니다. 질문이 “나빠졌는가” 뿐이면 비열등성으로 묻는 편이 더 정확합니다.

pandas 로 CSV 를 읽어 위의 모든 숫자를 다시 만듭니다. 파일 경로만 가지고 계신 자료에 맞게 바꾸십시오.

import numpy as np
import pandas as pd
from scipy import stats

def paired_test(before, after, alpha=0.05):
    """같은 대상(점)의 전·후를 짝지어 비교하는 대응 t검정.
    반환: 평균 차이(후-전), 표준오차, t, 자유도, p, 신뢰구간(1-alpha)
    d = after - before 를 만들어 '평균이 0인가'를 한 표본 t로 묻는다."""
    d = np.asarray(after, float) - np.asarray(before, float)
    n = len(d)
    se = d.std(ddof=1) / np.sqrt(n)
    t = d.mean() / se
    p = 2 * stats.t.sf(abs(t), n - 1)
    h = stats.t.ppf(1 - alpha / 2, n - 1) * se
    return dict(diff=d.mean(), se=se, t=t, df=n - 1, p=p, ci=(d.mean() - h, d.mean() + h))

def wilcoxon_signed(d):
    """점별 차이 d 의 윌콕슨 부호순위 검정(정규 근사, 같은 값 보정 포함)."""
    d = np.asarray(d, float)
    r = stats.wilcoxon(d, method='approx')
    return dict(n=int((d != 0).sum()), W=float(r.statistic), p=float(r.pvalue))

def tost_paired(d, delta, alpha=0.05):
    """차이 d 가 (-delta, +delta) 안에 있다는 동등성을 TOST 로 검정.
    p = 두 단측검정 p 중 큰 값. 동등 판정은 p < alpha, 90% 신뢰구간이 ±delta 안과 같은 말."""
    d = np.asarray(d, float)
    n = len(d)
    se = d.std(ddof=1) / np.sqrt(n)
    t_low = (d.mean() + delta) / se
    t_up = (d.mean() - delta) / se
    p_low = stats.t.sf(t_low, n - 1)
    p_up = stats.t.cdf(t_up, n - 1)
    h = stats.t.ppf(1 - alpha, n - 1) * se
    p = max(p_low, p_up)
    return dict(p_low=p_low, p_up=p_up, p=p, ci90=(d.mean() - h, d.mean() + h), equivalent=bool(p < alpha))

rep = pd.read_csv('agentlab/data/csv/s3_repair_pair.csv')
cln = pd.read_csv('agentlab/data/csv/s3_clean_pair.csv')

# 질문 1: 리페어로 좋아졌는가 (오차 단위 µm, 작을수록 좋음)
b, a = rep['repair_err_before'], rep['repair_err_after']
w = stats.ttest_ind(a, b, equal_var=False)
pr = paired_test(b, a)
d = a - b
sw = stats.shapiro(d)
wx = wilcoxon_signed(d)
print(f"[독립 Welch] p={w.pvalue:.4g}   [대응 t] 차이={pr['diff']:.3f} t={pr['t']:.3f} p={pr['p']:.4g}")
print(f"[차이의 정규성] Shapiro p={sw.pvalue:.4f}   [윌콕슨] W={wx['W']:.1f} p={wx['p']:.4g}")

# 질문 2: 세정 후 나빠지지 않았는가 (허용폭은 데이터를 보기 전에 정한 0.3 µm)
dc = cln['clean_err_after'] - cln['clean_err_before']
pc = paired_test(cln['clean_err_before'], cln['clean_err_after'])
tc = tost_paired(dc, delta=0.3)
print(f"[세정 대응 t] p={pc['p']:.4g}   [TOST] p={tc['p']:.4g}  90%CI=({tc['ci90'][0]:.3f}, {tc['ci90'][1]:.3f})")

print("보고: 리페어 후 점 오차 평균이 %.3f µm 줄었습니다(95%% 신뢰구간 %.3f ~ %.3f, 대응 t p=%.1e). "
      "세정 후 평균 변화는 %+.3f µm 이며 ±0.3 µm 안에서 동등합니다(TOST p=%.1e)."
      % (-pr['diff'], -pr['ci'][1], -pr['ci'][0], pr['p'], dc.mean(), tc['p']))
