LLM에게 일을 맡기는 법 — 검증 설계

숫자는 도구가, 문장은 LLM 이, 대조는 자동으로 — 두 가지 방법으로 맡겨 본 실제 답 6개

0410 에서 틀림은 숫자가 아니라 문장에 있었으므로, 맡기는 법을 바꿉니다. 숫자는 도구가 계산한 사실 목록의 번호로만 쓰게 하고(계산이 필요하면 식만 쓰게 하고 도구가 계산합니다), 출력을 정해 둔 JSON 형식으로 고정하고, 문장마다 근거 사실 번호를 달게 합니다. 그러면 검사기가 ‘숫자를 직접 쓰지 않았는가 · 번호가 실제로 있는가 · 식이 허용된 모양인가 · 원인 문장에 근거가 달렸는가’를 자동으로 확인합니다. 그래도 ‘언제·어느 날에 일어났나’ 같은 관계를 담은 문장은 이 검사기가 보지 못하므로, 그런 관계도 도구가 사실로 만들어 목록에 넣고 사람이 마지막으로 봅니다. 사내 자료는 밖으로 보내지 않고 사내 모델로만 다룹니다.

2첫 시도 — 설계 A (자유 서술)

먼저 0410 에서 하던 대로, 사실 목록을 주고 문장을 자유롭게 쓰게 한 답 세 개를 봅니다. 0410 의 숫자 대조를 그대로 돌리되, 대조할 ‘표’ 자리에 이번에는 사실 목록을 놓았습니다. 계산 목록은 두 사실의 차·합·비·비×100 입니다.

설계 A 의 답 — 하나씩 읽고 숫자 대조 결과를 보십시오
무엇을 볼지 먼저. 1) 답을 고르고 색칠된 숫자를 보십시오(초록 실선 = 사실 목록에 그대로 있음, 파랑 점선 = 계산됨, 빨강 = 근거 없음, 주황 점선 테두리 = 거친 일치). 2) 빨간 숫자가 있는지 세어 보십시오. 3) 그다음 ‘7일 구간’·‘5일 구간’처럼 시점을 말하는 대목을 찾아, 아래 표지 표와 견주어 보십시오.
사실 목록에 있음계산됨근거 없음거친 일치

여기서 막힙니다. 세 답의 숫자는 모두 사실 목록에서 왔고 묻지 않은 계산도 없습니다. 그런데 시점을 말한 문장 하나가 틀렸고, 숫자 대조는 그것을 통과시켰습니다. 교체 시각이 사실 목록에 있으므로 숫자로는 ‘표에 있음’이기 때문입니다. 게다가 문장이 자유로워서 기계는 어느 문장이 원인을 주장하는 문장인지조차 알지 못하고, 사람은 한 답의 문장 개를 전부 읽어야 합니다.

표지의 ‘틀림·맞음’은 사람이 읽고 붙인 것이고, 오른쪽 열의 숫자와 구간은 이 페이지가 하루 구간(06:00 ~ 다음 날 06:00)으로 다시 계산한 것입니다. 이 막힘을 풀려면 맡기는 법을 바꿔야 합니다.

3이름 — 자리 채우기

  • 자리 채우기 (slot filling) — 문장 속 숫자 자리에 값을 직접 쓰지 않고 {{f1}} 같은 번호를 쓰게 한 뒤, 도구가 값을 넣는 방식입니다.

번호로만 쓰게 하면 LLM 이 숫자를 베껴 쓰다 틀릴 일이 없고, 문장 속에 숫자가 직접 나타나면 곧 규칙 위반이라 기계가 찾아낼 수 있습니다. 사실 목록에 없는 숫자(비율·몫)가 필요하면 값을 직접 계산하지 말고 {{calc: 식}} 으로 쓰게 합니다. 식에는 번호·숫자 상수·+ − * / ( ) 만 쓸 수 있고, 계산은 도구가 합니다.

설계 B 의 답 — 자리가 값으로 바뀌는 모습
무엇을 볼지 먼저. 1) 답을 고르고 왼쪽의 자리 표시({{…}})와 오른쪽의 렌더 결과를 문장마다 견주십시오. 2) 식 표에서 도구가 계산한 값과 정답을 견주십시오. 3) 맨 아래 같은 번호의 설계 A 답과 렌더 결과를 나란히 읽어 보십시오.
B 답 원문(JSON) 그대로 보기

식의 계산은 도구가 하므로 계산이 틀릴 일은 없습니다. 틀릴 수 있는 것은 식의 뜻입니다. 예를 들어 초과 비율을 f4/f5*100 이 아니라 f4/f6*100 으로 쓰면 도구는 아무 문제 없이 계산하지만 다른 비율이 됩니다.

그래서 검사기는 식이 허용된 글자만 쓰는지와 쓴 번호가 cites 에 달려 있는지만 확인하고, 식의 뜻이 맞는지는 사실 이름(“7일 잰 유리 수” 등)과 함께 사람이 한 번 보는 칸으로 남깁니다. 이 기록의 식 개는 모두 개가 정답과 같았습니다.

렌더 결과가 설계 A 의 문장만큼 자연스럽다는 점에 주목하십시오. 숫자가 도구의 값으로 채워졌을 뿐 문장은 LLM 이 쓴 그대로입니다. 렌더는 자리 바로 뒤 조사(이/가·은/는·을/를)를 받침에 맞추는 일만 하고, 그 밖의 어색함(예: ‘ppm였으며’)은 고치지 않고 그대로 둡니다.

4출력 형식 고정 · 스키마 · 근거 인용

  • 출력 형식 고정 (structured output) — 답을 정해 둔 꼴로만 내게 하는 것입니다. 여기서는 JSON(칸 이름과 값을 중괄호로 묶어 쓰는 글의 꼴)과 그 칸들입니다. 기계가 읽고 검사할 수 있게 됩니다.
  • 스키마 (schema) — 출력 형식의 약속입니다. 어떤 칸이 있고 각 칸에 무엇이 올 수 있는지를 적습니다.
  • 근거 인용 (citation) — 문장마다 그 문장이 기대는 사실 번호를 다는 것입니다. 이 실험실에서는 cites 칸입니다.

이 약속을 지켰는지 확인하는 검사 규칙이 V1~V5 입니다. 규칙에 이름(V1~V6)을 붙이는 것은 ‘어느 규칙에 걸렸는가’를 기록으로 남기기 위해서입니다. V6 은 6절에서 틀림을 만난 뒤 제안하는 규칙이라 7절에서 다룹니다.

답 6개를 검사기에 넣은 결과 — 규칙을 켜고 끄면 표시와 집계가 함께 움직입니다
무엇을 볼지 먼저. 1) V1 을 끄면 설계 A 답 세 개가 어떻게 보이는지 보십시오(V2~V6 은 JSON 으로 읽혀야만 돌 수 있어서 설계 A 에는 ‘검사 안 함’입니다). 2) 규칙을 하나씩 꺼 보며 어느 칸이 회색으로 바뀌는지 보십시오. 3) V6 을 켜면 어느 답의 어느 칸이 빨갛게 되는지 보십시오(7절). 4) 칸을 눌러 답을 고르면 아래에 규칙별 이유가 나옵니다.
통과실패꺼짐 또는 검사 안 함(좁은 화면에서는 —)
직접 고쳐 넣어 걸리게 해 보기 — 답 원문을 고치면 검사 결과가 바로 바뀝니다
무엇을 볼지 먼저. 1) 기준이 되는 설계 B 답을 고르십시오. 2) 아래 단추를 눌러 일부러 틀리게 고치고, 어느 규칙이 걸리는지 보십시오. 3) 상자 안 글을 직접 고쳐도 됩니다. 4) ‘기록 원문으로 되돌리기’로 돌아옵니다.

딱딱해지지 않습니다. 형식은 그릇이고 문장은 그 안에 자유롭게 씁니다. JSON 에서 고정하는 것은 text·cites·type 이라는 칸이고, text 칸의 문장은 설계 A 와 똑같이 LLM 이 자유롭게 쓴 글입니다.

3절에서 본 렌더 결과가 그 증거입니다. 설계 B 의 답 1 의 첫 문장은 “” 로, 보통 보고 문장과 다르지 않습니다.

V1 에서 실패로 잡히므로, 다시 요청하거나 사람에게 넘기고 실패한 횟수를 기록합니다. 이 기록에서는 설계 B 답 세 개가 모두 형식을 지켰습니다(/). 세 번의 결과라 앞으로도 지킨다고는 말할 수 없습니다.

형식을 어긴 답은 V2~V6 을 돌릴 수 없으므로, 그 답은 ‘검사 못 함’으로 따로 세어 둡니다. 실패 횟수가 쌓이면 프롬프트 틀을 고칠 근거가 됩니다(11절 기록).

6검사기가 못 잡는 것

설계 B 의 답 2 에서 검사 규칙 V1~V5 를 모두 통과한 한 문장을 봅니다. 앞 문장과 함께 읽어 보십시오.

B 답 2 의 두 문장 (원문의 text 칸 그대로)

‘같은 기간’이 앞 문장의 7일을 가리키므로, 읽는 사람은 교체가 7일에 있었다고 이해합니다. 자리 채우기로도 이 틀림은 막지 못합니다. 날짜와 시각은 번호(f7)로 정확히 들어갔고, 틀린 것은 그 시각과 ‘같은 기간’이라는 말의 연결이기 때문입니다. 관계(언제·어느 날·전후)는 문장 속에 숨어 있습니다.

7관계도 사실로 — V6

해법은 관계도 도구가 계산해 사실 목록에 넣는 것입니다. 관계 사실은 사건 시각과 하루 구간 사이의 관계(어느 날에 드는가, 구간 시작과 몇 시간 차이인가)를 도구가 계산해 번호를 붙인 사실입니다. 아래 f9·f10 이 그것이고, 사건 시각 f7 과 함께 다음 표에 있습니다.

교체 시각을 옮겨 보기 — 관계 사실이 함께 움직입니다
무엇을 볼지 먼저. 1) 슬라이더를 옮겨 f9(든 날)와 f10(7일 구간 시작과의 차)이 어떻게 바뀌는지 보십시오. 2) 교체 시각이 7일 구간 안으로 들어오는 순간 f10 의 부호가 어떻게 되는지 보십시오. 3) 아래 두 문장 “교체가 7일 구간 안에 있었다”, “7일 자료는 전부 교체 뒤다”가 지금 참인지 보십시오. 4) ‘실제 값으로 되돌리기’를 누르십시오.

이제 LLM 은 관계가 필요할 때 이 번호를 인용하면 됩니다. 검사기에 규칙을 하나 더합니다.

정직하게 말해 둘 것이 있습니다. 이 기록의 답 6개는 V6 이라는 규칙도 f9·f10 이라는 사실도 알기 전에 받은 것입니다. 목록에 f9·f10 이 있었다면 LLM 이 그 번호를 인용했을지는 이 기록으로는 알 수 없고, 목록을 바꿔 다시 맡겨 봐야 압니다. V6 으로도 못 보는 것은 번호를 인용한 채 해석을 잘못 쓴 문장입니다. 그런 문장은 사람이 봅니다.

# --- 자리 {{…}} 와 식 ------------------------------------------------------------
TOK = re.compile(r"\s*(?:(f\d+)|(\d+(?:\.\d+)?)|([+\-*/()]))")


def calc_expr(expr, fb):
    """{{calc: 식}} 의 식을 도구가 계산합니다. 허용 글자는 번호·숫자 상수·+ − * / ( ) 뿐입니다. 돌려주는 값 = (값 또는 None, 쓴 번호 목록, 오류 글)"""
    s = expr.replace("−", "-")
    toks, pos = [], 0
    while pos < len(s):
        m = TOK.match(s, pos)
        if not m:
            if s[pos:].strip() == "":
                break
            return None, [], "허용하지 않는 글자"
        toks.append(("id", m.group(1)) if m.group(1) else ("num", float(m.group(2))) if m.group(2) else ("op", m.group(3)))
        pos = m.end()
    if not toks:
        return None, [], "식이 비어 있음"
    ids, p = [], [0]

    def peek():
        return toks[p[0]] if p[0] < len(toks) else None

    def prim():
        x = peek()
        if x is None:
            raise ValueError("식이 끝나지 않음")
        p[0] += 1
        if x[0] == "num":
            return x[1]
        if x[0] == "id":
            f = fb.get(x[1])
            if f is None:
                raise ValueError("목록에 없는 번호")
            if not isinstance(f["value"], (int, float)):
                raise ValueError("숫자가 아님")
            if x[1] not in ids:
                ids.append(x[1])
            return f["value"]
        if x[1] == "(":
            v = add()
            y = peek()
            if y is None or y[1] != ")":
                raise ValueError("괄호가 닫히지 않음")
            p[0] += 1
            return v
        if x[1] == "-":
            return -prim()
        raise ValueError("식 모양이 맞지 않음")

    def mul():
        v = prim()
        while peek() and peek()[1] in ("*", "/") and peek()[0] == "op":
            o = toks[p[0]][1]
            p[0] += 1
            r = prim()
            if o == "/" and r == 0:
                raise ValueError("0 으로 나눔")
            v = v * r if o == "*" else v / r
        return v

    def add():
        v = mul()
        while peek() and peek()[1] in ("+", "-") and peek()[0] == "op":
            o = toks[p[0]][1]
            p[0] += 1
            r = mul()
            v = v + r if o == "+" else v - r
        return v
    try:
        val = add()
        if p[0] < len(toks):
            raise ValueError("식 모양이 맞지 않음")
        if not math.isfinite(val):
            raise ValueError("값이 유한하지 않음")
        return val, ids, None
    except ValueError as e:
        return None, [], str(e)


def slots_of(text, fb):
    """문장 속 자리를 읽습니다. 돌려주는 값 = ([(종류, 쓴 번호들, 값, 오류)], 닫히지 않은 괄호 여부)"""
    out = []
    for m in SLOT.finditer(text):
        c = m.group(1).strip()
        if re.match(r"calc\s*:", c):
            v, ids, err = calc_expr(re.sub(r"^calc\s*:", "", c), fb)
            out.append(("calc", ids, v, err, m))
        elif re.fullmatch(r"f\d+", c):
            out.append(("fact", [c], None, None if c in fb else "목록에 없는 번호", m))
        else:
            out.append(("bad", [], None, "알 수 없는 자리 모양", m))
    return out, bool(re.search(r"\{\{|\}\}", SLOT.sub("", text)))


NAME = re.compile(r"[A-Za-z][A-Za-z0-9_]*\d[A-Za-z0-9_]*(?:-[A-Za-z0-9_]+)*")


def nums_outside(text):
    """V2: 자리 밖에 쓴 숫자. 챔버·마스크 이름과 '7일' 같은 날 이름만 허용합니다."""
    s = SLOT.sub(" ", text)
    s = NAME.sub(lambda m: " " * len(m.group(0)), s)
    s = re.sub(r"\d+일(?:간)?", lambda m: " " * len(m.group(0)), s, flags=re.A)
    return re.findall(r"\d+(?:[.,]\d+)*", s, flags=re.A)


def rel_word(text):
    return next((w for w in REL_WORDS if w in text), None)


def parse_answer(raw):
    """V1: 답이 약속한 JSON 꼴인가. 돌려주는 값 = (JSON 또는 None, 어긋난 이유 또는 None)"""
    s = raw.strip()
    if not s.startswith("{"):
        return None, "JSON 이 아니라 보통 글"
    try:
        o = json.loads(s)
    except ValueError:
        return None, "JSON 으로 읽히지 않음"
    if not isinstance(o, dict) or not isinstance(o.get("sentences"), list) or not o["sentences"]:
        return None, "sentences 배열이 없음"

            return None, f"{i}번째 문장이 text·cites·type 약속과 다름"

def has_batchim(s):
    c = s[-1]
    if "가" <= c <= "힣":
        return (ord(c) - 0xAC00) % 28 != 0
    if c.isdigit():
        return c in "013678"
    return c in "lmnLMN"


JOSA = {"이": "이가", "가": "이가", "은": "은는", "는": "은는", "을": "을를", "를": "을를"}


def render_text(text, facts):
    """자리를 값으로 바꿉니다. {{fN}} = 값 + 단위(뒤에 같은 단위가 이미 있으면 값만), {{calc: 식}} = 소수 첫째 자리, 자리 바로 뒤 조사(이/가·은/는·을/를)는 받침에 맞춥니다."""
    fb = {f["id"]: f for f in facts}
    sl, _ = slots_of(text, fb)
    out, pos = "", 0
    for kind, ids, val, err, m in sl:
        out += text[pos:m.start()]
        pos = m.end()
        rest = text[m.end():]
        if err:
            out += m.group(0)
            continue
        if kind == "calc":
            piece = f"{val:.1f}"
            if float(piece) == 0:
                piece = piece.replace("-", "")
        else:
            f = fb[ids[0]]
            plain = (not f["unit"]) or rest.lstrip().startswith(f["unit"])
            piece = fmt_val(f, plain)
        j = re.match(r"([이가은는을를])(?=$|[\s.,;)])", rest)
        if j:
            pair = JOSA[j.group(1)]
            out += piece + (pair[0] if has_batchim(piece) else pair[1])
            pos = m.end() + 1
        else:
            out += piece
    return out + text[pos:]

MASKS = [
    (r"[A-Za-z][A-Za-z0-9_]*\d[A-Za-z0-9_]*(?:-[A-Za-z0-9_]+)*", 0),
    (r"\d{4}-\d{2}-\d{2}", 0),
    (r"(^|[^0-9-])(\d{2}-\d{2})(?![0-9-])", 2),
    (r"\d{1,2}:\d{2}", 0),
    (r"표[ \t]*\d+", 0),
    (r"\d+[ \t]*[~∼][ \t]*\d+[ \t]*일(?:간)?", 0),

    (r"\d+[ \t]*월", 0),
    (r"\d+[ \t]*시(?!간)(?:[ \t]*\d+[ \t]*분)?", 0),
    (r"(^|[^0-9.])(\d+\))", 2),
]
NUM = re.compile(r"([+\-−])?(\d{1,3}(?:,\d{3})+|\d+)(\.\d+)?([ \t]*%)?", re.A)


def extract_numbers(text):
    """보통 글에서 숫자를 뽑습니다(날짜·시각·이름·번호는 먼저 지움). 돌려주는 값 = [(절댓값, 소수 자릿수, % 여부), ...]"""
    s = text
    for pat, g in MASKS:
        s = re.sub(pat, lambda m, g=g: m.group(0)[:len(m.group(0)) - len(m.group(g))] + " " * len(m.group(g)), s, flags=re.A)
    out = []
    for m in NUM.finditer(s):
        dec = len(m.group(3)) - 1 if m.group(3) else 0
        out.append((float(m.group(2).replace(",", "") + (m.group(3) or "")), dec, bool(m.group(4))))
    return out


def fact_context(facts):
    """설계 A 의 숫자 대조용 목록: 사실 목록의 숫자(cells)와 두 사실의 차·합·비·비×100(der)."""
    nf = [f for f in facts[:8] if isinstance(f["value"], (int, float))]
    cells = [abs(f["value"]) for f in nf]
    der = []
    for a in nf:
        for b in nf:
            if a is b:
                continue
            if a["id"] < b["id"]:
                der += [("diff", abs(a["value"] - b["value"])), ("sum", a["value"] + b["value"])]
            if b["value"] != 0:
                der += [("ratio", abs(a["value"] / b["value"])), ("pct", abs(a["value"] / b["value"]) * 100)]
    return cells, der


def _best(vals, v, tol):
    b = None
    for c in vals:
        d = abs(v - c)
        if d <= tol and (b is None or d < b - 1e-12):
            b = d
    return b


def check_numbers(text, cells, der, tol_k=TOL_K):
    """숫자마다 '있음 / 계산됨 / 근거 없음'으로 나눕니다. 돌려주는 값 = (분류, 거친 일치 여부) 목록.
    쓰면 안 되는 때: '근거 없음'을 곧 틀림으로 읽지 마십시오. 통과도 '맞음'이 아닙니다(숫자가 엉뚱한 곳에 붙어도 통과합니다)."""
    out = []
    for v, dec, pct in extract_numbers(text):
        tol = tol_k * 10 ** (-dec) + EPS
        coarse = tol >= 0.05 - 1e-12
        cls, diff = "none", None
        if pct:
            bd = _best([x for f, x in der if f == "pct"], v, tol)
            if bd is not None:
                cls, diff = "calc", bd
        else:
            bc = _best(cells, v, tol)
            if bc is not None and bc <= EPS:
                cls, diff = "has", bc
            else:
                bd = None
                for fam in ("diff", "sum", "ratio"):
                    bd = _best([x for f, x in der if f == fam], v, tol)
                    if bd is not None:
                        break
                if bc is not None and bd is not None:
                    cls, diff = ("calc", bd) if bd < bc - 1e-12 else ("has", bc)
                elif bc is not None:
                    cls, diff = "has", bc
                elif bd is not None:
                    cls, diff = "calc", bd
        out.append((cls, diff is not None and diff > EPS and coarse))
    return out
