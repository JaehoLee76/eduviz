Loss 예측

내일의 Loss 를 미리 맞히려면 기준 예측을 먼저 세우고, 그 시각에 알 수 없던 값을 가려내고, 원래 맞힐 수 없는 몫이 무엇인지 알아야 합니다

내일의 Loss 를 미리 알려 주는 모델은 모델부터 고르는 일이 아닙니다. 먼저 몇 시간 뒤까지 맞힐지를 정하고, 모델 없이 세울 수 있는 가장 단순한 예측을 기준으로 둔 뒤, 예측하는 시각에는 아직 알 수 없던 정보가 특징에 섞이지 않게 시간순으로 재서 그 기준을 이기는지 봅니다. 그다음에 Loss 를 원인별로 갈라 보면 정규 PM 처럼 달력에 적힌 Loss 는 달력만으로도 맞고, 고장처럼 마지막 고장 뒤 지난 시간과 무관하게 일어나는 Loss 는 경과 시간으로는 시각을 맞힐 수 없다는 것을 알게 됩니다. 마지막으로 마스크 한 장 한 장의 사용 이력을 따라가면 결함 위험이 높은 사용을 미리 골라 점검할 수 있습니다. 같은 가상 공장 일의 시간별 기록 줄과 Loss 사건 건, 마스크 사용 회로 전부 직접 해 봅니다.

새로 이름을 붙이는 낱말은 여섯 개입니다. 쓰이는 자리에서 하나씩 정의하고, 정의한 뜻 그대로만 씁니다. 이 여섯 개 말고 계산에 붙인 이름(MAE · 개선률 · 로그 손실 · 위험률)과 6절의 부속 낱말(로지스틱 회귀 · 시그모이드 · 규제 · FMM 블록 · 오즈)은 쓰는 자리에서 문장이나 식으로 정의합니다. 이 편의 개선률은 모델의 시험 MAE 가 기준보다 줄어든 비율이며, 0501·0502 에서 과제가 줄이는 비율을 부른 ‘개선율’과는 다른 양입니다.

  • 예측 지평 (forecast horizon)
  • 기준 예측 (baseline forecast)
  • 미래 정보 누설 (look-ahead leakage)
  • 무기억성 (memorylessness)
  • 제품 공정 추적 (product genealogy)
  • 보정도 (calibration)

이 실험실에서 가져가는 것

  1. 실무에서 쓰는 곳 — 내일·다음 교대의 Loss 를 미리 보고 세정 순서와 예비 카세트와 사전 점검을 정하는 것, 그리고 어떤 Loss 는 원래 예측이 안 된다는 것을 알아 예측 과제에 헛힘을 쓰지 않는 것(1~8절).
  2. 손으로 연습 — 기준 예측을 세우고 모델이 그것을 이기는지 시간순 시험으로 재기, 미래 정보가 섞인 특징을 넣었다 빼며 점수가 얼마나 부풀어 오르는지 보기, 근본 원인별로 오차를 갈라 PM 은 맞히고 고장은 못 맞히는 것 보기, 마스크 사용 이력으로 위험 순위를 매겨 상위 몫을 미리 점검할 때 잡히는 결함 수 보기(1~7절).
  3. 다음 날 산출물 — make_horizon_target·baseline_forecast·time_split_eval·leak_check·error_by_root·mask_use_table·risk_rank_capture·calibration_table Python 함수(10절), Loss 예측 모델 카드(11절).
  4. 기록할 데이터 — 시간별 상태를 ‘그 시각에 알 수 있었던 값’으로만 저장하는 스냅숏, PM 계획표 원본, 마스크 개체 id 로 이은 사용 이력(11절).
  5. 사람·규칙·에이전트의 몫 — 지평과 용도의 결정·점검 실행·모델 승인은 사람, 시간순 시험·누설 점검·기준 대비 판정은 규칙, 매일의 특징 생성·예측·오차 추적·모델 카드 초안은 에이전트(8절).
  6. 성과 환산 — 마스크 사전 점검으로 막는 Loss 장수와 점검 비용을 뺀 순이익, 예측 오차가 기준 대비 줄어든 장수(9절).

1첫 시도 — 있는 특징을 모두 넣고 섞어 나눠 재 봅니다

맞히려는 값은 지금 시각 이후 다음 시간 안에 시작한 Loss 사건이 잃게 한 유리 장수의 합입니다. 사건이 그 시간 안에 시작하면 끝이 구간 밖으로 걸쳐도 잃은 장수 전부를 시작한 시각의 칸에 넣습니다. 출발 시각은 한 시간 간격으로 모두 쓰고, 출발 시각마다 한 줄이 생깁니다.

특징은 가진 것을 모두 넣었습니다. 시간별 상태(stocker 채움·세정 대기·빈 카세트·triple 운전 블록 수·라인 출력), 지난 24시간에 끝난 사건의 장수(근본 원인 묶음별), PM 달력, 마지막 고장 뒤 경과 시간, 그리고 같은 시간 구간 안의 상태와 사건에서 뽑은 값들입니다. 아래 3절에서 이 특징을 하나씩 따져 봅니다. 이 가운데 triple 운전 블록 수는 챔버 하나가 서서 나머지 3개로 돌고 있는 블록의 수로, 0501 의 RUN-TRIPLE 이 잃게 하는 3대 운전과 같은 상태입니다. 챔버가 이미 선 블록이 많다는 뜻이라 뒤따르는 Loss 의 앞선 신호가 됩니다.

행을 무작위처럼 섞어 세 칸 중 한 칸을 시험으로 떼어 놓고(번호에 정수 해시를 곱해 나머지로 나눕니다), 직선 회귀와 깊이 회귀 트리를 맞춥니다. 오차는 MAE — 예측과 실제의 차이의 절댓값을 평균한 것이며 단위는 유리 장수입니다. 비교 대상으로 아무 모델 없이 학습 구간의 평균 하나만 말했을 때의 MAE 를 옆에 둡니다. 이 비교 대상에는 3절에서 이름을 붙입니다.

3이름 — 예측 지평·기준 예측·미래 정보 누설

  • 예측 지평 (forecast horizon) — 지금 시각에서 몇 시간 뒤까지의 Loss 를 맞히려는지입니다. 이 실험실에서는 다음 H 시간 안에 시작한 사건의 잃은 유리 장수이며 H 는 아래 슬라이더로 바꿉니다. 정하는 것은 쓰는 사람의 몫이고, 세정 순서를 조정하는 데에는 하루가, 교대 인계에는 열두 시간이 맞는 식으로 용도가 정합니다.
  • 기준 예측 (baseline forecast) — 모델 없이 세우는 가장 단순한 예측입니다. 둘을 씁니다. 평균 예측은 학습 기간의 목표 평균 하나를 늘 말하고, 지속 예측은 ‘지난 H 시간에 끝난 사건의 장수와 같다’고 말합니다. 지난 H 시간에 시작한 사건은 아직 진행 중이면 잃은 장수가 확정되지 않아서, 예측하는 시각에 알 수 있는 것은 이미 끝난 사건뿐입니다. 시작과 끝이 어긋나므로 지속 예측은 맞히기 어려운 약한 기준이고, 평균 예측보다 나쁠 수도 있습니다. 모델은 이 둘 가운데 더 나은 쪽을 이겨야 쓸모가 있습니다. 이 실험실은 모델의 개선률을 1 − (모델의 시험 MAE ÷ 더 나은 기준의 시험 MAE)로 적습니다.
  • 미래 정보 누설 (look-ahead leakage) — 예측하는 시각에는 아직 알 수 없던 값이 특징에 섞여 시험 점수가 부풀어 오르는 것입니다. 0305 의 섞어 나누기 낙관 편향과는 다른 일입니다. 그쪽은 시험 행이 학습 행과 이웃해 닮은 문제이고 시간순 분할로 막습니다. 이쪽은 특징 안에 그 시각에 모를 값이 든 문제이고 특징표의 ‘알려지는 시각’ 열로 막습니다. 둘은 따로 일어나고 따로 막아야 합니다.

시간순 분할은 0305 와 같이 앞쪽을 학습, 뒤쪽을 시험으로 씁니다. 여기서는 목표 구간까지 학습 기간 안에서 끝나는 출발 시각만 학습에 넣어, 학습의 정답과 시험 기간이 겹치지 않게 합니다. 특징은 아래 표와 같습니다.

PM 달력 특징은 챔버마다 지난 PM 시작 시각에 학습 기간 PM 시작 간격의 중앙값()을 더한 시각이 다음 H 시간 안에 드는 챔버 수입니다. 이 간격은 기록에서 추정한 값입니다. 모든 챔버의 첫 PM 을 아직 못 본 처음 시간은 출발 시각에서 뺍니다. 지난 24시간의 사건 장수는 이미 끝난 사건만 셉니다. 고장 계열은 설비 고장과 증착기 불량을 묶은 이름으로 5절에서 다시 정의합니다.

조건은 운영과 같게 고정합니다. 시간순 분할, 누설 특징 없음, 지평 H = 시간, 학습 일입니다(3절의 슬라이더를 따라갑니다). 모델 넷을 견줍니다. 기준 둘은 3절에서 정했습니다. 직선 회귀는 특징의 가중합입니다. 포아송 회귀는 0502 의 포아송을 회수해 평균이 특징의 지수 함수가 되게 맞춥니다. 목표가 건수가 아니라 장수여서 정수 건수의 분포라는 가정은 쓸 수 없지만, 계수는 ‘예측 평균과 실제 평균이 특징마다 맞게’라는 조건만으로 구할 수 있어 직선 회귀와 견줄 수 있습니다. 회귀 트리는 특징을 문턱으로 갈라 구간마다 평균을 말합니다. 깊이는 슬라이더로 바꿉니다.

두 확인을 읽는 기준. 첫째, ‘평균 ≈ 표준편차’의 ≈ 는 변동계수(표준편차 ÷ 평균)가 1 에서 우연히 벗어나는 폭으로 가립니다. 무기억성을 가진 간격 n 개의 변동계수는 1 둘레에서 대략 1/√n 만큼 흔들리므로(지수분포에서 간격 n 개를 뽑아 변동계수를 반복해 재어 본 시뮬레이션으로 확인한 어림이며, 100개이면 약 0.1), 그 안에 들어오면 평균 = 표준편차와 어긋나지 않는다고 봅니다. 이 성질을 가진 시간의 분포가 지수분포이고, 무기억성은 그 분포의 성질입니다. 둘째, 위험률 비의 p 값이 크다는 것은 ‘차이가 없다’의 증거가 아니라 ‘이 건수로는 차이를 못 찾았다’입니다. 고장 간격이 수십~백 개뿐이라 작은 차이는 놓칠 수 있으므로, 이 확인이 말하는 것은 위험률이 경과 시간에 따라 크게 오르내리지 않는다는 데까지입니다.

비율로만 계획에 넣습니다. 시간당 위험률이 일정하면 다음 H 시간에 고장이 시작할 건수는 위험률 × 챔버 수 × H 로 기대할 수 있습니다. 어느 챔버가 언제 서는지는 맞히지 못해도 세정 순서의 여유나 예비 인력의 총량은 이 기대값으로 잡습니다(0502 의 포아송). 진동·온도 같은 전조 신호를 기록하면 이야기가 달라지지만, 그 신호가 기록에 없는 한 이 기록으로는 시각을 맞힐 수 없습니다.

이 기록으로는 아닙니다. 근거는 둘로 나뉩니다. 첫째, 5절에서 잰 위험률은 마지막 고장 뒤 경과 시간 하나에 대한 것인데, 그것이 평평하므로 지난 시간은 다음 고장 시각에 대해 알려 주는 정보가 없습니다. 둘째, 경과 시간 말고 다른 특징(stocker·세정 대기·가동 블록 수 등)에 정보가 있는지는 같은 시간순 시험의 개선률로 따로 잽니다. 고장 계열 몫은 직선 회귀와 트리 모두 개선률이 음수여서 기준을 이기지 못했습니다(5절 표). 모델을 아무리 크게 만들어도 입력에 정보가 없으면 평균 이상을 말할 수 없습니다. 깊이를 올린 트리가 학습 오차만 내리고 시험 오차를 올리는 4절의 모습이 그 작은 예입니다.

다른 이야기는 있습니다. 고장 전에 진동이나 온도 같은 신호가 달라지는 설비라면, 그 신호를 시간별로 기록해 두는 것이 먼저입니다. 신호가 쌓여 있어야 모델이 그것을 배울 수 있습니다. 시각이 아니라 신호를 기록하는 쪽이 경쟁력입니다.

6제품 공정 추적으로 마스크 결함 예측

마스크 결함은 챔버가 아니라 마스크 한 장의 이력에 따라 위험이 달라지는 Loss 입니다. 그 이력을 따라가려면 마스크 하나가 어디서 몇 번 쓰이고 몇 번 세정과 리페어를 거쳤는지를 개체 단위로 이은 기록이 있어야 합니다.

  • 제품 공정 추적 (product genealogy / traceability) — 제품이나 소모품(여기서는 마스크) 하나가 어느 블록에서 몇 번 쓰이고 몇 번 세정·리페어됐는지를 개체 단위로 잇는 기록입니다. 이 기록이 있어야 ‘이 마스크는 지금 몇 번째 세정이고 어느 블록에 들어가는가’를 사용 하나하나에 붙일 수 있습니다.
  • 보정도 (calibration) — 예측 확률이 실제 빈도와 맞는 정도입니다. “결함 확률 1% 라고 한 사용들 가운데 실제로 약 1% 가 결함이었나”를 묻습니다. 순위만 맞히는 모델과 확률까지 맞히는 모델은 다릅니다.

0206 의 전이 기록(mask_transitions.csv)에서 마스크의 전이만 뽑으면 아래와 같은 줄이 나옵니다. 사용 한 번은 to=in_use 인 행이고, 그 행의 cause 에 나이(마지막 리페어 뒤 세정 횟수)가 적힙니다. 사용이 결함이었는지는 다음 사용이 시작되기 전에 to=repair 이고 trigger=turn_end_defect 인 행이 있었는지로 정합니다(끝나지 않은 사용은 결함 없음으로 셉니다. 기록 끝 무렵에 아직 끝나지 않은 사용의 결함은 놓치므로 결함 수는 실제보다 조금 작게 나옵니다. 0400 의 늦게 들어오는 자료와 같은 종류의 문제이고, 이 기록에서는 끝나지 않은 사용이 전체의 1% 안쪽이라 영향이 작습니다. 현장에서는 결함 표시가 늦게 확정되므로 나중에 다시 채워 셉니다.) 처음으로 결함이 난 마스크의 기록입니다.

이렇게 사용 한 번당 한 줄로 만든 표가 마스크 사용 표입니다. FMM 블록은 화소(픽셀)를 만드는 마스크를 쓰는 여섯 블록(B02~B07)이고, 공통층과 오픈 마스크 블록(B01·B08~B11)은 FMM 블록이 아닙니다. 사용마다 그 블록이 FMM 블록이면 1, 아니면 0 인 칸(FMM)을 붙입니다. 같은 세트가 같은 시각에 시작한 사용들의 평균 나이도 붙입니다(7절에서 쓰입니다).

계수가 몇 개뿐인 단순한 모델이면 됩니다. 6절의 나이별 결함률은 구간마다 건수가 몇 건이라 점 하나하나로는 믿을 수 없었습니다. 그래서 계수 네 개(절편·나이·FMM·나이×FMM)로 전체를 요약하는 로지스틱 회귀를 썼고, 그 계수가 시드마다 얼마나 흔들리는지는 7절에서 봅니다.

반대로 칸이 수십 개인 표나 깊은 트리는 결함 몇 건에 맞춰져 버립니다. 결함이 드물수록 모델은 단순해야 하고, 보정도 표의 칸도 적어야 합니다.

확률만으로는 정하지 않습니다. 점검 비용과 막는 장수로 문턱을 정합니다. 확률 p 인 사용 하나를 점검하면 기대로 p × (그 결함이 일으킬 Loss 장수) 만큼 막고, 점검 한 번이 챔버 시간을 씁니다. 막는 장수가 비용을 넘는 사용부터 점검하는 것이 맞습니다.

9절의 환산 상자가 그 계산입니다. 점검 몫을 올리면 포착률은 늘지만 점검마다 드는 비용이 쌓여 순이익이 줄어드는 지점이 생깁니다.

# ---- 가정·설정: 회사 값으로 바꿀 곳 --------------------------------------------------
START = pd.Timestamp("2026-01-05 00:00")   # 기록 시작 시각
H = 24                            # 예측 지평(시간): 지금부터 다음 H 시간
SPLIT_DAY = 40                    # 앞 40일 학습 / 나머지 시험(시간순 분할)

GROUPS = [("pm", ["EQ-PM"]), ("mask", ["Q-MASK"]), ("fault", ["EQ-BD", "Q-EVAP"]), ("other", None)]   # 근본 원인 묶음(마지막 = 그 밖)

FEATURES = [("pm_due", "before"), ("l24_pm", "before"), ("l24_mask", "before"), ("l24_fault", "before"), ("l24_other", "before"),

def group_of(code):
    for gi, (_, codes) in enumerate(GROUPS[:-1]):
        if code in codes:
            return gi
    return len(GROUPS) - 1


# ---- 1. 불러오기 ------------------------------------------------------------------------
def load_events(path="loss_events.csv"):
    """Loss 사건 표. 시작·끝 시각을 기록 시작부터 분으로 바꾸고, 근본 원인 묶음 번호(grp)를 붙인다."""
    df = pd.read_csv(path, keep_default_na=False)
    for c in ("start", "end"):
        df[c + "_min"] = ((pd.to_datetime(df[c + "_ts"]) - START) / pd.Timedelta(minutes=1)).round().astype(int)
    df["grp"] = df["root_cause"].map(group_of)
    return df


def cum(a):
    return np.concatenate([[0.0], np.cumsum(a)])


# ---- 2. 목표와 특징 ------------------------------------------------------------------------
def make_horizon_target(ev, hr, H, split_day):
    """출발 시각 t = 60h 분마다 한 줄: 목표 y = t 이후 H 시간 안에 '시작한' 사건의 잃은 유리 합(걸친 사건도 시작 시각 칸에 전부),
    y_pm·y_mask·y_fault·y_other = 근본 원인 묶음별 합, pers = 지난 H 시간에 '끝난' 사건 합(지속 기준), 특징 열(FEATURES 와 같은 이름).
    특징은 t 에 알 수 있던 값만: 직전 시간 상태, 지난 24시간에 끝난 사건 합, PM 달력(챔버의 지난 PM 시작 + 학습 기간 PM 간격의 중앙값),
    마지막 고장 뒤 경과 시간. fut_ 열 둘은 예측 구간 안에서야 알 수 있는 '누설 특징'이다.
    쓰면 안 되는 때: 사건 끝에 채워지는 근본 원인 칸을 사건이 아직 안 끝난 시각의 특징으로 쓸 때."""
    n, ng = len(hr), len(GROUPS)
    sb = (ev["start_min"] // 60).to_numpy()
    eb = np.ceil(ev["end_min"].to_numpy() / 60).astype(int)
    g, glass = ev["grp"].to_numpy(), ev["loss_glass"].to_numpy(float)
    S = np.zeros((ng, n)); E = np.zeros((ng, n))
    for k in range(len(ev)):
        if 0 <= sb[k] < n:
            S[g[k], sb[k]] += glass[k]
        if 0 <= eb[k] < n:
            E[g[k], eb[k]] += glass[k]
    cnt = np.bincount(sb[(sb >= 0) & (sb < n)], minlength=n).astype(float)
    pm_mask = (ev["root_cause"] == "EQ-PM").to_numpy()
    cpm = np.bincount(sb[pm_mask & (sb >= 0) & (sb < n)], minlength=n).astype(float)
    CS, CE, Ccnt, Ccpm = [cum(r) for r in S], [cum(r) for r in E], cum(cnt), cum(cpm)
    CSt, CEt = cum(S.sum(0)), cum(E.sum(0))
    Ctri = cum(hr["blocks_triple"].to_numpy(float))
    own = ev[ev["reason"] == ev["root_cause"]]
    pm_starts = [np.sort(d["start_min"].to_numpy()) for _, d in own[own["reason"] == "EQ-PM"].groupby(["block", "chamber"])]
    bd, evp = (np.sort(own[own["reason"] == c]["start_min"].to_numpy()) for c in ("EQ-BD", "Q-EVAP"))
    split_h = split_day * 24
    gaps = np.concatenate([np.diff(a)[a[1:] < split_h * 60] for a in pm_starts])
    period = float(np.median(gaps))
    h0 = max(ORIGIN0, int(np.ceil(period / 60)))
    rows = []
    for h in range(h0, n - H + 1):
        t = h * 60
        due = 0
        for a in pm_starts:
            i = np.searchsorted(a, t, side="right") - 1
            if i >= 0 and t <= a[i] + period < t + H * 60:
                due += 1
        r = hr.iloc[h - 1]
        ib, ie = np.searchsorted(bd, t, side="right") - 1, np.searchsorted(evp, t, side="right") - 1
        nc, npm = Ccnt[h + H] - Ccnt[h], Ccpm[h + H] - Ccpm[h]
        row = {"h": h, "y": CSt[h + H] - CSt[h], "pers": CEt[h + 1] - CEt[h - H + 1],
               "pm_due": due, "stocker_fill": r["stocker_fill"], "cleaner_queue": r["cleaner_queue"], "cassette_free": r["cassette_free"],
               "blocks_triple": r["blocks_triple"], "line_out": r["line_out"],
               "since_bd": (t - bd[ib]) / 60 if ib >= 0 else t / 60, "since_ev": (t - evp[ie]) / 60 if ie >= 0 else t / 60,
               "fut_triple": (Ctri[h + H] - Ctri[h]) / H, "fut_pmshare": npm / nc if nc > 0 else 0.0}
        for gi, (gid, _) in enumerate(GROUPS):
            row["y_" + gid] = CS[gi][h + H] - CS[gi][h]
            row["pers_" + gid] = CE[gi][h + 1] - CE[gi][h - H + 1]
            row["l24_" + gid] = CE[gi][h + 1] - CE[gi][h - 23]
        rows.append(row)
    tab = pd.DataFrame(rows)
    tab.attrs.update(H=H, split_h=split_h, period=period)
    return tab


def leak_check(features):
    """특징표(이름, 알려지는 시각)에서 예측 시각 t 에 쓸 수 없는 것을 골라낸다. 쓰면 안 되는 때: 시각 열을 사람이 채우지 않은 특징표."""
    return [name for name, avail in features if avail != "before"]


# ---- 3. 기준 예측과 시간순 시험 --------------------------------------------------------------
def baseline_forecast(tab, idx_train, idx_test, kind, target="y"):
    """'mean' = 학습 기간 평균 · 'persist' = 지난 H 시간에 끝난 사건 합(지속). target 은 'y' 또는 'y_pm' 같은 열 이름."""
    if kind == "mean":
        return np.full(len(idx_test), tab[target].to_numpy()[idx_train].mean())
    return tab[target.replace("y", "pers", 1)].to_numpy()[idx_test]


def split_index(tab, mode):
    h, H, sh = tab["h"].to_numpy(), tab.attrs["H"], tab.attrs["split_h"]
    if mode == "shuffle":
        te = (h * SHUF_MUL) % 4294967296 % SHUF_MOD == 0
        return np.where(~te)[0], np.where(te)[0]
    return np.where(h + H <= sh)[0], np.where(h >= sh)[0]


def time_split_eval(tab, model, depth=DEPTH, leak=(False, False, False), mode="time", target="y"):
    """한 번의 시험. model = 'linear'|'poisson'|'tree'|'mean'|'persist'. leak = (예측 구간 안 triple, 구간 안 PM 비율, 표준화에 시험 기간 포함).
    시간순 분할은 목표 구간이 분할 시각 안에서 끝난 출발 시각만 학습에 쓴다. 반환: (시험 MAE, 시험 RMSE, 예측값).
    쓰면 안 되는 때: 섞어 나눈 점수로 운영 성능을 말할 때."""
    cols = LEGIT + (["fut_triple"] if leak[0] else []) + (["fut_pmshare"] if leak[1] else [])
    tr, te = split_index(tab, mode)
    X, y = tab[cols].to_numpy(float), tab[target].to_numpy(float)
    if model in ("mean", "persist"):
        p = baseline_forecast(tab, tr, te, model, target)
    elif model == "tree":
        p = DecisionTreeRegressor(max_depth=depth, min_samples_leaf=MIN_LEAF, random_state=0).fit(X[tr], y[tr]).predict(X[te])
    else:
        sc = StandardScaler().fit(X if leak[2] else X[tr])
        Ztr, Zte = sc.transform(X[tr]), sc.transform(X[te])
        if model == "linear":
            p = LinearRegression().fit(Ztr, y[tr]).predict(Zte)
        else:
            p = PoissonRegressor(alpha=0, solver="newton-cholesky", tol=1e-12, max_iter=1000).fit(Ztr, y[tr]).predict(Zte)
    return np.abs(y[te] - p).mean(), np.sqrt(((y[te] - p) ** 2).mean()), p


def improvement(tab, model, **kw):
    """시험 MAE 로 잰 기준 대비 개선률: 1 − (모델 MAE ÷ 더 나은 기준의 MAE)."""
    t = kw.get("target", "y")
    base = min(time_split_eval(tab, b, target=t, mode=kw.get("mode", "time"))[0] for b in ("mean", "persist"))
    return 1 - time_split_eval(tab, model, **kw)[0] / base


def error_by_root(tab, depth=DEPTH):
    """근본 원인 묶음마다 따로 맞춘 시험 오차와 기준 대비 개선률(시간순, 누설 끔).
    쓰면 안 되는 때: 시험 기간 평균이 아주 작은 묶음(그 밖)의 개선률로 결론을 낼 때."""
    out = []
    for gid, _ in GROUPS:
        t = "y_" + gid
        out.append((gid, tab[t].to_numpy()[split_index(tab, "time")[1]].mean(), improvement(tab, "linear", target=t), improvement(tab, "tree", target=t, depth=depth)))
    return out


def composite(tab):
    """분해 예측: 정규 PM 몫은 직선 회귀, 나머지 몫은 학습 기간 평균으로 맞춰 더한 전체 예측의 개선률."""
    te = split_index(tab, "time")[1]
    p = time_split_eval(tab, "linear", target="y_pm")[2] + sum(time_split_eval(tab, "mean", target="y_" + g)[2] for g, _ in GROUPS[1:])
    y = tab["y"].to_numpy()[te]
    base = min(time_split_eval(tab, b)[0] for b in ("mean", "persist"))
    return 1 - np.abs(y - p).mean() / base


# ---- 4. 무기억성: 고장 간격과 경과 시간별 위험 ----------------------------------------------------
def memoryless_check(ev, code, tmax_min, edges_h=(0, 72, 144, 240, 336, 504)):
    """같은 챔버의 '끝 → 다음 시작' 간격(시간)의 평균·표준편차·변동계수와, 마지막 고장이 끝난 뒤 경과 시간 구간별 위험률(건/시간).
    위험률이 구간마다 비슷하면(앞 3구간 대 뒤 3구간을 정확 이항 검정) 지난 시간이 다음 고장 확률에 영향이 없는 무기억성에 가깝다.
    쓰면 안 되는 때: 고장이 수십 건 안쪽일 때(구간별 위험률이 건수 몇 개로 흔들린다)."""
    own = ev[(ev["reason"] == code) & (ev["root_cause"] == code)]
    gaps, expo, n = [], np.zeros(len(edges_h)), np.zeros(len(edges_h), int)
    for _, d in own.groupby(["block", "chamber"]):
        d = d.sort_values("start_min")
        done = d[d["end_min"] <= tmax_min]
        gaps += list(((done["start_min"].to_numpy()[1:] - done["end_min"].to_numpy()[:-1]) / 60))
        d = d[d["start_min"] < tmax_min]      # 관찰창 끝(학습 기간 끝) 뒤에 시작한 고장은 아직 모르는 것
        s, e = d["start_min"].to_numpy(), d["end_min"].to_numpy()
        for i in range(len(d)):
            nxt = s[i + 1] if i + 1 < len(d) else None
            span = ((nxt if nxt is not None else tmax_min) - e[i]) / 60
            if span <= 0:
                continue
            for b, lo in enumerate(edges_h):
                hi = edges_h[b + 1] if b + 1 < len(edges_h) else np.inf
                if min(span, hi) - lo > 0:
                    expo[b] += min(span, hi) - lo
            if nxt is not None:
                n[max(b for b, lo in enumerate(edges_h) if span >= lo)] += 1
    gaps = np.array(gaps)
    e1, e2, n1, n2 = expo[:3].sum(), expo[3:].sum(), n[:3].sum(), n[3:].sum()
    p = stats.binomtest(int(n1), int(n1 + n2), e1 / (e1 + e2)).pvalue
    return {"n_gap": len(gaps), "mean_h": gaps.mean(), "sd_h": gaps.std(ddof=1), "wait_h": expo.sum() / n.sum(), "rate_ratio": (n2 / e2) / (n1 / e1), "p": p, "expo": expo, "n": n}


# ---- 5. 제품 공정 추적: 마스크 사용 이력 ---------------------------------------------------------
def mask_use_table(trans, fmm_blocks=FMM_BLOCKS):
    """전이 기록에서 마스크 사용 한 번 = 한 줄(in_use 로 들어간 행). 나이 = 리페어 뒤 세정 횟수(cause 'age=N'), 결함 = 다음 사용 전에
    to='repair' & trigger='turn_end_defect' 행이 있음. 같은 세트가 같은 시각에 시작한 사용의 평균 나이(set_age)도 붙인다.
    쓰면 안 되는 때: 마스크 개체 id 가 기록에 없고 세트 단위로만 남은 이력(그때는 set_age 만 쓸 수 있고 포착률이 떨어진다)."""
    m = trans[trans["entity"] == "mask"]
    uses, cur = [], {}
    for t, mid, to, trig, cause in zip(m["t"], m["id"], m["to"], m["trigger"], m["cause"]):
        if to == "in_use":
            cur[mid] = {"mask_id": mid, "t": int(t), "age": int(str(cause).replace("age=", "")), "block": mid[:3], "fmm": int(mid[:3] in fmm_blocks), "set": mid[:5], "defect": 0}
            uses.append(cur[mid])
        elif to == "repair" and trig == "turn_end_defect" and mid in cur:
            cur[mid]["defect"] = 1
    df = pd.DataFrame(uses)
    df["set_age"] = df.groupby(["set", "t"])["age"].transform("mean")
    return df


def fit_risk(df, split_day, kind="full"):
    """로지스틱 회귀(규제 없음). kind: full = 나이·FMM·나이×FMM · add = 나이·FMM · fmm = FMM 만 · set = 세트 평균 나이 쪽."""
    a = "set_age" if kind == "set" else "age"
    feats = {"full": [a, "fmm", "x"], "set": [a, "fmm", "x"], "add": [a, "fmm"], "fmm": ["fmm"]}[kind]
    df = df.assign(x=df[a] * df["fmm"])
    tr, te = df[df["t"] < split_day * 1440], df[df["t"] >= split_day * 1440]
    lr = LogisticRegression(penalty=None, solver="newton-cholesky", tol=1e-12, max_iter=1000).fit(tr[feats], tr["defect"])
    return lr, lr.predict_proba(te[feats])[:, 1], te["defect"].to_numpy(float), tr["defect"].mean()


def _ties(p, y):
    """예측 확률이 같은 사용은 한 묶음으로(큰 쪽부터). 반환: [확률, 사용 수, 결함 수]."""
    o = np.lexsort((np.arange(len(p)), -p))
    gs = []
    for i in o:
        if gs and abs(gs[-1][0] - p[i]) <= 1e-12 * max(1, abs(p[i])):
            gs[-1][1] += 1; gs[-1][2] += y[i]
        else:
            gs.append([p[i], 1, y[i]])
    return gs


def risk_rank_capture(p, y, k):
    """위험 상위 k 몫을 미리 점검했을 때 잡히는 결함 몫(포착률). 같은 점수 묶음이 경계에 걸리면 묶음 안에서 비례로 센다.
    쓰면 안 되는 때: 점검 대상 수(k × 사용 수)가 결함 수보다 훨씬 작을 때 잡힌 수만으로 순위의 질을 말할 때."""
    want, taken, cap = k * len(p), 0.0, 0.0
    for q, n, d in _ties(p, y):
        if taken >= want - 1e-12:
            break
        take = min(n, want - taken)
        cap += d * take / n; taken += take
    return cap, y.sum(), cap / y.sum()


def calibration_table(p, y, bins):
    """보정도 표: 확률이 같은 묶음은 쪼개지 않고 낮은 쪽부터 쌓아 한 칸이 n/bins 이상이면 자른다. 반환: [(사용 수, 예측 평균, 실제 비율, 결함 수)].
    쓰면 안 되는 때: 결함이 수십 건뿐인데 10칸으로 자를 때(칸마다 결함 서너 건이라 실제 비율이 건수 하나에 흔들린다)."""
    gs, rows, cn, cd, cp = _ties(p, y)[::-1], [], 0, 0.0, 0.0
    for i, (q, n, d) in enumerate(gs):
        cn += n; cd += d; cp += q * n
        if (cn >= len(p) / bins - 1e-9 and len(rows) < bins - 1) or i == len(gs) - 1:
            rows.append((cn, cp / cn, cd / cn, cd)); cn, cd, cp = 0, 0.0, 0.0
    return rows
