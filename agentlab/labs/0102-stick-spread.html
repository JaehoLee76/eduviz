평균은 그대로인데 산포가 줄었다

이 실험실의 물음은 한 줄입니다. 마스크의 불량 스틱을 새것으로 갈아 끼웠더니 PPA 지표의 평균은 그대로인데 흩어짐만 눈에 띄게 줄어 보입니다. 이것이 우연이 아니라고 숫자로 말하려면 어떤 검정을 어떤 순서로 써야 하는가.

실험실 0101 에서 이어집니다. 0101 에서는 PM 전후로 압력의 평균이 옮겨 갔는지를 재는 법을 배웠습니다. 평균은 “중심이 어디냐”를 묻는 숫자입니다. 그런데 PPA 에서는 중심 못지않게 “얼마나 흩어졌느냐”가 곧 품질입니다. 평균이 목표에 딱 맞아도 점마다 들쭉날쭉하면 화소가 서로 겹치거나 비어 불량이 되기 때문입니다. 그래서 이번에는 평균이 아니라 산포(흩어진 정도)가 줄었는지를 묻는 법을 배웁니다.

이미 알고 계신 것

  • 평균·중앙값·표준편차, 정규분포, 평균 ±3σ 로 그은 관리선
  • p값과 유의수준 5%, 귀무가설, 자유도
  • 웰치 t검정 (실험실 0101), 분산분석의 제곱합

1문제와 주어진 데이터

문제

마스크 B05-B3 (블록 B05 G EML 층, 챔버 CH3 전용)는 11개의 스틱으로 이루어져 있고, 그중 4번째 스틱이 불량으로 판정되어 새것으로 교체되었습니다. 교체 전 유리 장, 교체 후 유리 장에서 PPA 를 쟀습니다.

PPA (Pixel Position Accuracy, 화소 위치 정확도)는 유리 한 장 위의 77개 점(가로 11 × 세로 7)에서 화소가 목표 위치에서 얼마나 벗어났는지 잰 값입니다. 여기서는 가로 방향 오차 dx (µm)를 씁니다. 유리 한 장마다 77개 값에서 지표 하나를 만듭니다. 지표가 작을수록 좋습니다.

유리 한 장의 품질 지표 (µm) 지표=|x¯|+3s x̄ 와 s 는 그 유리의 77개 dx 값의 평균과 표준편차입니다. 중심이 어긋난 만큼과 흩어진 만큼을 한 숫자로 더한 것입니다.

질문: 스틱 교체는 효과가 있었는가. 곧 교체 전후의 유리 지표가 달라졌는가.

전제: 이 40장은 같은 마스크와 같은 챔버에서 이어서 처리된 유리 가운데 모은 표본이며, 앞으로 같은 조건에서 나올 유리를 대표한다고 봅니다. 유리 한 장이 다음 장의 값을 따라가지 않는다(서로 독립)고 가정합니다. 이웃한 값이 서로 닮는 경우는 실험실 0104 에서 다룹니다.

x 방향으로 +쪽 오차−쪽 오차칸 안 숫자 = dx (µm), 아래 막대 = 열 평균

한 유리만 보아서는 알 수 없지만, 20장을 모아 열마다 평균을 내고 그 평균이 유리마다 얼마나 흔들렸는지(표준편차)를 보면 이렇습니다. 교체 전에는 스틱 4 열이 µm 로 흔들리고 나머지 열은 가장 큰 것이 µm 입니다. 교체 후에는 스틱 4 열이 µm, 나머지 열의 최대가 µm 로 모든 열이 비슷해졌습니다. 불량 스틱은 중심을 옮긴 것이 아니라 유리마다 다른 방향으로 흔들리게 만들고 있었습니다. 유리 20장의 지표 평균이 비슷한데도 흩어짐이 다른 까닭이 여기 있습니다.

한 유리 안의 77개 점은 같은 유리, 같은 마스크 배치, 같은 온도를 공유하므로 서로 닮아 있습니다. 독립적인 관측이 아닙니다.

이것을 20장 × 77점 = 1540개의 독립 관측처럼 세면 자유도를 부풀려 p값이 실제보다 훨씬 작게 나옵니다. 독립에 가까운 관측 단위는 “유리 한 장”이므로, 유리마다 지표 하나로 줄여 20개 대 20개로 비교하는 것이 안전합니다.

단계 5 · 결론 서술 (여기까지)

“교체 전후 평균 지표에 차이가 있다는 증거가 없다. 교체 효과가 없었다.” 이렇게 쓰면 안 되는 이유가 바로 다음 대목입니다.

여기서 막힙니다. 위 그림을 다시 보십시오. 교체 후 점들은 가운데 좁은 구간에 모여 있고, 교체 전 점들은 양쪽으로 넓게 퍼져 있습니다. 표준편차는 교체 전 , 교체 후 입니다. 3σ 관리선은 “교체 후 값이 교체 전의 흩어진 범위를 벗어났는가”만 묻기 때문에, 흩어짐이 줄어 범위 안쪽으로 더 모인 것은 아예 볼 수 없습니다. 웰치 t검정도 평균만 비교합니다. PPA 에서 품질은 평균이 아니라 산포이므로 평균이 아닌 산포를 비교하는 도구가 필요합니다.

아닙니다. p값이 크다는 것은 “차이가 있다는 증거가 충분하지 않다”는 뜻이지 “같다”를 증명한 것이 아닙니다. 20장씩으로는 작은 평균 차이를 우연과 구별하지 못할 수 있습니다.

“바뀌지 않았다”를 숫자로 보이려면 허용폭을 정해 놓고 그 안에 들어오는지 확인하는 별도의 검정(동등성 검정)이 필요합니다. 실험실 0103 에서 다룹니다.

3산포를 비교하는 첫 번째 도구: 분산비와 F검정

왜 필요한가. 평균의 차이는 “뺄셈”으로 쟀습니다. 흩어짐은 뺄셈보다 “몇 배냐”가 자연스럽습니다. 교체 전이 교체 후보다 몇 배 흩어져 있는가를 물으려면 두 집단의 분산(표준편차의 제곱)을 나누면 됩니다. 이 비 F 는 영국 통계학자 피셔(Fisher)의 머리글자를 딴 이름이고, 두 집단의 산포가 정말 같다면 1 근처의 값이 나옵니다. 우연만으로 1 에서 얼마나 멀어질 수 있는지 알려 주는 분포가 F분포이며, 분자와 분모 자유도 두 개가 필요합니다.

그런데 이 결과를 그대로 믿어도 될까요? F검정은 정규분포에서 조금만 벗어나도 흔들립니다. 특히 한쪽으로 긴 꼬리가 있으면 “산포가 다르다”는 거짓 경보를 자주 냅니다. 같은 분포에서 뽑은 표본 두 개는 산포가 같으므로 검정이 5% 기준으로 경보를 울린다면 그것은 모두 거짓 경보여야 합니다. 그 비율을 직접 세어 봅니다.

두 종류의 분포를 정합니다. 하나는 좌우 대칭인 정규분포, 다른 하나는 오른쪽 꼬리가 긴 치우친 분포(로그정규분포)입니다. 각각에서 20개씩 두 표본을 번 뽑아, 두 표본은 언제나 같은 분포에서 나왔으므로 정답은 항상 “산포가 같다”입니다.

유의수준을 5% 로 정했으므로 거짓 경보는 5% 안팎이어야 합니다. 정규분포에서는 F검정이 그 약속을 지키지만, 꼬리가 긴 분포에서는 약속이 깨집니다. 이 자료가 정규에 가까운지 20개로는 확신할 수 없으므로 정규성에 기대지 않는 산포 검정이 필요합니다. 거짓 경보 비율은 이 쪽의 고정된 난수 열로 센 값이므로 난수를 달리 쓰면 몇 퍼센트포인트는 달라집니다.

대립가설이 “전의 산포가 더 크다”가 아니라 “다르다”이므로, F 가 아주 크거나 아주 작은 두 경우를 모두 치우친 것으로 칩니다. F 가 1 보다 작아도 분모가 더 큰 것뿐이므로 문제없습니다.

한쪽 꼬리 확률(F 보다 더 극단적인 쪽)에 2 를 곱하고, 1 이 넘으면 1 로 자릅니다. 분자·분모를 바꾸어 F 를 거꾸로 해도 같은 p값이 나옵니다.

Q-Q 그림이나 샤피로-윌크(Shapiro–Wilk) 검정을 씁니다. 하지만 20개로는 정규에서 꽤 벗어나 있어도 “벗어났다는 증거가 부족하다”로 나오는 일이 흔합니다.

그래서 정규성을 먼저 확인하고 검정을 고르는 순서보다, 정규성이 깨져도 잘 버티는 검정을 기본으로 삼는 편이 안전합니다. 에이전트의 검정 선택 규칙도 이 방식으로 만듭니다.

4꼬리에 속지 않는 산포 검정: 레빈 검정 (중앙값 기준)

왜 필요한가. F검정은 분산을 직접 비교해서 꼬리에 흔들렸습니다. 발상을 바꿉니다. 산포 비교를 우리가 이미 잘 아는 평균 비교로 바꾸는 것입니다. 각 값이 자기 집단의 중심에서 얼마나 떨어져 있는지를 새 자료 z 로 만들면, 산포가 큰 집단은 z 의 평균이 큽니다. 그 z 들의 평균을 비교하면 됩니다. 이 방법이 레빈 검정이고, 중심을 평균 대신 중앙값으로 잡은 형태가 브라운-포사이스입니다. 평균은 꼬리 쪽 값에 끌려가 중심이 이동하지만 중앙값은 끌려가지 않아서 치우친 자료에서 훨씬 안정적입니다.

단계 1 · 가설

import numpy as np
import pandas as pd
from scipy import stats


def variance_ratio_test(a, b):
    """분산비 F검정(양측). 두 자료가 정규분포일 때만 믿을 수 있다."""
    a, b = np.asarray(a, float), np.asarray(b, float)
    F = a.var(ddof=1) / b.var(ddof=1)
    d1, d2 = len(a) - 1, len(b) - 1
    p = min(1.0, 2 * min(stats.f.sf(F, d1, d2), stats.f.cdf(F, d1, d2)))
    return {"F": F, "df1": d1, "df2": d2, "p": p}


def levene_test(a, b, center="median"):
    """두 집단의 산포 비교(레빈; center='median' 이면 브라운-포사이스).
    각 값이 자기 집단 중심에서 떨어진 거리 z 를 만들어 그 평균을 분산분석 F 로 비교한다."""
    a, b = np.asarray(a, float), np.asarray(b, float)
    mid = np.median if center == "median" else np.mean
    za, zb = np.abs(a - mid(a)), np.abs(b - mid(b))
    n1, n2 = len(a), len(b)
    N = n1 + n2
    m1, m2 = za.mean(), zb.mean()
    mt = np.concatenate([za, zb]).mean()
    between = n1 * (m1 - mt) ** 2 + n2 * (m2 - mt) ** 2
    within = ((za - m1) ** 2).sum() + ((zb - m2) ** 2).sum()
    W = (N - 2) * between / within
    return {"W": W, "df1": 1, "df2": N - 2, "p": stats.f.sf(W, 1, N - 2),
            "center": center, "z_mean_a": m1, "z_mean_b": m2}


def mannwhitney(a, b):
    """맨-휘트니 U(양측, 정규 근사·연속성 보정·동점 보정). U 는 a 쪽 값이다.
    prob_a_gt_b = U/(n1*n2) : a 값이 b 값보다 클 확률(동점은 반)."""
    a, b = np.asarray(a, float), np.asarray(b, float)
    n1, n2 = len(a), len(b)
    N = n1 + n2
    ranks = stats.rankdata(np.concatenate([a, b]))
    Ra, Rb = ranks[:n1].sum(), ranks[n1:].sum()
    U1 = Ra - n1 * (n1 + 1) / 2
    mu = n1 * n2 / 2
    t = np.unique(ranks, return_counts=True)[1]
    s = np.sqrt(n1 * n2 / 12 * ((N + 1) - (t ** 3 - t).sum() / (N * (N - 1))))
    z = max(abs(U1 - mu) - 0.5, 0) / s
    p = stats.mannwhitneyu(a, b, alternative="two-sided", method="asymptotic").pvalue
    return {"U": U1, "z": z, "p": p, "rank_sum_a": Ra, "rank_sum_b": Rb,
            "prob_a_gt_b": U1 / (n1 * n2)}


df = pd.read_csv("agentlab/data/csv/s2_stick_replace.csv")
before = df.loc[df.phase == "before", "dx_metric_um"].to_numpy()
after = df.loc[df.phase == "after", "dx_metric_um"].to_numpy()

w = stats.ttest_ind(after, before, equal_var=False)
f = variance_ratio_test(before, after)
lev = levene_test(before, after, center="median")
levm = levene_test(before, after, center="mean")
mw = mannwhitney(before, after)
assert abs(lev["p"] - stats.levene(before, after, center="median").pvalue) < 1e-12

print(f"평균 {before.mean():.3f} -> {after.mean():.3f}  표준편차 {before.std(ddof=1):.3f} -> {after.std(ddof=1):.3f}")
print(f"웰치 t={w.statistic:.3f} p={w.pvalue:.4g}")
print(f"맨-휘트니 U={mw['U']:.1f} z={mw['z']:.3f} p={mw['p']:.4g}")
print(f"분산비 F={f['F']:.3f} p={f['p']:.4g}")
print(f"레빈(중앙값) W={lev['W']:.3f} p={lev['p']:.4g}   레빈(평균) W={levm['W']:.3f} p={levm['p']:.4g}")
same = "차이 없음" if w.pvalue >= 0.05 else "차이 있음"
disp = "줄었다" if lev["p"] < 0.05 and after.std(ddof=1) < before.std(ddof=1) else "차이 확인 안 됨"
print(f"보고: 평균은 {same}, 산포는 교체 후 {disp} (레빈 p={lev['p']:.3g}).")

이 분석을 에이전트가 자동으로 하려면 현장에서 남겨야 할 것

    
    
      
  • 스틱 교체 이력: 마스크 ID, 교체한 스틱 번호, 교체 일시, 교체 사유(어떤 PPA 패턴을 보고 불량으로 판정했는지), 재장착 후 첫 유리 번호.

    • 
      
  • 유리마다 처리 순번(턴 안 위치)과 챔버 온도: 교체 전후를 같은 조건으로 맞춰 비교하는 데 필요합니다.

  • 측정 장비와 측정 반복성(같은 유리를 다시 쟀을 때의 흔들림): 산포 감소가 측정이 안정된 덕분인지 구분할 수 있습니다.

11에이전트 도구 상자

  

    
이 실험실이 남기는 검증된 함수

    
    
      
  • levene_test(a, b, center='median') -> {W, df1, df2, p, center, z_mean_a, z_mean_b} — 두 집단의 산포를 비교합니다. 각 값이 자기 집단 중심에서 떨어진 거리를 만들어 그 평균을 분산분석 F 로 비교합니다. 기본이 중앙값(브라운-포사이스)이고 center='mean' 이 원래 레빈입니다. scipy 의 stats.levene 와 같은 값을 냅니다.
    • 
      
  • mannwhitney(a, b) -> {U, z, p, rank_sum_a, rank_sum_b, prob_a_gt_b} — 순위로 위치를 비교합니다. 양측 정규 근사에 연속성 보정과 동점 보정을 넣었고 U 는 a 쪽 값입니다. 산포 변화는 보지 못하므로 산포 검정과 짝으로 씁니다.
    • 
      
  • variance_ratio_test(a, b) -> {F, df1, df2, p} — 분산비 F검정. 정규성에 민감하므로 에이전트는 기본으로 쓰지 않고 레빈 결과의 참고로만 붙입니다.
    • 
      
  • 검정 선택 규칙 한 줄: 산포를 묻는 질문이면 레빈(중앙값)을 기본으로, 위치를 확인할 때는 웰치 t와 맨-휘트니를 함께 돌려 결론이 같은지 봅니다.
    • 
    

  






  
12다음으로: 같은 마스크의 전후는 짝이다

  
이 실험실의 교체 전 20장과 교체 후 20장은 서로 다른 유리였습니다. 그런데 리페어 전후처럼 같은 마스크의 같은 77개 점을 전후로 다시 재면 점마다 원래 다른 몫(위치마다 크기가 다른 오차)을 지우고 변화분만 비교할 수 있습니다. 같은 대상을 전후로 짝지어 비교하는 것을 대응 비교라고 하며, 같은 자료에서 p값이 훨씬 작아집니다. 다음 실험실 0103 은 이것과 “나빠지지 않았음”을 증명하는 법을 다룹니다.
