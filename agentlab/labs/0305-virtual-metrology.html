가상 계측: FDC로 PPA 예측

재지 않은 유리의 배율을 FDC 로 미리 맞히고, 그 실력을 나중 시점의 유리로 재는 법

← 실험실 목록← 이전: 보정할까 리페어할까

PPA 를 재지 않은 유리의 장변 배율 Mx 는 FDC 로 미리 맞힐 수 있고(가상 계측), 그 모델의 실력은 학습에 쓴 유리가 아니라 나중 시점의 유리(시간순 시험 구간)로 재야 합니다. 이 가상 라인에서는 0303 의 직선 모델이 회귀 트리보다 낫고(5절), 예측으로 순위를 매겨 위험한 유리부터 재면 같은 측정 장 수로 한계를 넘은 유리를 훨씬 더 잡으며(6절), 온도 센서 교정이 바뀌면 모델이 조용히 틀려지므로 예측 오차를 감시 차트로 지켜야 합니다(7절).

시작하기 전에

이미 아시는 것 — 0303의 다중 회귀(마스크별 절편 + 온도 + 턴)와 열변형·턴 기울기, 0302의 유리마다 77점에서 뽑는 계수 M̂x, 0204의 EWMA(λ·L·ARL), 0205의 ‘섞어 나누면 낙관 편향이 생긴다’와 시간순 분할, ADP 0013의 과적합과 교차검증(같은 생각을 여기서는 시간 순서로 합니다).

  • 다중 회귀 · 마스크별 절편 (0303)
  • 계수 표 M̂x (0302)
  • EWMA 감시 (0204)
  • 섞어 나누기의 낙관 편향 · 시간순 분할 (0205)
  • 과적합 · 교차검증 (ADP 0013)

새로 이름을 붙이는 낱말은 여섯 개입니다. 쓰이는 자리에서 하나씩 정의하고, 정의한 뜻 그대로만 씁니다. 이 여섯 개 말고 계산에 붙인 이름(RMSE · 학습·검증 구간 · 기준과 한계 · 포착률 · 예측 오차)은 쓰는 자리에서 문장이나 식으로 정의합니다.

  • 가상 계측 (virtual metrology)
  • 특징 (feature)
  • 시간순 시험 구간 (time-ordered test set)
  • 회귀 트리 (regression tree)
  • 외삽 (extrapolation)
  • 모델 드리프트 (model drift)

이 실험실에서 가져가는 것

  1. 실무에서 쓰는 곳 — PPA 는 턴마다 몇 장만 재므로, 재지 않은 유리의 배율을 FDC 로 미리 맞혀 위험한 유리를 먼저 재게 하는 일(2~6절).
  2. 손으로 연습 — 특징을 넣고 빼며 학습 오차와 시험 오차가 따로 움직이는 것을 보고(4절), 트리 깊이를 올리며 과적합과 외삽을 보고(5절), 먼저 잴 비율과 한계를 옮기며 포착률을 보고(6절), 센서 교정 변화의 크기를 옮기며 감시 차트가 알람을 내는 시점을 봅니다(7절).
  3. 다음 날 산출물 — make_features·time_split·fit_vm·vm_rmse·priority_capture·vm_monitor Python 함수(10절)와 가상 계측 모델 기록지(11절).
  4. 기록할 데이터 — 예측값과 그 뒤 실제 측정을 같은 유리 번호로, 센서 교정·교체 이력, 모델을 바꾼 날(11절).
  5. 사람·규칙·에이전트의 몫 — 모델 승인과 센서 변경 공지는 사람, 감시 알람과 재학습 조건은 규칙, 특징 만들기·학습·보고 초안은 에이전트(8절).
  6. 성과 환산 — 같은 측정 장 수로 더 잡는 한계 초과 유리와 줄어드는 흘려보냄(9절).
[문제] 마스크 장이 턴 동안 증착한 기록입니다. PPA 는 마스크마다 한 턴에 장(턴 안 번째 유리)만 재므로 잰 유리는 장이고, 마스크 한 장이 한 턴에 증착하는 유리는 장이라 나머지는 PPA 를 재지 않습니다. 유리마다 FDC 에는 챔버 온도 센서 표시값·턴·턴 안 순번·증착률·챔버 압력이 있습니다.
(1) 이 FDC 로 재지 않은 유리의 장변 배율 Mx 를 맞히는 모델을 만들고, 그 실력을 숫자 하나로 보고하십시오. (2) 직선과 트리 가운데 무엇을 씁니까. (3) 예측으로 순위를 매겨 한계를 넘었을 법한 유리부터 재면, 같은 측정 장 수로 한계를 넘은 유리를 얼마나 더 잡습니까. (4) 온도 센서 교정이 바뀌어도 이 모델을 계속 믿어도 됩니까. 바뀐 것은 어떻게 압니까.

한계는 6절에서 가정으로 정하고, 센서 교정 변화는 이 가상 라인에 일어나는 사건입니다(7절). 2~7절에서 숫자를 만들고 8절에서 이 네 물음으로 돌아옵니다.

여기서부터 위 기록을 이용한 풀이입니다

1손에 쥔 것 — 유리 장의 FDC 열과 측정 M̂x

표 한 줄이 유리 한 장입니다. 맞히려는 값은 M̂x(0302의 방법으로 그 유리의 77점에서 뽑은 장변 배율, ppm)이고, 나머지 열이 FDC 에서 온 정보입니다. 아래 범위는 이 표에서 센 값입니다.

실제 줄을 몇 개 보면 이렇습니다(마스크 ).

이 가상 라인에는 약속이 둘 있습니다. 증착률은 Mx 와 무관하게 정해졌고, 압력은 챔버 온도와 같이 움직이도록(상관 ) 정해졌지만 Mx 에 직접 작용하지는 않습니다. 현장에는 이런 정답이 없으니, 어느 열이 일을 하는지는 4절에서 시험 오차로 가립니다. 센서 교정 판 cal_ver 는 7절에서 씁니다. 2~6절은 교정 변화가 없던 표시값으로 계산합니다.

2첫 시도 — 전부 맞추고 같은 자료로 오차 재기

0303 의 모델 판(Mx = 마스크별 절편 + 열변형 기울기 × (온도 − ) + 턴 기울기 × 턴)을 유리 장 전부에 맞추고, 같은 장에서 오차를 재 보겠습니다. 오차는 RMSE(root mean squared error)로 잽니다. 유리마다 (측정 − 예측)을 제곱해 평균하고 제곱근을 씌운 값이며 단위는 ppm 입니다.

RMSE (유리 n장) RMSE=1n∑i=1n(yi−y^i)2 yi 는 유리 i 의 측정 M̂x, ŷi 는 그 유리의 예측입니다. 작을수록 잘 맞힌 것입니다.
측정 M̂x 대 예측 (전 자료로 맞추고, 같은 자료로 잼)
무엇을 볼지 먼저. 점이 대각선(예측 = 측정)에 얼마나 붙는지 보십시오. 대각선에서 먼 점이 거의 없으면 모델이 잘 맞는 것처럼 보입니다.

측정 M̂x 의 표준편차가 ppm 인데 RMSE 는 ppm 이니 매우 잘 맞는 것처럼 보입니다. 그런데 이 모델이 쓰일 곳은 다음 주에 증착할 유리입니다. 이 숫자가 그 유리의 오차일까요. 무작위로 70%로만 맞추고 나머지 30%로 재는 방법(섞어 나누기: 표의 행 번호를 10 으로 나눈 나머지가 0~6 이면 학습, 7~9 이면 시험)도 해 보겠습니다.

여기서 막힙니다. 두 숫자는 모두 ‘학습에 쓴 유리와 같은 턴·같은 마스크의 이웃 유리’를 시험으로 쓴 값입니다. 다음 주 유리는 이웃이 아니라 더 뒤의 시점이고, 그 사이에 챔버는 더 따뜻해져 있습니다. 어느 숫자가 진짜 실력인지 가르려면 ‘무엇을 학습으로 쓰고 무엇을 시험으로 쓸지’에 이름과 규칙이 필요합니다. 3절에서 이름을 붙입니다.

3이름 — 가상 계측, 특징, 시간순 시험 구간

  • 가상 계측 (virtual metrology) — PPA 를 재지 않은 유리의 계측값(여기서는 Mx)을 공정 데이터(FDC)로 예측하는 일입니다. 2절의 모델이 이미 그것입니다.
  • 특징 (feature) — 모델에 넣는 입력 한 칸입니다. 지금까지는 온도(fdc_temp)·턴·마스크 번호(절편)가 특징이었고, 1절의 증착률·압력·턴 안 순번도 후보입니다.
  • 시간순 시험 구간 (time-ordered test set) — 학습에 쓴 시점보다 뒤의 유리만 모아 실력을 재는 구간입니다. 섞어서 나누면 같은 턴 이웃 유리의 정보가 학습에 새어 들어 실력이 부풀려질 수 있습니다(0205의 낙관 편향).

이 자료를 시간순으로 세 구간으로 나눕니다. 학습 구간(턴 )은 모델을 맞추는 데, 검증 구간(턴 )은 5절에서 트리 깊이를 고르는 데, 시험 구간(턴 )은 실력을 한 번 재는 데 씁니다. 시험 구간 유리는 마지막까지 모델이 본 적이 없습니다.

턴 축 위의 학습 · 검증 · 시험 구간과 FDC 온도
무엇을 볼지 먼저. 1) 턴이 갈수록 FDC 온도(한 턴 안 유리들의 최소~최대 띠와 평균)가 어떻게 달라지는지 보십시오. 2) 시험 구간의 온도가 학습 구간의 최대(점선)를 넘는 곳을 찾으십시오. 3) 이 그림의 모든 구간 값은 아래 표로 이어집니다.

시드 분포를 계산하고 있습니다…

직선 모델에서는 세 값이 거의 같습니다. 직선에는 이웃 유리에서 외울 것이 없기 때문입니다. 5절의 회귀 트리에서는 이 차이가 크게 벌어집니다. 먼저 4절에서 어떤 특징을 넣을지 가려 보겠습니다.

4특징 넣고 빼기 — 학습 오차는 늘 줄고, 시험 오차는 그렇지 않다

후보 특징은 여섯입니다. 온도·턴·턴 안 순번·증착률·압력, 그리고 마스크별 절편. 아래에서 켜고 끄며 학습·검증·시험 RMSE 를 봅니다. 모델은 모두 직선(M̂x = 절편 + 고른 특징 × 기울기)이고 학습 구간 턴 에만 맞춥니다.

특징을 골라 직선 모델 맞추기
무엇을 볼지 먼저. 1) 특징을 하나 넣을 때 학습 RMSE 가 늘 줄거나 같은지, 시험 RMSE 도 그런지 보십시오. 2) 증착률이나 압력을 넣으면 시험 RMSE 가 얼마나 달라지는지 보십시오. 3) 온도를 빼고 압력이나 턴 안 순번을 넣으면 그 특징이 온도 대신 일을 하는 듯 보이는지, 그래도 온도만큼 맞는지 보십시오.

같은 비교를 미리 계산해 둔 조합으로 나란히 놓으면 이렇습니다(모두 학습 구간에만 맞춘 직선).

아닙니다. 학습 RMSE 는 특징을 넣을수록 늘 줄지만, 시험 RMSE 는 일하는 특징일 때만 줄고 일하지 않는 특징은 거의 바꾸지 못합니다. 이 라인에서 증착률을 더하면 학습 RMSE 가 → , 시험 RMSE 가 → ppm 으로 변합니다.

상관이 있는 특징은 서로 일을 나눠 갖습니다. 온도를 뺀 모델(턴 + 마스크별 절편)의 시험 RMSE ppm 은 압력을 넣으면 , 턴 안 순번을 넣으면 로 줄지만, 온도를 넣은 에는 못 미칩니다. 압력과 턴 안 순번이 줄이는 것은 이 둘이 온도와 같이 움직이기 때문이지 열변형을 직접 설명해서가 아닙니다(0303의 교란과 같은 원리). 특징은 많이 넣는 것이 아니라, 시험 구간에서 오차를 줄이는 것만 남기는 것입니다.

5회귀 트리와 외삽 — 가정 없는 모델은 어디서 무너지나

직선 모델에는 ‘온도와 턴이 배율에 직선으로 작용한다’는 가정이 들어 있습니다. 이 가정을 두지 않는 모델을 견주어 볼 필요가 있습니다. 가장 쉬운 것이 회귀 트리입니다.

  • 회귀 트리 (regression tree) — 특징 하나의 문턱값으로 유리를 둘로 나누기를 되풀이하고, 마지막 칸(잎)마다 그 칸 유리의 M̂x 평균을 예측값으로 쓰는 모델입니다. 나누는 횟수의 상한이 깊이(depth)입니다. 문턱은 정렬된 서로 다른 값의 중점 가운데 두 칸의 제곱오차 합을 가장 줄이는 것을 고르고, 한 칸에 유리가 장보다 적게 남는 나누기는 하지 않습니다. 특징은 온도·턴·턴 안 순번·증착률·압력·마스크 번호(정수)입니다.
  • 외삽 (extrapolation) — 학습에 없던 범위의 입력으로 예측하는 것입니다. 직선은 기울기를 이어 가고 트리는 가장자리 칸의 평균에 머뭅니다.

트리의 깊이를 키울수록 학습 RMSE 는 줄어듭니다. 검증 구간(턴 )으로 어디까지가 유익한지 고릅니다.

깊이를 옮기며 트리 보기
무엇을 볼지 먼저. 1) 깊이를 올릴 때 학습·검증·시험 RMSE 곡선이 서로 어떻게 벌어지는지 보십시오. 2) 오른쪽 그림에서 시험 구간의 따뜻한 유리(붉은 점선 오른쪽)에서 트리의 예측(주황 점)이 직선(청록선)과 어떻게 갈라지는지 보십시오. 3) 시험 RMSE 가 직선(점선 가로선)보다 낮아지는 깊이가 있는지 보십시오.

같은 트리로 2~3절의 세 가지 방식을 다시 재 보겠습니다. 직선에서는 거의 같았던 숫자가 트리에서는 어떻게 되는지 보십시오.

마지막으로 시험 유리를 학습 구간의 온도 범위(~ °C) 안과 밖으로 나눠 외삽 오차를 봅니다. 오차는 (측정 − 예측)의 평균이며 0 에서 멀수록 한쪽으로 치우친 것입니다.

정직하게 말하면 이 가상 공정은 배율이 온도와 턴에 직선이라 직선이 이기기 쉽습니다. 트리는 비선형이나 특징끼리의 상호작용이 있을 때 쓰는 도구이고, 이 자료에서 트리가 진 것은 ‘트리가 나쁘다’가 아니라 ‘이 공정에는 직선이 맞다’는 뜻입니다. 현장 공정이 직선인지는 직선 모델의 시험 오차가 충분히 작은지로 확인합니다. 또 검증 RMSE 가 가장 낮은 깊이가 이 표의 상한()에 닿아 있으므로, 상한을 더 올리면 더 줄어드는지는 이 표로는 알 수 없습니다.

아닙니다. 물리가 직선에 가까우면 직선이 이기고, 트리 계열은 학습 범위 밖에서 약합니다. 이 라인의 시험 RMSE 는 직선 ppm, 트리(깊이 ) ppm 입니다.

랜덤 포레스트는 트리 여러 개의 평균이라 한 트리보다 흔들림은 줄지만, 칸마다 평균을 쓰는 점은 같아서 학습 범위 밖에서는 가장자리 평균에 머뭅니다. 먼저 직선으로 시험 오차를 재고, 직선이 모자랄 때(비선형·상호작용) 트리 계열을 견줍니다.

같은 턴의 이웃 유리가 학습과 시험에 함께 들어가, 모델이 이웃을 외운 만큼 실력이 부풀려지기 때문입니다. 이 라인에서 트리(깊이 )의 섞어 나눈 시험 RMSE 는 ppm, 시간순 시험 RMSE 는 ppm 이어서 비가 입니다. 직선은 이 비가 로 거의 1 입니다.

다음 주 유리는 학습에 쓴 유리의 이웃이 아니므로, 실제 쓸 방식과 같은 시간순 시험 구간으로 재야 합니다.

6측정 우선순위 — 위험한 유리부터 재기

재지 않은 유리가 많으니 측정할 자리를 어떻게 고르느냐가 가상 계측의 쓸모입니다. 예측으로 유리마다 ‘그 마스크의 기준에서 얼마나 멀어졌을 것 같은가’를 매기고, 큰 순서로 먼저 재는 것입니다. 세 가지를 정의합니다.

  • 기준 — 마스크마다 턴 1 의 유리 6장 M̂x 평균입니다(0303의 기준선과 같은 약속).
  • 한계를 넘은 유리 — |측정 M̂x − 기준| 이 한계보다 큰 유리입니다. 한계는 현장 기준으로 바꿔야 할 가정이며, 0303의 0.3 ppm 은 턴 평균의 변화에 적용한 값이어서 유리 한 장(턴 안 온도 상승만으로 Mx 가 ppm 정도 움직임)에는 따로 정해야 합니다.
  • 포착률 — 한계를 넘은 유리 가운데 먼저 잰 유리에 들어간 비율입니다. 먼저 재는 장 수가 같을 때 우선순위로 고른 것과 무작위로 고른 것을 견줍니다. 무작위로 고르면 기대 포착률은 먼저 재는 비율 그대로입니다.

시험 구간의 유리 장을 ‘아직 재지 않은 유리 더미’로 보고, 직선 모델의 예측 |예측 − 기준| 이 큰 순서로 상위 q% 만 잰다고 하겠습니다.

먼저 잴 비율과 한계를 옮기며 포착률 보기
무엇을 볼지 먼저. 1) 먼저 잴 비율 q 를 올릴수록 우선순위 포착률이 무작위(대각선)와 얼마나 벌어지는지 보십시오. 2) 한계를 낮추면 한계를 넘은 유리가 많아져 곡선이 어떻게 달라지는지 보십시오. 3) 완벽한 순서(점선)에 못 미치는 몫이 어디서 생기는지 생각해 보십시오.
예측 순위로 먼저 잼무작위로 잼(기대)완벽한 순서세로 선: 지금의 q

순위가 얼마나 잘 맞는가는 모델의 시험 오차에 달려 있습니다. 예측이 틀리면 순위가 흩어지고 포착률이 무작위(대각선)에 가까워집니다. 이 숫자를 성과 환산으로 잇는 것이 9절입니다.

7모델 드리프트 — 센서 교정이 바뀌면 모델이 조용히 틀린다

  • 모델 드리프트 (model drift) — 공정이나 센서가 바뀌어 예측 오차의 평균이나 크기가 학습 때와 달라지는 것입니다. 예측 오차는 (측정 − 예측)이며, 측정한 유리에서만 알 수 있습니다.

이 라인에는 턴 부터 챔버 온도 센서의 표시값이 K 높아지는 사건이 있습니다(참 온도는 그대로이므로 Mx 는 그대로입니다). 모델은 표시값을 쓰므로 예측이 (열변형 기울기) × (표시값이 어긋난 만큼) 만큼 틀어집니다. 표시값만 보면 알아차리기 어려우니 예측 오차를 0204 의 EWMA 로 감시합니다.

예측 오차의 EWMA 감시 (직선 모델, 턴 이후의 잰 유리를 시간순으로) et=yt−y^t,zt=et−e¯s,wt=λzt+(1−λ)wt−1 |wt|>Lλ2−λ⇒알람 ē·s 는 검증 구간(턴 )의 예측 오차 평균·표준편차(· ppm), λ = , L = (0204 에서 λ 가 이 값일 때 변화가 없어도 평균 370장에 한 번 알람이 나는 한계). 변화 전에 난 알람은 헛알람으로 세고, 통계량을 0 으로 되돌립니다.
센서 교정 변화의 크기를 옮기며 감시 차트 보기
무엇을 볼지 먼저. 1) 교정 변화 δ 를 올리면 교정 변화 뒤의 예측 오차(위 그림 파란 점)가 얼마나 위로 올라가는지 보십시오. 2) 아래 EWMA 선이 한계선을 넘는 시점이 δ 에 따라 어떻게 달라지는지 보십시오. 3) δ 를 거의 0 으로 내리면 알람이 늦어지고 헛알람과 구별되지 않는 것을 보십시오.

알람이 나면 규칙은 두 가지 일을 합니다. 센서 교정 이력(날짜·전후 값)이 있으면 표시값을 되돌려 쓰고, 이력이 없으면 새 센서 판으로 모델을 다시 맞춥니다. 위 표의 ‘교정 이력으로 되돌린 표시값의 시험 RMSE’가 이력이 있을 때 얻는 것입니다.

아닙니다. 예측 오차는 잰 유리에서만 알 수 있어서, 측정을 0 으로 줄이면 모델이 틀려져도 알 방법이 없어집니다. 이 라인에서 교정 변화( K)가 일어난 뒤 모델의 시험 RMSE 는 ppm 에서 ppm 으로 올라갔고, 이것을 알아차린 것은 잰 유리의 예측 오차였습니다.

측정은 줄일 수 있어도 0 으로 만들 수는 없습니다. 가상 계측이 하는 일은 ‘어느 유리를 먼저 잴지’를 고르는 것이지, 재는 일을 대신하는 것이 아닙니다. 잰 유리의 수가 줄수록 같은 변화를 알아차리기까지 오래 걸린다는 점은 감시 설정(λ·L)과 함께 정해야 합니다.

9현장에서 환산하면

같은 측정 장 수로 한계를 넘은 유리를 더 잡는 수 = (우선순위 포착률 − 무작위 포착률) × 한계를 넘은 유리 수입니다. 놓친 유리 한 장이 다음 측정까지 흘려보내는 유리 수(가정)를 곱하면 줄어드는 흘려보냄이 됩니다. 6절의 q·한계가 그대로 반영됩니다.

우선순위로 재면 줄어드는 흘려보냄
무엇을 볼지 먼저. 1) 한계를 넘은 유리 수와 추가로 잡는 수를 함께 보십시오. 2) 한 장이 흘려보내는 유리 수를 바꿀 때 줄어드는 양이 어떻게 달라지는지 보십시오. 3) 6절에서 q·한계를 바꾸면 이 표가 함께 바뀌는 것을 오가며 보십시오. 차이가 작으면 작다고 적습니다.

회사에서는 같은 식에 ‘유리 한 장의 값’을 곱해 금액으로 적습니다. 이 화면의 유리 더미(장)는 이미 잰 유리를 ‘재지 않은 유리’로 가정한 것이므로, 현장에서는 실제 재지 않은 유리 수와 실제 한계로 바꿔 넣으십시오. 한 장이 흘려보내는 유리 수는 잰 유리 사이의 간격(이 자료는 턴 안 순번이 5·20·40·60·90·120번째라 간격이 15~30장)과 같은 크기로 잡았습니다.

10Python — 회사 PC에 가져갈 코드

아래 코드는 numpy·pandas·scikit-learn을 씁니다. 0303의 join_fdc_ppa로 만든 표(유리마다 FDC 열과 Mx_hat)가 입력이고, 코드와 같은 폴더의 vm_s13.csv로 그대로 돌아갑니다. 각 함수에 ‘쓰면 안 되는 때’를 한 줄씩 적었습니다. fit_vm 의 트리는 DecisionTreeRegressor(random_state=0, min_samples_leaf=5) 입니다. 트리는 같은 표본을 똑같이 가르는 두 특징이 동점일 때 어느 쪽을 고르는지가 난수 순서에 달려 있어, 다른 버전의 라이브러리에서는 뒷자리가 달라질 수 있습니다.

import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeRegressor

T_REF = 80.0                    # 기준 온도 (°C). 0303 과 같은 약속입니다.
CAL_TURN, CAL_SHIFT = 20, 0.3   # 센서 교정 이력: 턴 20 부터 표시값 +0.3 K (교정 기록에서 옮겨 적은 값 — 우리 장비의 이력으로 바꿔 쓰십시오)
LIMIT, Q = 1.5, 0.2             # 한계(ppm, 가정)와 먼저 잴 비율
LAM, L_EWMA = 0.2, 2.8599       # EWMA (0204 와 같은 설정: λ = 0.2 에서 변화가 없을 때 평균 370장에 한 번 알람이 나는 한계 L)
FEATURES = ["temp", "turn", "glass_in_turn", "dep_rate", "pressure", "mask"]   # 트리가 특징을 훑는 순서도 이 순서입니다


def make_features(df, cols, kind, masks, undo_cal=True):
    """특징 표를 만듭니다. cols 는 FEATURES 중에서 고른 이름. temp 는 센서 표시값이며 undo_cal=True 면 교정 이력(CAL_SHIFT)으로 교정 변화 전 판 기준으로 되돌린 값입니다.
    mask 는 직선(kind="linear")에서는 마스크별 더미(= 마스크별 절편), 트리(kind="tree")에서는 마스크 번호(정수)입니다.
    쓰면 안 되는 때: 교정 이력이 없는 구간의 표시값을 되돌릴 때(되돌릴 값을 모르면 되돌리지 말고 재학습) · 직선에 마스크 번호를 정수로 넣을 때(번호의 크기에 뜻이 없습니다)."""
    X = pd.DataFrame(index=df.index)
    for c in [c for c in FEATURES if c in cols]:
        if c == "temp":
            X["temp"] = df["fdc_temp"] - (CAL_SHIFT * df["cal_ver"] if undo_cal else 0.0)
        elif c == "mask" and kind == "linear":
            X = X.join(pd.get_dummies(pd.Categorical(df["mask_id"], categories=masks), dtype=float).set_index(df.index))
        elif c == "mask":
            X["mask"] = df["mask_id"].map({m: i for i, m in enumerate(masks)})
        else:
            X[c] = df[c]
    return X


def time_split(df, train_turns, valid_turns, test_turns):
    """시간순으로 학습·검증·시험 표를 나눕니다. 각 인자는 (처음 턴, 끝 턴).
    쓰면 안 되는 때: 시험 구간이 학습 구간보다 앞서거나 겹칠 때(미래 정보가 학습에 새어 들어갑니다)."""
    cut = lambda t: df[(df["turn"] >= t[0]) & (df["turn"] <= t[1])]
    return cut(train_turns), cut(valid_turns), cut(test_turns)


def fit_vm(train, cols, model, masks, depth=None):
    """가상 계측 모델을 학습 표에 맞춥니다. model = "linear"(마스크를 고르면 마스크별 절편만, 아니면 절편 하나) 또는 "tree"(깊이 depth, 한 칸에 유리 5장 이상).
    쓰면 안 되는 때: 학습 구간에 없던 온도 범위의 유리를 트리로 예측할 때(가장자리 칸의 평균에 머뭅니다) · 센서 교정이나 레시피가 바뀐 뒤 재학습 없이 쓸 때."""
    X = make_features(train, cols, model, masks)
    if model == "linear":
        est = LinearRegression(fit_intercept="mask" not in cols)
    else:
        est = DecisionTreeRegressor(max_depth=depth, min_samples_leaf=5, random_state=0)
    return {"est": est.fit(X, train["Mx_hat"]), "cols": cols, "kind": model, "masks": masks}


def vm_predict(m, data, undo_cal=True):
    return m["est"].predict(make_features(data, m["cols"], m["kind"], m["masks"], undo_cal))


def vm_rmse(m, data, undo_cal=True):
    """모델의 RMSE (ppm). 반드시 시간순 시험 표로 재십시오.
    쓰면 안 되는 때: 학습에 쓴 표로 재고 그 값을 실력으로 보고할 때."""
    return float(np.sqrt(np.mean((data["Mx_hat"] - vm_predict(m, data, undo_cal)) ** 2)))


def priority_capture(pred, actual, base, limit, q):
    """예측 |예측 − 기준| 이 큰 순서로 상위 q 만 잰다고 할 때, 한계(|실제 − 기준| > limit)를 넘은 유리를 잡는 비율과 무작위의 기대 포착률(= 재는 비율).
    쓰면 안 되는 때: 기준(base)을 시험 구간의 측정으로 정할 때(학습 구간까지의 값으로만 정합니다)."""
    pred, actual, base = map(np.asarray, (pred, actual, base))
    exceed = np.abs(actual - base) > limit
    m = int(np.floor(q * len(pred) + 0.5))
    first = np.argsort(-np.abs(pred - base), kind="stable")[:m]
    return exceed[first].sum() / exceed.sum(), m / len(pred), int(exceed.sum())


def vm_monitor(err, lam, L, ref_n, change_at):
    """예측 오차 err(시간순)를 앞 ref_n 개의 평균·표준편차로 표준화해 EWMA 로 감시합니다. change_at 번째 이전에 난 알람은 헛알람으로 세고 통계량을 0 으로 되돌립니다.
    쓰면 안 되는 때: 앞 ref_n 개가 이미 변화 뒤의 값을 포함할 때 · 측정한 유리가 거의 없어 err 가 비어 있을 때."""
    err = np.asarray(err, float)
    z = (err - err[:ref_n].mean()) / err[:ref_n].std(ddof=1)
    U, w, first, false = L * np.sqrt(lam / (2 - lam)), 0.0, None, 0
    for i, v in enumerate(z):
        w = lam * v + (1 - lam) * w
        if abs(w) > U:
            if i + 1 < change_at:
                false, w = false + 1, 0.0
            elif first is None:
                first = i + 1
    return first, false

예측을 남기지 않고 측정만 쌓으면 몇 달 뒤에 모델이 언제부터 틀렸는지 가릴 수 없습니다.
