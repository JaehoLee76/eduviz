작은 변화 감지

EWMA·CUSUM과 평균 런 길이 — 선이 맞게 그어져 있어도 얼마나 늦게 알려 주는가

← 실험실 목록← 이전: 3σ의 숨은 가정 셋다음: 가성 인터락을 줄이는 spec →

3σ 선은 유리 한 장만 보고 판단하므로, 1σ 정도의 작은 변화가 계속 이어져도 평균 장이 지나야 알아챕니다. 지난 값들을 모아 보는 EWMA와 CUSUM은 헛알람 간격(ARL0)을 똑같이 맞춘 채 그 지연을 평균 장·장으로 줄입니다. 대신 3σ 이상의 큰 변화에서는 3σ 선이 여전히 가장 빠릅니다. 이 실험실에서 두 방법을 직접 만들고, 맞는 값을 고르는 방법과 자기상관이 있을 때의 처방까지 손에 쥡니다. 이 실험실의 데이터는 학습용 가상 데이터입니다.

시작하기 전에

이미 아시는 것 — 평균·표준편차·z값(0101·0102), 3σ 관리선과 정상 값이 선을 넘을 확률(0201·0203), 여러 장을 평균하면 흔들림이 √n배 줄어든다는 표준오차(0101), 자기상관 φ와 실효 표본 수(0104), 헛알람과 놓침의 맞바꿈(0202), 잔차 관리도(0203).

  • 3σ 관리선

  • 자기상관 φ
  • 헛알람·놓침
  • 잔차 관리도

새로 이름을 붙이는 낱말은 다섯 개입니다. 쓰이는 자리에서 하나씩 정의하고, 정의한 뜻 그대로만 씁니다. 계산 방법의 이름(마르코프 사슬, 이분법, 몬테카를로)은 쓰는 자리에서 한 줄로 풀어 설명하는 도구이고, 위 다섯에 세지 않습니다. 위 다섯과 함께 쓰는 부속 낱말(런 길이·ARL0·ARL1·허용량 k·결정 구간 h·EWMA 한계의 폭 L)도 쓰는 자리에서 한 줄로 풉니다.

  • 평균 런 길이 ARL (average run length)
  • EWMA (지수가중 이동평균)
  • 평활 계수 λ (smoothing constant)
  • CUSUM (누적합)
  • 변화 시작점 추정 (change-point estimate)

이 실험실에서 가져가는 것

  1. 실무에서 쓰는 곳 — 소스 소모나 부품 교체 뒤에 증착 속도가 계단처럼 조금 내려앉아 그대로 머무는 경우. 3σ 선은 이런 변화를 한참 뒤에야 알립니다.
  2. 손으로 연습 — 슬라이더로 λ·k·변화 크기를 움직여 ARL을 직접 비교하고(2~6절), 4절 끝의 칸에 내 값을 붙여 넣어 감시해 봅니다.
  3. 다음 날 산출물 — ARL 계산 셋, 한계 맞춤 하나, 감시 둘로 이루어진 Python 함수 여섯 개(10절).
  4. 기록할 데이터 — 변화 사건 라벨(언제·왜·얼마나)과 알람 확인 결과(11절). 이것이 쌓여야 회사 데이터로 ARL1을 직접 재 볼 수 있습니다.
  5. 사람과 에이전트의 몫 — 잡을 최소 변화 δ*와 감내할 헛알람 간격은 사람이 정하고, 한계 맞춤·감시·변화 시작점 추정·보고는 에이전트가 맡습니다(7절).
  6. 성과 환산 — 변한 줄 모르고 흘려보내는 유리가 몇 장 줄어드는지 숫자로 봅니다(8절).

2한 장만 보는 선의 한계

1절의 장이 운이 나빴던 것인지부터 가려야 합니다. 변화가 시작된 뒤에는 유리 한 장이 선을 넘을 확률이 정상 때보다 커집니다. 그 확률을 p라 하면, 유리가 서로 독립일 때 첫 알람까지 걸리는 장수는 평균 1/p입니다. 이 평균에 이름을 붙입니다.

감시를 시작해 첫 알람이 날 때까지 지나간 유리 수를 런 길이 (run length), 그 평균을 평균 런 길이 ARL (average run length)이라 부릅니다. 정상일 때의 ARL을 ARL0(헛알람 사이의 평균 간격), 변화가 생긴 뒤의 ARL을 ARL1(변화를 알아채기까지의 평균 지연)이라 부릅니다.

3σ 선(양쪽)의 평균 런 길이 ARL=1p,p(δ)=Q(L−δ)+Q(L+δ) L은 선이 평균에서 떨어진 거리(σ의 배수, 지금까지는 3), δ는 평균이 이동한 크기(σ의 배수), Q(z) = 1 − Φ(z)는 표준정규분포에서 z보다 클 확률입니다. 선이 위·아래 두 개이므로 두 꼬리를 더합니다. δ = 0이면 정상 때의 확률 p₀이고 ARL0 = 1/p₀입니다.
선의 위치 L · 변화 크기 δ — 한 장만 보는 선의 ARL0과 ARL1

3EWMA — 최근 값에 큰 무게를 주는 평균

여러 장을 모으는 가장 쉬운 방법은 최근 n장의 평균을 보는 것입니다. 그런데 n을 몇으로 정할지 막막하고, n장 전의 값이 어느 순간 갑자기 계산에서 빠지면서 평균이 덜컥 움직입니다. 최근 값에는 큰 무게를, 오래된 값에는 서서히 줄어드는 무게를 주는 평균이면 두 문제가 모두 사라집니다. 이것이 EWMA (exponentially weighted moving average, 지수가중 이동평균)입니다. 이름 그대로 무게가 지수적으로 줄어듭니다.

이번 값에 주는 무게를 평활 계수 λ (smoothing constant)라 부르고 0 < λ ≤ 1 사이에서 고릅니다. λ = 1이면 이번 값만 쓰는 3σ 선과 똑같아지고, λ가 작을수록 더 오래 기억해 작은 변화에 민감해집니다. 아래 식의 zt = (xt − μ₀)/σ는 t번째 유리가 정상 평균에서 몇 σ 떨어졌는지입니다.

EWMA 값과 한계 ut=λzt+(1−λ)ut−1,u0=0 |ut|>Lλ2−λ⟹알람 정상일 때 u의 표준편차는 √(λ/(2−λ))입니다(λ=1이면 1, λ가 작을수록 여러 장을 평균한 것처럼 작아집니다). 이유는 이렇습니다. u는 지난 z들의 가중합이고 무게는 λ, λ(1−λ), λ(1−λ)², …이며, 정상일 때 z들은 서로 독립이고 분산이 1입니다. 독립인 값의 가중합의 분산은 무게를 제곱해 더한 값이므로 λ² ÷ (1−(1−λ)²) = λ/(2−λ)입니다(여러 장이 쌓인 뒤의 값). L은 그 표준편차의 몇 배 위치에 한계를 둘지입니다.

L은 얼마로 둘까요? 3으로 두면 λ마다 정상 때 헛알람 간격이 달라져 방법끼리 공정하게 견줄 수 없습니다. 그래서 세 방식 모두 정상 때 ARL0 = (3σ 선 양쪽의 헛알람 간격)로 맞춥니다. L은 슬라이더로 정하는 값이 아니라 λ가 정해지면 이 약속에서 자동으로 나옵니다.

ARL과 L은 어떻게 계산하나

EWMA 값 u가 한계 안에 있는 범위를 101칸으로 나눕니다. 한 장이 지날 때 각 칸에서 어느 칸으로(또는 한계 밖으로) 옮겨 가는지 확률을 구하면, 칸마다 “첫 알람까지 평균 몇 장”이라는 값이 연립방정식으로 묶입니다(마르코프 사슬 근사). 시작 칸(u = 0)의 값이 ARL입니다. L은 이 ARL0이 가 될 때까지 구간을 반씩 줄여 가며 찾습니다(이분법). EWMA와 CUSUM의 ARL은 이렇게 계산하며, 3σ 선의 ARL은 2절의 식 1/p로 구합니다.

평활 계수 λ · 변화 크기 δ — EWMA의 한계와 반응
이렇게 해 보세요. λ를 1까지 올려 보십시오. L이 3.000이 되고 EWMA 값이 3σ 선과 같은 점으로 바뀝니다. 다시 λ를 0.05까지 내리면 L이 작아지며 EWMA 선이 부드러워지고 ARL1이 줄어드는 것을 볼 수 있습니다. δ를 0으로 두면 변화가 없는 정상 궤적이라 알람이 없거나 드물게 헛알람이 보입니다.

4CUSUM — 벗어난 양을 쌓아 두는 합

EWMA는 오래된 값을 서서히 잊습니다. 그래서 “정상에서 벗어난 양이 얼마나 쌓였는가” 자체는 보지 않고, 알람이 났을 때 변화가 언제 시작했는지도 말해 주지 못합니다. 벗어난 양을 아예 쌓아 두면 두 가지가 모두 보입니다. 이것이 CUSUM (cumulative sum, 누적합)입니다.

유리마다 정상에서 벗어난 양을 더해 가되, 매번 허용량 k를 빼고 0 아래로는 내려가지 않게 합니다. 합이 결정 구간 h를 넘으면 알람입니다. 평균이 내려가는 변화를 보는 합 S−와 올라가는 변화를 보는 합 S+ 둘을 함께 둡니다.

CUSUM의 두 합과 알람 St−=max(0,St−1−−zt−k) St+=max(0,St−1++zt−k) S₀ = 0에서 시작하고, S− 또는 S+가 h를 넘으면 알람입니다.

k의 뜻은 이렇습니다. 정상일 때 z의 평균은 0이므로 매번 k를 빼면 합이 0 쪽으로 돌아옵니다. 반대로 평균이 δ* 내려앉았다면 한 장마다 δ* − k만큼 쌓입니다. 그래서 k는 잡고 싶은 최소 변화 δ*의 절반으로 정합니다(k = 0.5이면 δ* = 1σ). 절반인 까닭은 양쪽의 균형입니다. k를 δ*보다 훨씬 작게 잡으면 정상 때 0 쪽으로 돌아가는 힘이 약해져, 같은 ARL0에 맞추려면 h가 커지고 알람이 늦어집니다. k를 크게 잡으면 δ* 변화에서 한 장마다 쌓이는 양 δ*−k가 줄어듭니다. 절반에서는 정상 때 되돌아가는 양과 변화 때 쌓이는 양이 같은 크기(δ*/2)이고, 통계학에서 “정상이냐 δ* 이동이냐”를 가장 잘 가르는 누적 점수가 정확히 이 꼴이기도 합니다. 아래 슬라이더에서 k를 움직여 확인해 보십시오. h는 k가 정해지면 EWMA의 L처럼 정상 때 ARL0이 가 되도록 자동으로 나옵니다.

알람이 났을 때 합이 마지막으로 0이었던 바로 다음 유리가 변화가 시작된 자리의 추정입니다. 이것을 변화 시작점 추정 (change-point estimate)이라 부릅니다. 그 지점부터 합이 계속 올라갔기 때문입니다.

허용량 k · 변화 크기 δ — CUSUM의 합과 변화 시작점 추정
이렇게 해 보세요. k를 0.5로 두고 δ를 0.5·1·2로 바꿔 보십시오. 변화 시작점 추정(초록 점선 세로선)이 실제 시작에 얼마나 가까운지 보입니다. 다음에 k를 1.5까지 올리면 δ = 1의 변화를 거의 놓치고, 0.1까지 내리면 h가 커지면서 큰 변화도 천천히 알립니다.

CUSUM과 EWMA는 유리가 한 장 올 때마다 판정합니다. 변화가 시작되었는지를 기다리지 않고 실시간으로 감시하는 데 쓰고, 알람이 난 뒤에 변화가 있었는지를 확정하거나 크기를 재는 일에는 0101의 전후 비교를 씁니다. 둘은 경쟁이 아니라 앞뒤 단계입니다.

6자기상관이 있으면 — 0203의 숙제

0203의 잔차 관리도는 이웃 유리가 닮은 값(자기상관)의 헛알람을 약속값으로 되돌렸지만, 작은 변화가 오래 이어질 때는 잔차가 다시 잦아들어 놓칠 수 있다고 했습니다. 그 장면을 다시 보고, 잔차에 CUSUM을 쓰면 잡히는지 확인합니다.

이웃과의 닮은 정도 φ인 값의 평균이 한 번에 −δ 내려앉으면 잔차(직전 값으로 예측한 값과의 차이)는 이렇게 움직입니다. 아래 슬라이더가 가리키는 φ에서는 변화 직후 한 장에서 잔차 표준편차의 배만큼 크게 튀고, 그다음부터는 예측이 새 평균에 맞춰지면서 배만큼만 계속 밀립니다. 일회성 큰 튐은 잔차의 3σ 선이 잡을 수 있지만, 못 잡으면 남는 것은 작은 지속 변화입니다. 그런 변화를 잡는 방법이 위 4절의 CUSUM이며, 이번에는 원값이 아니라 잔차에 씁니다. 이때 k는 잔차에 남은 지속 변화 크기의 절반으로 정합니다. 남는 크기는 이렇게 나옵니다. 잔차는 (이번 값 − 평균) − φ(직전 값 − 평균)인데, 변화가 자리 잡은 뒤에는 두 값이 모두 δ만큼 내려가 있으므로 −δ + φδ = −(1−φ)δ가 남습니다. 이 값을 잔차 표준편차의 몇 배인지로 바꾸어 쓰므로, 코드의 k_res는 원값 표준편차 단위의 최소 변화에 (1−φ)를 곱하고 잔차 표준편차(sdr)로 나눈 것의 절반입니다.

10Python — 회사 PC에 가져갈 코드

아래 코드는 numpy, scipy만 씁니다. 함수 여섯 개(ARL 계산 셋, 한계 맞춤 하나, 감시 둘)가 이 실험실의 도구입니다. 감시 함수는 부를 때마다 EWMA 값과 CUSUM 합을 0에서 시작합니다. 그래서 알람이 나고 설비를 확인해 재가동한 뒤에는 그다음 유리부터의 값을 새로 잘라 함수를 다시 부르면 되고, 그 호출이 곧 통계량의 초기화입니다. 설비 조치로 정상 평균이 바뀌었으면 mu0도 새 기준으로 넣습니다. 가상 데이터를 파일로 받으려면 단추를 누르십시오. 받은 파일 s8_small_shift.csv를 코드와 같은 폴더에 두면 맨 아래 부분이 그대로 돌아갑니다. 파일의 truth_flag 열은 가상 데이터의 정답 표시(변화 뒤 유리 = 1)이며, 현장 데이터에는 없습니다.

import csv
import numpy as np
from scipy.stats import norm

MU0, SD0 = 1.000, 0.010          # 정상일 때의 평균과 표준편차 (이 실험실에서는 이미 안다고 놓습니다)
TARGET = 1 / (2 * norm.sf(3))    # 약속하는 정상 때 평균 런 길이: 3σ 선 양쪽의 헛알람 간격 370.4


def arl_shewhart(delta, L=3.0):
    """3σ 선(양쪽)의 평균 런 길이 = 1/p. 쓰면 안 되는 때: 유리끼리 닮았거나(자기상관) 값이 종 모양이 아닐 때(0203)."""
    return 1 / (norm.sf(L - delta) + norm.sf(L + delta))


def arl_ewma(lam, L, delta, m=101):
    """EWMA(양쪽 한계)의 평균 런 길이. 한계 안쪽을 m칸으로 나눠 칸 사이 이동 확률로 푼다.
    쓰면 안 되는 때: 자기상관이 있을 때(잔차에 쓸 것), μ0·σ 를 적은 기준에서 추정했을 때(ARL0 이 약속과 달라진다)."""
    U = L * np.sqrt(lam / (2 - lam))
    w = 2 * U / m
    e = -U + w * np.arange(m + 1)
    c = (e[:-1] + e[1:]) / 2
    z = (e[None, :] - (1 - lam) * c[:, None]) / lam - delta
    P = np.diff(norm.cdf(z), axis=1)
    return np.linalg.solve(np.eye(m) - P, np.ones(m))[m // 2]


def _cusum_one_side(k, h, delta, m):
    w = 2 * h / (2 * m - 1)
    s = w * np.arange(m)
    lo = s - w / 2
    lo[0] = -np.inf
    P = norm.cdf(s[None, :] + w / 2 - s[:, None] + k - delta) - norm.cdf(lo[None, :] - s[:, None] + k - delta)
    return np.linalg.solve(np.eye(m) - P, np.ones(m))[0]


def arl_cusum(k, h, delta, m=100):
    """CUSUM(양쪽)의 평균 런 길이 = 위쪽과 아래쪽 한쪽 ARL 의 역수를 더해 합친 값.
    쓰면 안 되는 때: 자기상관이 있을 때(잔차에 쓸 것), k 를 잡고 싶은 변화의 절반보다 훨씬 크게 잡았을 때(작은 변화를 놓친다)."""
    a = _cusum_one_side(k, h, delta, m)
    return a / 2 if abs(delta) < 1e-12 else 1 / (1 / a + 1 / _cusum_one_side(k, h, -delta, m))


def calibrate(arl_fn, target, lo, hi, n=50):
    """arl_fn(x) 가 x 에 따라 커진다고 보고, 이분법으로 arl_fn(x) = target 인 x 를 찾는다.
    쓰면 안 되는 때: 구간 [lo, hi] 안에서 arl_fn 이 target 을 가로지르지 않을 때(구간을 넓혀서 다시)."""
    for _ in range(n):
        mid = (lo + hi) / 2
        if arl_fn(mid) < target:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2


def ewma_monitor(x, mu0, sd, lam, L):
    """(EWMA 값 배열, 첫 알람 번호) 를 돌려준다. 번호는 1부터, 알람이 없으면 None.
    쓰면 안 되는 때: 자기상관이 있을 때(잔차에 쓸 것), 알람 뒤 통계량을 처음 상태로 돌리지 않고 이어서 볼 때(같은 알람이 계속 난다)."""
    z = (np.asarray(x, float) - mu0) / sd
    u = np.zeros(len(z))
    prev = 0.0
    for i, v in enumerate(z):
        prev = lam * v + (1 - lam) * prev
        u[i] = prev
    ucl = L * np.sqrt(lam / (2 - lam))
    hit = np.flatnonzero(np.abs(u) > ucl)
    return u, (int(hit[0]) + 1 if hit.size else None)


def cusum_monitor(x, mu0, sd, k, h):
    """(S+ 배열, S- 배열, 첫 알람 번호, 변화 시작점 추정 번호). 번호는 1부터, 알람이 없으면 None.
    변화 시작점 추정 = 알람 난 쪽 합이 마지막으로 0 이었던 다음 유리. 쓰면 안 되는 때: 자기상관이 있을 때(잔차에 쓸 것)."""
    z = (np.asarray(x, float) - mu0) / sd
    sp, sm = np.zeros(len(z)), np.zeros(len(z))
    a = b = 0.0
    for i, v in enumerate(z):
        a = max(0.0, a + v - k)
        b = max(0.0, b - v - k)
        sp[i], sm[i] = a, b
    hit = np.flatnonzero((sp > h) | (sm > h))
    if not hit.size:
        return sp, sm, None, None
    i = int(hit[0])
    s = sm if sm[i] > h and sm[i] >= sp[i] else sp
    zero = np.flatnonzero(s[:i] == 0)
    return sp, sm, i + 1, (int(zero[-1]) + 2 if zero.size else 1)

print(f"정상 때 목표 ARL0 = {TARGET:.1f} (3σ 선 양쪽의 헛알람 간격)")
L = calibrate(lambda v: arl_ewma(0.2, v, 0.0), TARGET, 1.0, 5.0)
h = calibrate(lambda v: arl_cusum(0.5, v, 0.0), TARGET, 0.05, 60.0)
print(f"맞춘 한계: EWMA(λ=0.2) L = {L:.4f} · CUSUM(k=0.5) h = {h:.4f}")
print("평균 런 길이 ARL (δ = 변화 크기, σ 단위)")
print("  δ    3σ 선    EWMA   CUSUM")
for d in (0.0, 0.5, 1.0, 2.0, 3.0):
    print(f"{d:5.1f} {arl_shewhart(d):8.1f} {arl_ewma(0.2, L, d):7.1f} {arl_cusum(0.5, h, d):7.1f}")

ref, mon = load("S", "ref"), load("S", "mon")
print(f"\n[증착 속도] 기준 {len(ref)}장 평균 {ref.mean():.4f} 표준편차 {ref.std(ddof=1):.4f} · 감시 {len(mon)}장")
z = (mon - MU0) / SD0
f3 = int(np.argmax(np.abs(z) > 3)) + 1 if (np.abs(z) > 3).any() else None
u, fe = ewma_monitor(mon, MU0, SD0, 0.2, L)
sp, sm, fc, st = cusum_monitor(mon, MU0, SD0, 0.5, h)
print(f"3σ 선  첫 알람 {f3}번째 유리 (변화 뒤 {f3 - SHIFT_AT + 1}장째)")
print(f"EWMA   첫 알람 {fe}번째 유리 (변화 뒤 {fe - SHIFT_AT + 1}장째)")
print(f"CUSUM  첫 알람 {fc}번째 유리 (변화 뒤 {fc - SHIFT_AT + 1}장째) · 변화 시작점 추정 {st}번째 유리 (실제 {SHIFT_AT}번째)")

# 자기상관이 있을 때: 0203 의 잔차 만들기(residual_limit 과 같은 계산)를 거친 뒤 CUSUM
r_ref, r_mon = load("R", "ref"), load("R", "mon")
m = r_ref.mean()
d = r_ref - m
phi = (d[1:] * d[:-1]).sum() / (d[:-1] ** 2).sum()
sdr = (d[1:] - phi * d[:-1]).std(ddof=1)
prev = np.concatenate([[r_ref[-1]], r_mon[:-1]])
res = (r_mon - m) - phi * (prev - m)
k_res = 0.5 * (1 - phi) * r_ref.std(ddof=1) / sdr            # 잡고 싶은 변화 = 원값 표준편차의 1배
h_res = calibrate(lambda v: arl_cusum(k_res, v, 0.0), TARGET, 0.05, 60.0)
f_r3 = int(np.argmax(np.abs(res) > 3 * sdr)) + 1
_, _, f_rc, _ = cusum_monitor(res, 0.0, sdr, k_res, h_res)
_, _, f_raw, _ = cusum_monitor(r_mon, 0.0, 1.0, 0.5, h)       # 이 가상 데이터는 평균 0, 전체 표준편차 1
print(f"\n[자기상관 갈래] 기준 {len(r_ref)}장에서 φ̂ = {phi:.4f} 잔차 표준편차 {sdr:.4f}")
print(f"잔차 CUSUM: k = {k_res:.4f} h = {h_res:.4f}")
print(f"첫 알람(번째 유리): 잔차 3σ {f_r3} · 잔차 CUSUM {f_rc} · 원값 CUSUM {f_raw} (변화 {'전' if f_raw < SHIFT_AT else '뒤'})")

감시 순서: 0203 assumption_check → (자기상관이면 잔차로) → CUSUM 또는 EWMA와 3σ 선 → 0202 alarm_audit. 사람이 정하는 것은 δ*와 감내할 ARL0, 변화의 진위 확정이고, 에이전트는 한계 맞춤·감시·변화 시작점 추정·보고까지 맡습니다.

  





  
아닙니다. 이 실험실의 ARL은 정상 평균과 표준편차를 정확히 안다고 놓고 계산한 값입니다. 기준 장수가 적으면 추정한 평균과 표준편차가 참값에서 흔들리고, 그 흔들림이 선이나 합의 위치를 옮겨 ARL0이 약속보다 짧아지거나 길어집니다. 6절의 잔차 쪽 정상 때 ARL0이 약속과 조금 다르게 나오는 것도 같은 이유입니다.
