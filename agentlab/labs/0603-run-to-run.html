닫힌 고리의 가장 단순한 형태 — 런투런 제어

한 턴을 돌리고, 잰 배율 오차로 다음 턴의 보정값을 식으로 정합니다. 이득을 얼마로 잡을지, 그 식이 언제 발산하는지까지 손으로 확인합니다

0602 는 세정 시간이라는 상태를 날마다 추정했습니다. 이 실험실은 추정한 값을 공정에 되먹임하는 가장 작은 형태를 다룹니다. 마스크 한 장을 턴 쓰는 동안 배율 오차(Mx, ppm)는 마모와 챔버 온도 때문에 한쪽으로 밀립니다. 지금은 잰 값이 spec 을 넘을 때마다 사람이 그 오차만큼 한 번 보정합니다. 그 보정을 턴마다 식으로 정하면 무엇이 달라지는지, 그 식을 어떤 조건에서 믿어도 되는지를 같은 기록 위에서 다시 돌려 확인합니다. 마지막에는 보정 규칙을 라인에 쓰기 전에 지켜야 할 확인 항목을 운영표로 남깁니다.

시작하기 전에

이미 아시는 것 — 0204 의 EWMA(지난 값을 지수로 줄여 가며 평균하는 방법), 0303 의 열변형과 턴 누적(배율이 온도 1 K 당 약 ppm 밀리고 턴마다 조금씩 내려가는 것), 0304 의 보정과 리페어의 구분, 0306 의 마스크 수명과 spec 한계(목표에서 ± ppm), 0601 의 닫힌 고리와 트윈, 0602 의 칼만 필터(정상 상태에서 이득이 EWMA 의 λ 와 같은 것).

  • EWMA (0204)
  • 열변형 · 턴 누적 (0303)
  • 보정 vs 리페어 (0304)
  • 마스크 수명 · spec 한계 (0306)
  • 닫힌 고리 · 트윈 (0601)
  • 칼만 필터 (0602)

새로 이름을 붙이는 낱말은 여섯 개입니다. 쓰이는 자리에서 하나씩 정의하고, 정의한 뜻 그대로만 씁니다. 이 여섯 개 말고 계산에 붙인 이름(RMS·출렁임·교체 알림·가정 이득)은 쓰는 자리에서 식이나 문장으로 정의합니다.

  • 런투런 제어 (run-to-run control)
  • 공정 이득 (process gain)
  • 외란 (disturbance)
  • 모델 불일치 비 (model mismatch ratio)
  • 안정 영역 (stability region)
  • 잔류 오프셋 (steady-state offset)

이 실험실에서 가져가는 것

  1. 실무에서 쓰는 곳 — 배율이 턴마다 열과 마모로 밀릴 때 사람이 감으로 하던 보정을 규칙으로 바꾸는 것, 그리고 그 규칙의 이득 λ 를 ‘빠르게’가 아니라 ‘공정 이득을 잘못 알아도 발산하지 않게’ 고르는 판단(3~7절).
  2. 손으로 연습 — λ 를 바꿔 따라가는 속도와 출렁임을 맞바꾸기(4절), 표류가 크거나 잡음이 큰 공장에서 좋은 λ 가 어디로 옮겨 가는지 보기(5절), 공정 이득을 일부러 틀리게 두어 발산 경계 찾기(6~7절), 표류가 계속될 때 남는 늦음 재기(8절), 마스크 교체 때 추정을 리셋하는 효과 보기(9절).
  3. 다음 날 산출물 — ewma_r2r·r2r_stability·r2r_replay Python 함수(12절), 보정 규칙 운영표 양식(13절).
  4. 기록할 데이터 — 턴마다 ‘넣은 보정값’과 ‘그 뒤 잰 값’을 같은 키로, 마스크 교체·리페어 시각(13절). 보정값을 기록하지 않으면 공정이 원래 어떻게 밀렸는지를 되살릴 수 없습니다.
  5. 사람·규칙·에이전트의 몫 — λ 와 보정 상한과 개입 조건의 승인은 사람, 안정 영역 안의 λ·교체 리셋·보정값 상한은 규칙, 매 턴 보정 계산과 출렁임 감시와 이상 시 사람 호출은 에이전트(10절).
  6. 성과 환산 — 사람 방식 대비 spec 밖 턴 수의 감소와 그만큼의 유리 장수(11절).
[문제] 마스크 한 장을 턴 쓰는 동안 배율 오차를 spec(± ppm) 안에 두려고 합니다. 지금은 잰 값이 ± 를 넘을 때마다 사람이 그 오차만큼 한 번 보정합니다. 아래 기록(시드 )은 그렇게 운영한 결과입니다. 보정값을 턴마다 자동으로 정하는 규칙으로 바꾸면 spec 밖 턴이 얼마나 줄고, 그 규칙을 어떤 조건에서 믿어도 됩니까?

이 기록은 가상 공장이 만들 수 있는 수많은 기록 가운데 마스크 한 장(중간에 교체 1회)의 턴입니다. 한 장으로 규칙의 효과를 단정하지 않으려고, 같은 공장의 시드 개 분포를 함께 봅니다. 무엇을 추정하는지는 ‘이 기록에서 사람 방식과 규칙 방식의 차이’와 ‘시드가 달라질 때 그 차이가 얼마나 흔들리는가’ 둘입니다. 1절에서 지금 방식의 한계를 보고, 2절에서 가장 쉬운 시도가 막히는 곳을 보고, 3절에서 이름을 붙이고, 4절에서 규칙을 세워 λ 를 바꿔 보고, 5절에서 좋은 λ 가 무엇에 따라 달라지는지 보고, 6~7절에서 이득을 잘못 알 때의 발산과 안정 영역을, 8절에서 잔류 오프셋을, 9절에서 마스크 교체를, 10절에서 처음 물음으로 돌아옵니다.

여기서부터 가상 공장의 기록으로 푸는 풀이입니다

1지금의 방식 — 넘을 때마다 사람이 고친다

두 가지를 먼저 정합니다. y 는 t 번째 턴에 잰 배율 오차(ppm, 목표 0 에서 얼마나 벗어났는지)이고, u 는 그 턴에 넣은 보정값(ppm)입니다. 보정값은 배율 오차를 움직이는 손잡이입니다. 사람 방식은 잰 값의 크기가 ± ppm 을 넘은 턴에만, 그 값만큼을 한 번에 되돌립니다(가정). 아래는 그렇게 운영한 턴의 기록입니다. 점선 가로선이 spec 이고 세로선이 마스크를 바꾼 턴입니다.

사람 방식으로 운영한 기록 — 잰 배율 오차와 넣은 보정값
무엇을 볼지 먼저. 점이 spec 선을 넘는 턴이 몇 번인지, 넘은 다음 턴에 보정값(아래 그림)이 어떻게 한 번에 움직이는지, 마스크를 바꾼 턴 뒤에 어떤 일이 벌어지는지 보십시오.
잰 배율 오차 y (ppm)넣은 보정값 u (ppm)spec 밖인 턴

이 방식에는 구조적인 한계가 둘 있습니다. 첫째, 넘은 뒤에야 움직이므로 spec 밖인 턴이 반드시 생깁니다. 둘째, 잰 값 하나를 그대로 믿습니다. 잰 값에는 측정 잡음이 섞여 있어서, 잡음이 크게 나온 턴에 보정하면 오히려 공정을 밀어 놓게 됩니다. 그렇다면 문턱을 없애고 매 턴 잰 오차만큼 전부 보정하면 되지 않을까요? 다음 절에서 해 봅니다.

2첫 시도와 막힘 — 매 턴 잰 만큼 전부 보정하면

문턱 없이 매 턴 잰 오차를 전부 반영하는 규칙은 이번에 잰 오차를 새 보정에 반영하는 몫 λ 가 1 인 경우입니다(λ 의 정확한 식은 4절에서 씁니다). λ 를 1 보다 작게 하면 이번 오차의 일부만 반영하고 나머지는 지난 추정에 맡깁니다. 먼저 시드 개의 가상 공장에서 λ 에 따라 spec 안의 정도(RMS)가 어떻게 달라지는지 봅니다. RMS 는 오차를 제곱해 평균하고 제곱근을 씌운 값으로, 목표 0 에서 평균적으로 얼마나 벗어났는지를 나타냅니다.

λ 에 따른 RMS — 시드 개의 중앙값과 10~90% 띠 (측정 잡음의 크기를 바꿔 보기)
무엇을 볼지 먼저. 측정 잡음이 기본일 때 λ=1 이 가장 좋은 점과 얼마나 다른지, 잡음을 4배로 키우면 가장 낮은 점이 어디로 옮겨 가는지 보십시오.
RMS 중앙값10% 와 90%가장 낮은 점

기본 잡음에서는 λ=1 도 크게 나쁘지 않습니다. 이 가상 공장에서는 배율을 미는 힘(마모·온도 변동·마스크 교체)이 측정 잡음보다 크기 때문입니다. 그러나 막힘은 잡음이 커질 때 나타납니다. 보정값은 잰 값을 따라 움직이므로 잰 값에 섞인 잡음이 보정값에 그대로 실리고, 그 보정이 다시 공정을 밀어 새 오차를 만듭니다. 아래는 이 기록에서 같은 외란을 두고 λ=1 과 더 작은 λ 로 보정값이 얼마나 출렁이는지 본 것입니다(되살리는 방법은 3절에서 설명합니다).

보정값 u 의 출렁임 — 이 기록의 외란 위에서 λ 를 달리 했을 때
무엇을 볼지 먼저. λ=1 의 보정값이 턴마다 위아래로 흔들리는 폭과, λ 를 줄였을 때 그 폭이 얼마나 줄고 대신 오차의 RMS 가 얼마나 늘어나는지 보십시오.
λ = 1 (전부 보정)λ = 0.3

막힘: 보정값을 얼마나 빨리 움직일지(λ)는 ‘표류를 따라가는 속도’와 ‘잡음을 따라가는 위험’ 사이의 맞바꿈이고, 그 맞바꿈의 좋은 점은 공장에 따라 다릅니다. 이름을 붙이고 식으로 쓰면 이 맞바꿈을 같은 틀에서 다룰 수 있습니다.

3이름 — 런투런 제어·외란·공정 이득, 그리고 로그에서 외란을 되살리기

런투런 제어(run-to-run control) 는 한 번 돌린 결과를 재서 다음 번 입력(보정값)을 정하는 제어입니다. 여기서는 한 턴이 한 번(run)입니다. 제어를 식으로 쓰려면 배율 오차가 어떻게 만들어지는지부터 적어야 합니다. 턴 t 의 잰 값은 세 부분의 합입니다.

공정 모델: 잰 값 = 보정이 움직인 몫 + 외란 + 잡음 yt=β·ut+dt+εt u 는 넣은 보정값, d 는 보정과 무관하게 배율을 미는 값, ε 은 측정 잡음입니다.

공정 이득(process gain) β 는 보정값을 한 단위 바꿀 때 배율이 실제로 바뀌는 양입니다. 제어기는 이 값을 정확히 모르고 ‘믿는 값’ b 로 계산합니다(여기서는 보정 1 ppm 이 배율 1 ppm 을 움직인다고 보아 b = ). 외란(disturbance) d 는 보정과 무관하게 배율을 미는 것으로, 이 공장에서는 느린 표류(마모·챔버 온도의 느린 상승), 턴마다 달라지는 온도 변동, 마스크 교체의 계단 셋입니다. 제어기가 보는 것은 y 뿐이고 d 와 ε 은 나뉘어 보이지 않습니다.

그런데 위 기록에서 사람이 보정을 했기 때문에, y 에는 보정의 영향이 이미 섞여 있습니다. 규칙을 바꿔 다시 돌리려면 보정을 뺀 외란을 되살려야 하고, 그러려면 β 를 알아야 합니다. β 는 기록에서 읽을 수 있습니다. 보정값이 바뀐 턴에서 잰 값이 얼마나 따라 움직였는지를 보면 되기 때문입니다. 턴 사이의 변화로 쓰면 Δy = β·Δu + (외란의 변화) 이고, Δy 를 Δu 와 상수에 맞춘 직선의 기울기가 추정값 β̂ 입니다(마스크를 바꾼 턴의 Δy 는 계단이라 뺍니다). 외란의 변화는 평균이 0 에 가깝고 보정과 무관하다고 보는 가정입니다.

보정값이 바뀐 턴의 Δu 와 그 뒤의 Δy — 기울기가 β̂
무엇을 볼지 먼저. 점들이 기울기 1 의 선(보정을 그대로 받는 공장) 아래에 있는지 위에 있는지, 점이 얼마나 흩어져 있는지 보십시오. 흩어진 폭이 β̂ 의 표준오차를 정합니다.
잰 값 y되살린 외란 d̂ = y − β̂·u
이 추정이 기대는 것. 1) 외란의 변화가 보정과 무관하다고 봅니다. 보정은 직전에 잰 값으로 정해지므로 잡음 ε 이 보정값과 그 뒤 잰 값 양쪽에 들어 있어서, β̂ 는 실제보다 크게 나오는 쪽으로 어긋날 수 있습니다. 2) 보정이 바뀐 턴이 적으면 흩어짐이 큽니다. 위 표준오차가 그 크기입니다. 3) 이 기록은 사람 방식으로 운영한 것이라 보정값이 움직인 턴이 몇 번뿐입니다. 어긋남이 얼마인지는 14절에서 숨은 값과 견주어 봅니다.

4EWMA 규칙 — 외란을 지수 가중 평균으로 쌓아 반대로 보정한다

0204 의 EWMA 를 외란 추정에 씁니다. 이번 턴에 보정이 설명하지 못한 몫 z = y − b·u 가 외란과 잡음의 합이므로, 그 지수 가중 평균 a 가 ‘지금 공정에 걸려 있는 외란의 추정’입니다. 다음 턴 보정값은 그 추정을 상쇄하도록 반대로 넣습니다(목표 r = 0).

EWMA 런투런 제어기 at=λ(yt−but)+(1−λ)at−1ut+1=r−atb a 의 처음 값은 0(보정이 없던 상태)입니다. λ 는 0 과 1 사이의 평활 계수로, 0204 와 0602 의 λ 와 같은 뜻입니다. 칼만 이득이 정상 상태에서 가라앉은 값이 곧 λ 였습니다.

아래는 3절에서 되살린 외란 위에서 이 규칙을 돌린 결과입니다. 공정 이득은 3절의 추정 β̂ 를 가정 이득(되살린 외란 위에서 규칙을 다시 돌릴 때 공정이 보정을 얼마나 받아들인다고 둘지)으로 두었습니다. 그래서 같은 외란, 같은 잡음에서 규칙만 바뀐 비교입니다. 이 방식이 맞는지의 점검으로, 사람 방식을 같은 외란 위에서 다시 돌리면 1절의 기록과 똑같이 나와야 합니다.

같은 외란 위에서 규칙만 바꿔 다시 돌린 결과
무엇을 볼지 먼저. λ 를 0.1 로 내렸을 때 곡선이 얼마나 부드러워지지만 표류에 늦게 따라붙는지, λ 를 1 로 올렸을 때 곡선이 얼마나 거칠어지는지, 그 가운데 어디가 spec 밖 턴 수가 가장 적은지 보십시오.

표류를 따라가는 속도는 빨라지지만 잡음도 그만큼 따라갑니다. 4절 슬라이더로 λ 를 1 쪽으로 올리면 외란의 변화에는 빨리 붙는 대신 보정값이 턴마다 크게 흔들리는 것을 볼 수 있습니다. 어느 쪽이 이기는지는 공장에 달려 있습니다. 5절에서 표류와 잡음을 바꿔 가장 낮은 λ 가 어디로 옮겨 가는지 봅니다. 이 가상 공장에서는 표류가 클수록 좋은 λ 가 대체로 커지고 측정 잡음이 클수록 작아지지만, 곡선의 바닥이 넓어서 표류 한 단계마다 가지런히 달라지지는 않습니다. 표류가 0 이어도 좋은 λ 가 큰 것은 마스크 교체의 계단과 온도 변동이 외란으로 남기 때문입니다. 그리고 λ 를 키울 때는 반드시 공정 이득의 불일치(6절)를 같이 점검합니다. λ 와 이득의 곱이 2 를 넘으면 보정이 발산합니다.

5좋은 λ 는 무엇에 따라 달라지나 — 표류와 잡음

4절의 곡선에서 λ 를 바꾸면 RMS 가 어느 쪽으로 움직이는지는 보았습니다. 그러면 가장 낮은 점은 공장이 달라질 때 어디로 옮겨 갑니까? 두 가지를 따로 바꿔 봅니다. 하나는 표류의 크기(마모와 온도의 느린 상승 속도를 배수로 바꿈)이고, 다른 하나는 2절의 측정 잡음입니다. 시드 개마다 RMS 를 재어 중앙값이 가장 낮은 λ 를 고릅니다. 이 기록 한 벌에서도 되살린 외란의 직선 기울기를 배수로 바꿔 같은 일을 해 봅니다(기울기만 키우고 나머지 요동은 그대로 둡니다).

6공정 이득을 잘못 알면 — 모델 불일치 비

지금까지 제어기는 b 를 믿고 계산했고, 되살린 외란 위의 공정은 β̂ 로 움직였습니다. 두 값이 어긋나면 어떻게 될까요? 어긋남을 하나의 숫자로 부르려고 모델 불일치 비(model mismatch ratio) ξ = β / b 를 씁니다. 1 이면 제어기가 공정을 정확히 알고 있다는 뜻이고, ξ 가 1 보다 크면 보정이 믿은 것보다 더 세게 먹히며, 1 보다 작으면 덜 먹힙니다.

모델 불일치 비 ξ=βb β 는 공정의 실제 이득, b 는 제어기가 믿는 이득입니다. 이 장의 슬라이더 ξ 는 b 를 고정하고 공정이 받아들이는 이득을 ξ·b 로 두어 보는 가정입니다(가정 이득).
같은 외란, 같은 λ 에서 공정 이득을 바꿔 본 결과
무엇을 볼지 먼저. ξ 를 1 에서 키울 때 곡선이 어느 값에서 진동하기 시작하는지, 진동이 서서히 줄어드는지 커지는지 보십시오. ξ 를 0.3 쪽으로 내리면 어떻게 달라지는지도 보십시오.
EWMA 가 만든 y보정 없음 (되살린 외란)

기본값 ξ̂ 는 3절의 β̂ 에서 온 것입니다. 이것은 사람 방식의 기록에서 읽은 값이라 어긋남이 있을 수 있으므로, 실제로는 따로 재어야 합니다(Q&A). 그보다 중요한 질문은 어긋남이 얼마까지 허용되는가입니다. 다음 절에서 λ 와 ξ 의 모든 조합에 대해 발산하는지를 한꺼번에 봅니다.

보정값을 일부러 조금 흔든 기록이 가장 믿을 만합니다. 이 기록처럼 사람이 오차를 보고 보정한 자료는 보정값이 잡음과 얽혀 있어서 β̂ 가 실제보다 크게 나오는 쪽으로 어긋날 수 있습니다(14절에서 숨은 값과 견줍니다). 공정을 만지는 권한이 있다면 몇 턴 동안 외란과 무관하게 정한 작은 보정값(예를 들어 ±0.3 ppm 을 번갈아)을 넣고, 그 뒤 잰 값의 변화를 보정값에 맞춰 기울기를 읽습니다. 이 방법은 다음 실험실(0604)에서 과거 기록으로 새 규칙을 평가할 때 ‘무엇을 기록해야 하는가’와 이어집니다. 어떤 방법이든 β̂ 와 표준오차를 함께 적고, 보정 규칙의 이득 λ 는 β̂ 가 실제의 두 배쯤 틀려도 발산하지 않는 범위에서 고릅니다.

7안정 영역 — λ 와 ξ 가 어디까지 허용되나

발산하는지는 외란과 무관하게 규칙과 공정만으로 정해집니다. 외란을 0 으로 두고 4절의 식을 이어 쓰면 추정 a 의 갱신이 한 줄로 정리됩니다.

외란 추정의 갱신 — 한 턴마다 곱해지는 몫 at=(1−λξ)at−1+λ(dt+εt) y = β u + d + ε 에 u = −a/b 를 넣으면 z = y − b u = (β − b) u + d + ε = d + ε − (ξ − 1) a 이고, 이를 EWMA 에 넣으면 위 식이 됩니다. 외란이 없으면 a 는 한 턴마다 (1 − λξ) 배가 됩니다.

한 턴마다 곱해지는 몫의 크기가 1 보다 작으면 줄어들고 크면 커집니다. 곱하는 몫 1 − λξ 가 −1 과 1 사이일 때가 발산하지 않는 때입니다. 이것이 안정 영역(stability region) 입니다. 보정이 발산하지 않는 (λ, ξ) 의 범위를 말합니다.

안정 영역 0<λξ<2 경계 λξ = 2 에서는 한 턴마다 부호만 바뀌며 크기가 변하지 않아 영원히 진동합니다. λ 는 0 과 1 사이의 평활 계수라 ξ 가 2 를 넘을 때부터 경계가 보입니다.

식이 맞는지 확인합니다. 외란과 잡음이 0 이고 추정이 1 로 시작할 때 200 턴 뒤의 |a| 가 처음보다 작으면 수렴, 크면 발산으로 세어, 칸마다 이론 판정(위 부등식)과 견줍니다.

(λ, ξ) 의 안정 지도 — 실제로 돌려 본 판정과 이론 경계
무엇을 볼지 먼저. 초록(수렴) 영역과 빨강(발산) 영역의 경계가 점선(λξ = 2)과 겹치는지, 슬라이더의 현재 (λ, ξ) 점이 어느 쪽에 있는지, 경계에 가까울수록 외란 위의 곡선이 얼마나 오래 진동하는지(6절) 보십시오.
수렴 (실측)발산 (실측)경계 (크기 불변)현재 (λ, ξ)

8표류가 계속될 때 남는 늦음 — 잔류 오프셋

EWMA 는 지난 값을 평균하므로 외란이 계속 한쪽으로 밀리면 따라가는 추정이 늘 조금 뒤처집니다. 잔류 오프셋(steady-state offset) 은 표류가 계속될 때 EWMA 보정이 끝내 남기는 일정한 늦음입니다. 외란이 턴마다 s ppm 씩 직선으로 밀릴 때 오차 y 에 남는 값은 다음과 같습니다.

잔류 오프셋 y∞=sλξ=s·1−λλ+s(ξ=1) 앞 항 s(1−λ)/λ 는 EWMA 가 직선 표류를 따라갈 때의 추정의 늦음이고, 뒤 항 s 는 이번 턴에 잰 값으로 다음 턴 보정을 정하는 데 걸리는 한 턴의 지연입니다.

식은 s 를 곱하는 몫이므로, s 가 작아도 λ 가 작으면 늦음이 커집니다. 직선 표류와 잡음 없는 가상 외란에서 돌려 식과 맞는지 확인하고, 이 기록에서 읽은 표류 기울기도 넣어 봅니다.

직선으로 밀리는 외란 위의 EWMA — 실제로 남는 오프셋과 식
무엇을 볼지 먼저. λ 를 낮출수록 마지막에 남는 간격이 어떻게 커지는지, 표에서 식의 값과 돌려 본 값이 같은지, ξ 를 1 에서 움직이면 오프셋이 어떻게 달라지는지 보십시오.

9마스크를 바꾸면 — 계단 외란과 리셋

마스크를 바꾸는 턴에는 외란이 계단처럼 한 번에 뜁니다(새 마스크의 제작 오프셋이 옛 마스크와 다르기 때문입니다). EWMA 의 추정 a 는 옛 마스크의 외란을 담고 있어서, 계단 뒤에 추정이 새 값에 닿을 때까지 오차가 남습니다. 교체 알림은 마스크를 바꾼 턴을 제어기에 알려 주는 것으로, 그 턴에는 추정을 평균하지 않고 그 턴의 값으로 다시 시작(리셋)합니다. 0602 에서 세정액 교체일에 칼만 추정을 다시 시작한 것과 같은 생각입니다.

10착지 — 처음 물음에 숫자로 답합니다

맨 앞의 물음으로 돌아옵니다. “보정값을 턴마다 자동으로 정하는 규칙으로 바꾸면 spec 밖 턴이 얼마나 줄고, 그 규칙을 어떤 조건에서 믿어도 됩니까?”

사람

  • λ 의 상한과 보정값의 상한, 사람을 부르는 조건을 정하고 승인합니다
  • 공정 이득을 따로 재는 일(보정값을 일부러 조금 흔든 기록)을 계획합니다
  • 마스크 교체·리페어 시각을 기록에 남깁니다

규칙

  • λ·ξ 의 곱이 1 을 넘는 설정은 쓰지 않습니다(안정 영역은 2 까지이지만 여유를 둔 기준입니다. 1 − λξ 가 음수가 되는 1 부터 보정이 부호를 번갈아 바꾸는 진동이 시작되고, 2 에 이르면 그 진동이 줄지 않습니다)
  • 마스크 교체나 리페어 기록이 생기면 그 턴에 추정을 다시 시작합니다
  • 한 번에 넣는 보정값에 상한을 둡니다

에이전트

  • 매 턴 잰 값으로 추정을 갱신하고 다음 턴 보정값을 계산합니다
  • 보정값의 출렁임과 누적 보정량을 감시해 한도를 넘으면 사람을 부릅니다
  • 운영표 초안과 한 주 요약을 씁니다(사실 목록 방식, 0411)

0604 로 가는 다리. 보정 규칙을 바꾸기 전에 지난 기록으로 새 규칙의 효과를 미리 재어 보고 싶다면 이 실험실의 되살리기가 그 첫 형태입니다. 그러나 되살린 외란은 공정 이득의 추정에 달려 있고, 지난 기록에 보정값과 그 뒤의 값이 같은 키로 남아 있어야만 가능합니다. 다음 실험실은 이 질문을 더 일반적으로, 지난 로그로 새 규칙의 효과를 치우침 없이 추정하는 조건으로 확장합니다.

이 값은 가상 공장의 장수입니다. 회사에서는 같은 식에 유리 한 장의 생산 손실 단가를 곱해 금액으로 적고, 마스크를 한 달에 몇 장 쓰는지로 곱해 월 환산합니다. spec 밖 유리를 전부 버린다는 가정은 보수적이거나 낙관적일 수 있으니 실제 처리 규칙으로 바꿔 넣습니다.

12Python — 회사 PC에 가져갈 코드

아래 코드는 numpy·pandas 만 씁니다. 입력은 아래 CSV 세 개이고, 코드와 같은 폴더에 두면 그대로 돌아갑니다. 회사에서는 s19_r2r.csv 자리에 같은 열(턴·잰 값·넣은 보정값·교체 표시)을 가진 자기 기록을 넣습니다.

s19_r2r.csvs19_seed_summary.csvs19_lambda_sweep.csv

쓰면 안 되는 때: 보정값을 기록하지 않은 채 제어의 효과를 말하지 마십시오(보정을 뺀 외란을 되살릴 수 없습니다). ξ 를 확인하지 않고 λ 를 키우지 마십시오(λ 와 ξ 의 곱이 1 을 넘으면 진동이 시작되고 2 에 가까워지면 진동이 줄지 않습니다). 이득 추정 β̂ 를 사람이 잰 값으로 보정한 기록 하나에서만 읽고 확정하지 마십시오(어긋남이 있습니다). 마스크를 바꾼 턴을 알리지 않은 채 작은 λ 를 쓰지 마십시오.

import numpy as np
import pandas as pd

# ---- 가정·설정: 회사 값으로 바꿀 곳 --------------------------------------------------
LAM = 0.8              # EWMA 이득 λ (0 < λ ≤ 1): 시드 200개의 RMS 중앙값이 가장 작은 값
B = 1.0                # 제어기가 믿는 공정 이득 b (보정 1 ppm 이 배율 1 ppm 을 움직인다고 봄)
TARGET = 0.0           # 목표 배율 오차(ppm)
LIMIT = 0.5            # spec: 목표에서 ±LIMIT ppm
HUMAN_THR = 0.5        # 사람 방식: 잰 값의 크기가 이 문턱을 넘은 턴에만 그만큼 한 번 보정
LAM_SLOW = 0.2         # 느린 λ (교체 알림의 효과를 보려는 비교용)
GLASS_PER_TURN = 120   # 한 턴의 유리 장수(spec 밖인 턴의 유리를 버린다는 가정)

def ewma_r2r(y_meas, b, lam, target=TARGET, resets=()):
    """권고한 보정값을 그대로 썼다고 보고, 턴마다 잰 y 로 외란 추정 a 를 갱신해 다음 턴 보정값을 낸다.
    resets = 추정을 그 턴의 값으로 다시 시작할 턴 번호(0 부터, 마스크를 바꾼 턴).
    반환 (u, a, u_next): u[t] = t 턴에 쓰인 보정값, a[t] = t 턴을 잰 뒤의 외란 추정, u_next = 다음 턴에 넣을 보정값."""
    u, a, ah, cur = [], [], 0.0, 0.0
    for t, y in enumerate(y_meas):
        u.append(cur)
        z = y - b * cur                       # 이번 턴에 보정이 설명하지 못한 몫 = 외란 + 잡음 (+ 이득 어긋남)
        ah = z if t in resets else lam * z + (1 - lam) * ah
        a.append(ah)
        cur = (target - ah) / b
    return np.array(u), np.array(a), cur

def r2r_stability(lams, xis, turns=200):
    """외란 0·잡음 0 에서 추정 a 를 1 로 시작해 turns 턴 뒤 |a| 를 잰다. 1 보다 크면 발산, 작으면 수렴."""
    out = np.empty((len(lams), len(xis)))
    for i, lam in enumerate(lams):
        for j, xi in enumerate(xis):
            a = 1.0
            cur = -a
            for _ in range(turns):
                y = xi * cur                  # 공정 이득 = ξ·b (b = 1)
                a = lam * (y - cur) + (1 - lam) * a
                cur = -a
            out[i, j] = abs(a)
    return out

def drift_scale(d, rep, m):
    """외란을 마스크 구간별 직선(기울기 γ)과 나머지로 나누어 직선 기울기만 m 배로 한다: d' = d + (m−1)·γ·(구간 안 위치)."""
    out = d.copy()
    for a, b in ((0, rep), (rep, len(d))):
        x = np.arange(b - a)
        g = np.polyfit(x, d[a:b], 1)[0]
        out[a:b] = d[a:b] + (m - 1) * g * x
    return out

def r2r_replay(log, lam=LAM, xi=None, reset=True, method="ewma", drift_mult=1.0):
    """사람 방식으로 운영한 기록 log(열 y_ppm·u_ppm·mask_replaced)로
    (1) 공정 이득 β̂ 를 보정값이 바뀐 턴에서 읽고, (2) 보정을 뺀 외란 d̂ = y − β̂·u 를 되살려,
    (3) 같은 외란 위에서 다른 규칙(method: none · human · ewma)을 다시 돌린다. xi = 가정 이득 / b (None 이면 β̂/B)."""
    y, u, mr = log["y_ppm"].to_numpy(float), log["u_ppm"].to_numpy(float), log["mask_replaced"].to_numpy()
    rep = int(np.flatnonzero(mr)[0])
    keep = mr[1:] == 0                         # 마스크를 바꾼 턴의 Δy 는 계단이라 뺀다
    du, dy = np.diff(u)[keep], np.diff(y)[keep]
    sxx = ((du - du.mean()) ** 2).sum()
    beta = ((du - du.mean()) * (dy - dy.mean())).sum() / sxx
    rss = (((dy - dy.mean()) - beta * (du - du.mean())) ** 2).sum()
    se = float(np.sqrt(rss / (len(du) - 2) / sxx))
    d = drift_scale(y - beta * u, rep, drift_mult)
    gain = (beta / B if xi is None else xi) * B
    cur, ah, yy, uu = 0.0, 0.0, [], []
    for t in range(len(d)):
        uu.append(cur)
        yt = gain * cur + d[t]
        yy.append(yt)
        if method == "human":
            if abs(yt - TARGET) > HUMAN_THR:
                cur = cur - (yt - TARGET) / B
        elif method == "ewma":
            z = yt - B * cur
            ah = z if (reset and t == rep) else lam * z + (1 - lam) * ah
            cur = (TARGET - ah) / B
    return {"beta": float(beta), "se": se, "njump": int((np.abs(du) > 1e-12).sum()), "d": d, "y": np.array(yy), "u": np.array(uu), "rep": rep}

def rms(y):
    return float(np.sqrt(np.mean(np.square(y))))

def n_out(y):
    return int((np.abs(y) > LIMIT).sum())

def offset_run(lam, xi, s, turns=400):
    """직선으로 밀리는 외란 d_t = s·t 위에서 turns 턴 돌린 뒤의 y(잔류 오프셋). 식: s/(λξ)."""
    d = s * np.arange(1, turns + 1)
    cur, ah, y = 0.0, 0.0, 0.0
    for t in range(turns):
        y = xi * B * cur + d[t]
        ah = lam * (y - B * cur) + (1 - lam) * ah
        cur = (TARGET - ah) / B
    return y

  • 사건 — 마스크 교체·리페어·챔버 PM 의 시각과 종류. 리셋 조건과 외란 되살리기의 근거입니다.

보정값을 기록하지 않으면 제어의 효과도, 공정이 원래 밀린 모습도 말할 수 없습니다. 회사 기록은 회사 안에만 둡니다.

0601 의 twin_gap 에서 승인 대기열까지 부르는 순서에 이 장의 함수가 들어옵니다.

PID 는 연속으로 움직이는 공정을 짧은 주기로 되먹임하는 방법이고, 이 공정은 한 번 돌려야 한 번 재는 이산 공정이기 때문입니다. 한 턴에 하나씩 오는 측정으로 다음 턴 보정을 한 번 정하므로, 적분항 하나로 충분한 EWMA 형태가 가장 단순합니다(EWMA 는 적분 제어와 같은 꼴입니다). 비례항이나 미분항은 측정 잡음을 키울 뿐 이 공정에서 얻는 것이 적습니다. 다만 표류가 빠르면 EWMA 는 8절의 늦음을 남기므로, 그때는 이중 EWMA 나 칼만 필터처럼 기울기까지 추정하는 방법을 검토합니다.

보정이 마모를 가려서 리페어 시점을 놓칠 수는 있습니다. 그래서 보정값의 누적량을 기록해 둡니다. 보정값이 마스크 한 장에서 쌓이는 크기가 곧 마모의 크기이므로, 0304 의 보정과 리페어 구분과 0306 의 한계 예측에 그 누적량을 넣어 읽습니다. 보정값이 상한에 가까워지면 규칙은 더 보정하지 않고 사람을 부르도록 둡니다. 보정이 가리는 것은 오차이고, 마모 자체는 누적 보정량에 그대로 남습니다.
