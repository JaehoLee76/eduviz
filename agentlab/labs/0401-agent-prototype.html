지금까지 만든 함수를 매일 아침 사람이 차례로 부르고 있습니다. 이 순서를 정해 두고 스스로 돌게 하되, 상태를 바꾸는 일은 0206 의 전이 표에 있는 전이만 가드를 통과할 때 하게 하고, 되돌릴 수 없는 일은 사람 승인 대기열로 보내고, 자료 점검이 실패한 날은 분석하지 않고 알리기만 하게 만든 ‘규칙으로 묶인 실행자’가 이 실험실의 에이전트입니다. 매 단계가 기록으로 남으므로 틀렸을 때 어느 단계가 틀렸는지 찾을 수 있습니다. 무대는 0400 의 가상 공장 일(대표 시드 , 챔버 개)이고, 에이전트는 날마다 0400 이 낸 표를 받습니다. 보고 문장은 정해 둔 틀로 만들며 LLM 을 부르지 않습니다.

시작하기 전에

이미 아시는 것 — 0400 의 점검 일곱 규칙과 지문, 0104 의 변경점 전후 비교(자기상관·대조 챔버 이중차분), 0202 의 가족 오류율과 본페로니 보정, 0206 의 전이 표와 요청 판정, 0304·0306 의 리페어 판단과 리페어 직후 기준 측정, 0411 의 사실 목록과 검사기(V1~V6).

  • 점검 일곱 · 지문 (0400)
  • 변경점 판정 흐름 (0104)
  • 가족 오류율 · 본페로니 (0202)
  • 전이 표 · 요청 판정 (0206)
  • 리페어 판단 (0304·0306)
  • 사실 목록 · 검사기 (0411)

새로 이름을 붙이는 낱말은 여섯 개입니다. 쓰이는 자리에서 하나씩 정의하고, 정의한 뜻 그대로만 씁니다. 이 여섯 개 말고 이 글이 쓰는 ‘요청’·‘판정’·‘가드’는 쓰는 자리에서 문장으로 풀어 둡니다.

  • 에이전트 (agent)
  • 도구 (tool)
  • 실행 단계 (step)
  • 정책 (policy)
  • 승인 대기열 (approval queue)
  • 실행 기록 (agent log)

이 실험실에서 가져가는 것

  1. 실무에서 쓰는 곳 — 매일 아침 자료를 보고 판단 초안·조치 요청·보고를 내는 에이전트의 뼈대(2~7절). 지금까지 만든 함수를 정해진 순서로 부르는 것이 전부입니다.
  2. 손으로 연습 — 14일을 하루씩 돌려 에이전트가 무엇을 보고 무엇을 요청했고 무엇이 거절·대기됐는지 읽고, 점검 허용 수·문턱·승인 정책을 바꿔 행동이 어떻게 바뀌는지 보고, 승인 대기열의 요청을 직접 승인·반려해 다음 날 상태가 어떻게 달라지는지 봅니다(3~6절).
  3. 다음 날 산출물 — agent_step 을 중심으로 한 Python 뼈대(관찰·점검·분석·결정·요청·보고 함수 묶음)(10절)와 에이전트 실행 기록·승인 대기열 양식(11절).
  4. 기록할 데이터 — 에이전트가 내린 모든 결정과 근거·요청한 전이·거절 이유·사람의 승인과 반려, 정책을 바꾼 날(11절).
  5. 사람·규칙·에이전트의 몫 — 승인·반려와 정책 문턱은 사람, 점검·가드·승인 필요 여부는 규칙, 도구 부르기·결정 초안·요청·보고는 에이전트(8절).
  6. 성과 환산 — 사람이 매일 함수를 부르고 붙이는 시간과 에이전트 기록만 보는 시간의 차(9절).
[문제] 지금까지 만든 함수(0101~0411)를 매일 아침 사람이 차례로 부르고 있습니다. (1) 이것을 스스로 돌게 하되, 위험한 일은 못 하게 하려면 어떻게 묶어야 합니까. (2) 가상 공장 일에 돌려 보고, 에이전트가 무엇을 보았고 무엇을 요청했고 무엇이 거절·보류됐는지 설명하십시오.

2~7절에서 묶는 법과 정책을 만져 보고, 8절에서 이 두 물음으로 돌아옵니다. 사람이 함수를 부르는 데 드는 시간은 현장 값으로 바꿔야 할 가정입니다(9절).

여기서부터 14일 가상 운전을 이용한 풀이입니다

1첫 시도 — 함수 목록을 주고 알아서 하라고 하면

  • 에이전트 (agent) — 정해진 목표를 위해 관찰·판단·행동을 스스로 되풀이하는 프로그램입니다. 이 실험실에서는 하루에 한 번 도는 정해진 순서의 묶음을 가리킵니다.

가장 쉬운 첫 시도는 LLM 에게 함수 목록을 주고 “알아서 하라”고 하는 것입니다(여기서 실행하지는 않습니다). 0410·0411 에서 받아 본 실제 답이 이 방식의 근거입니다. 같은 질문에도 문장의 틀이 달라졌고, 숫자는 맞아도 ‘어느 날에 일어났나’ 같은 관계 문장이 틀렸습니다. 사람이 붙인 틀림 표지는 0411 기록의 답 6개 가운데 곳이었습니다.

정해져 있지 않은 것그래서 생기는 일
누가 무엇을 언제 부르는가같은 자료에서도 부르는 함수와 순서가 매번 달라져, 어제와 오늘의 결과를 견줄 수 없습니다.
상태를 바꾸는 일을 막는 장치마스크 제외 같은 되돌릴 수 없는 일이 ‘그럴듯한 다음 낱말’로 일어날 수 있습니다. 표에서 사람 승인이 필요한 마스크 전이는 개()입니다.
틀렸을 때 어느 단계인지 찾는 길부른 함수·입력·받은 값이 남지 않으면 틀린 곳을 찾을 수 없습니다.

막힘: 누가 무엇을 언제 할 수 있는지가 정해져 있지 않습니다. 능력(함수)은 이미 있으므로, 필요한 것은 더 똑똑한 모델이 아니라 순서와 허가의 규칙입니다.

고르는 이유가 기록되지 않고 다시 재현되지 않으면, 그 똑똑함은 틀렸을 때 고칠 수 없습니다. 같은 자료에서 어제는 A 함수를, 오늘은 B 함수를 불렀다면 두 날의 결과를 견줄 수 없고, 어느 쪽이 맞는지도 가릴 수 없습니다.

위험한 전이(마스크 제외·spec 변경)는 더 그렇습니다. 그런 일은 모델의 판단에 맡기지 않고 표(허용된 전이)와 가드와 사람 승인이 막아야 합니다. 이 실험실은 고르는 일 자체를 규칙으로 만들어, 어떤 선택이 왜 일어났는지를 단계마다 남깁니다. 모델은 정해진 자리(보고 문장 초안)에만 쓰고, 그 문장도 0411 의 검사를 통과해야 합니다.

2이름 — 도구와 하루 한 바퀴

  • 도구 (tool) — 에이전트가 부를 수 있는 검증된 함수 하나입니다(예: run_checks, analyze, request). 도구 목록 밖의 일은 하지 못합니다.
  • 실행 단계 (step) — 하루 한 번의 ‘관찰 → 점검 → 분석 → 결정 → 요청 → 보고’ 한 바퀴입니다.

한 바퀴의 칸마다 이미 만든 실험실의 함수가 들어갑니다. 아래 그림은 하루를 골라 그날 각 칸이 무엇을 했는지 보여 줍니다. 어두운 칸은 그날 건너뛴 단계입니다.

하루 한 바퀴 — 도구와 그날 한 일
무엇을 볼지 먼저. 1일부터 ‘다음 날’을 눌러 8일까지 가 보십시오. 대부분의 날은 ‘점검’ 칸에서 멈추고, 8일에는 ‘분석’부터 ‘보고’까지 모두 돕니다.

‘요청’은 에이전트가 설비 상태를 바꾸자고 내놓는 한 건이고, ‘판정’은 그 요청이 허용·거절·승인 대기 가운데 어디로 가는지입니다. 5절에서 규칙을 풉니다.

3점검이 먼저

0400 의 점검 일곱 규칙이 실패하면 그날은 분석하지 않고 알림만 냅니다. 14일 달력에 그날 점검 결과와 주입된 고장(가상이라 정답이 있습니다)을 함께 놓았습니다. 칸을 누르면 그날 규칙별 값이 아래 표에 나옵니다. 마스크 이력 표에는 점검 규칙이 없으므로, 점검이 실패한 날에는 그 표도 읽지 않고 다음 통과한 날에 한꺼번에 읽는다고 정했습니다.

14일 달력 — 분석한 날과 멈춘 날
무엇을 볼지 먼저. 아래 슬라이더로 ‘허용하는 점검 실패 수’를 0 에서 끝까지 올려 보십시오. 분석하는 날이 늘어나는 만큼, 고장이 든 채로 분석한 날과 정답과 달라진 날도 함께 늘어납니다.
분석함멈춤(알림만)주입된 고장(정답)

짚어 둘 것이 있습니다. 점검이 엄격하면 분석할 날이 모자라 변경점 판정이 비교할 날을 찾지 못합니다. 점검을 풀면 분석하는 날이 늘지만 고장이 든 표로 결정을 내리게 됩니다. 어느 쪽이 나은지는 점검 문턱을 정하는 사람의 몫이고(0400·0202 의 맞바꿈), 자료를 빨리 고치는 파이프라인이 이 문제의 근본 해결입니다.

알림은 냅니다. 멈추는 것은 분석과 결정입니다. 실패한 날의 보고는 ‘점검에서 실패한 규칙 이름과 입력 지문’까지만 말합니다(7절에서 그날 보고를 열어 볼 수 있습니다).

이렇게 하는 이유는, 고장 난 표로 낸 결과는 값이 그럴듯해서 사람이 틀린 줄 모르기 때문입니다. 알림을 받은 사람이 실행 기록의 입력 지문과 행 수부터 보고 자료를 고친 뒤 같은 날을 다시 돌립니다(0400).

4정책과 결정

  • 정책 (policy) — 어떤 관찰에서 어떤 결정·요청을 내는지 정한 규칙 표(문턱 포함)입니다. 정책이 바뀌면 같은 자료에서도 행동이 바뀝니다.

분석은 0104 의 판정 흐름을 따릅니다. 챔버마다 ‘최근 k일’과 ‘그 전 m일’(분석한 날만)의 보정 후 Mx 를 비교하되, 같은 날 다른 챔버들의 중앙값을 빼서(대조 챔버 이중차분) 모두가 같이 움직이는 몫을 걷어 내고, 이웃 유리가 닮은 정도(자기상관)를 실효 표본 수로 반영한 Welch 검정을 쓰고, 챔버 여덟 개를 한꺼번에 보므로 0202 의 본페로니 보정(유의수준 0.05 를 챔버 수로 나눔)을 겁니다. 변경점은 ‘효과가 문턱 이상이고 p 가 보정한 수준 이하’일 때입니다. 변경점이 잡히면 시각 근처의 사건을 원인 후보로 붙이고(마스크 교체·이벤트), 없으면 원인 미확인으로 둡니다.

정책 표 — 만져 보면 아래 결정·요청이 함께 바뀝니다
무엇을 볼지 먼저. 3절의 ‘실패 2개까지 허용’ 단추를 누른 뒤 k·m·문턱을 바꿔 보십시오. 엄격한 기본 상태에서는 분석한 날이 몇 안 되어 k·m·문턱을 바꿔도 결정이 달라지지 않습니다. 분석할 날을 정하는 것이 점검 허용 수이기 때문입니다. 이어서 문턱을 낮춰 보고, 아래 비교표에서 점검을 끈 줄에 B03-CH2 말고 다른 챔버의 변경점이 생기는지 확인하십시오.

리페어 후보 규칙에 대해. 이 14일 기록만으로는 0304 의 ‘보정만으로 spec 안에 드는가’를 가릴 수 없어, 아래 슬라이더의 리페어 후보는 지표 초과 건수만 세는 규칙으로 정합니다. 0304 에서 보았듯 지표만으로 리페어하면 쓸데없는 리페어가 생기므로, 현장에서는 77점 격자로 보정한 뒤의 판정(0304 의 3단 규칙)으로 바꿔 씁니다.

변경점 판정 — 보는 날을 골라 챔버별로

정책 세 가지를 나란히

위의 k·m·문턱과 승인 정책은 그대로 두고 점검 허용 수만 0 · 2 · 끝 값으로 바꿔 세 번 돌린 결과입니다.

날마다 낸 결정

한계 둘을 적어 둡니다. 1) 이 가상 공장 표에는 PPA 77점 격자가 없어 0304 의 ‘보정만으로 spec 안에 드는가’ 판단을 근사하지 못합니다. 그래서 조치 판정은 ‘측정 지표 초과 건수’만으로 리페어·제외 후보를 고르는 단순 규칙이며, 0304 의 3단 규칙을 대신하지 못합니다. 2) 대조 챔버와 같이 움직이는 변화(모든 마스크의 노후 같은 것)는 이중차분이 걷어 내므로 변경점으로 잡히지 않습니다. 그런 변화는 spec 초과 비율로 따로 봅니다(5절의 spec 변경 요청).

5전이 요청과 가드

결정이 서면 에이전트는 ‘요청’을 냅니다. 요청 한 건의 판정은 순서대로 세 가지를 봅니다. 1) 0206 의 전이 표에 그 전이가 있는가(없으면 거절). 2) 표에 있어도 사람 승인이 필요한 전이인가(마스크 제외가 그렇습니다 — 되돌릴 수 없으므로 바꿀 수 없는 규칙입니다). 3) 가드를 통과하는가 — 리페어는 ‘동시에 리페어 중인 마스크 수가 한도 미만’이어야 합니다(한도는 가정값). 기준 측정 요청·보정값 입력은 설비 상태를 바꾸지 않고 기록만 남기므로 바로 허용되고, spec 변경은 전이 표 밖의 일이지만 되돌릴 수 없으므로 사람 승인으로 둡니다.

요청과 판정 — 가드와 승인 정책
무엇을 볼지 먼저. 가드를 보려면 아래 ‘가드 시험 정책’을 누르십시오. 점검 허용 수와 문턱이 옮겨져 리페어 요청이 여러 건 생깁니다. 이어서 리페어 동시 한도를 1 로 내리면 거절이 늘고, ‘리페어도 사람 승인’을 켜면 허용이 승인 대기로 옮겨 갑니다.

마스크 제외는 되돌릴 수 없는 전이라 자동으로 허용하는 선택지를 두지 않았습니다. 사람 승인이 필요한 전이는 전이 표의 표시(needs_human)가 정하고, 정책은 그 표시를 끌 수 없습니다.

안 됩니다. 에이전트는 요청과 기록까지만 하고, 설비를 움직이는 쓰기 권한은 따로 두지 않습니다. 이 실험실의 ‘실행’도 상태 표에 기록을 바꾸는 것이고 설비 제어 시스템을 부르지 않습니다.

현장 제어 시스템에 연결하려면 회사의 정보보안·설비 담당 승인과 별도 안전 절차가 먼저입니다. 연결하더라도 가드를 통과한 가역 전이부터, 사람의 확인을 거치는 방식으로 시작합니다.

  • 승인 대기열 (approval queue) — 사람 승인이 필요한 요청(되돌릴 수 없는 전이·spec 변경)을 쌓아 두는 곳입니다. 사람이 승인·반려하기 전에는 실행되지 않습니다.

def mean(a):
    return sum(a) / len(a)


def sd(a):
    m = mean(a)
    return math.sqrt(sum((x - m) * (x - m) for x in a) / (len(a) - 1))


def median(a):

def quantile(x, p):
    b = sorted(x)
    pos = (len(b) - 1) * p
    lo = math.floor(pos)
    f = pos - lo
    return b[lo] + (b[lo + 1] - b[lo]) * f if lo + 1 < len(b) else b[lo]


def lag1(x):
    m = mean(x)
    num = den = 0.0
    for i, v in enumerate(x):
        den += (v - m) * (v - m)
        if i:
            num += (v - m) * (x[i - 1] - m)
    return 0.0 if den == 0 else num / den


def _gammln(x):
    c = [76.18009172947146, -86.50532032941677, 24.01409824083091, -1.231739572450155, 0.1208650973866179e-2, -0.5395239384953e-5]
    y, t = x, x + 5.5
    t -= (x + 0.5) * math.log(t)
    s = 1.000000000190015
    for cj in c:
        y += 1
        s += cj / y
    return -t + math.log(2.5066282746310005 * s / x)


def _betacf(a, b, x):
    qab, qap, qam = a + b, a + 1, a - 1
    c, d = 1.0, 1 - qab * x / qap
    d = 1e-30 if abs(d) < 1e-30 else d
    d = 1 / d
    h = d
    for m in range(1, 301):
        m2 = 2 * m
        aa = m * (b - m) * x / ((qam + m2) * (a + m2))
        d = 1 + aa * d
        d = 1e-30 if abs(d) < 1e-30 else d
        c = 1 + aa / c
        c = 1e-30 if abs(c) < 1e-30 else c
        d = 1 / d
        h *= d * c
        aa = -(a + m) * (qab + m) * x / ((a + m2) * (qap + m2))
        d = 1 + aa * d
        d = 1e-30 if abs(d) < 1e-30 else d
        c = 1 + aa / c
        c = 1e-30 if abs(c) < 1e-30 else c
        d = 1 / d
        de = d * c
        h *= de
        if abs(de - 1) < 3e-14:
            break
    return h


def _betai(a, b, x):
    if x <= 0:
        return 0.0
    if x >= 1:
        return 1.0
    bt = math.exp(_gammln(a + b) - _gammln(a) - _gammln(b) + a * math.log(x) + b * math.log(1 - x))
    return bt * _betacf(a, b, x) / a if x < (a + 1) / (a + b + 2) else 1 - bt * _betacf(b, a, 1 - x) / b

def run_checks(f, p, joined, hist):
    """0400 의 점검 일곱 규칙: 규칙마다 (이름, 값, 통과 여부)."""
    nf, npp = len(f), len(p)
    out = []
    if hist:
        ratio = min(nf / median([h[0] for h in hist]), npp / median([h[1] for h in hist]))
        out.append(("rows", ratio, ratio >= RULES["rows_min"]))
    else:
        out.append(("rows", None, True))
    dup = (nf - f.glass_id.nunique()) + (npp - p.glass_id.nunique())
    out.append(("dup", dup, dup == 0))
    empty = sum(f[c].notna().sum() == 0 for c in ("glass_id", "ts", "chamber", "mask_id", "chamber_temp"))
    out.append(("cols", int(empty), empty == 0))
    blank = 1.0 if nf == 0 else float(f.chamber_temp.isna().sum()) / nf
    out.append(("blank", blank, blank <= RULES["blank_max"]))
    ids = set(f.glass_id)
    jr = 0.0 if npp == 0 else sum(g in ids for g in p.glass_id) / npp
    out.append(("join", jr, jr >= RULES["join_min"]))
    bad = int((joined.ts_m_x > joined.meas_m).sum()) if len(joined) else 0
    out.append(("ts", bad, bad == 0))
    nv = p.model_ver.nunique()
    out.append(("model", int(nv), nv <= 1))
    return out

        j = joined[(joined.block + "-" + joined.chamber) == c].sort_values("glass_id", kind="stable")
        temp = j[j.chamber_temp.notna()]
        ch[c] = {"vals": [float(m - SLOPE * (t - T_REF)) for m, t in zip(temp.Mx, temp.chamber_temp)], "mets": [float(x) for x in j.ppa_metric]}
    return {"day": day, "t": e, "fails": [c[0] for c in checks if not c[2]], "n_fdc": len(f), "n_ppa": len(p), "fp": fingerprint(f, p), "ch": ch,
            "mask": {c: mask_at(tables, c, e) for c in CHAMBERS}}


# ---- 2. 분석: 변경점 판정 (0104 흐름 + 0202 다중 비교) ----------------------------------
def day_mean(o):
    return mean(o["vals"]) if o and o["vals"] else None


def analyze(state, day, pol):
    """최근 k일 vs 그 전 m일(분석한 날만), 대조 = 다른 챔버의 하루 중앙값, 이웃 닮음(자기상관)을 감안한 Welch, 다중 비교."""
    an = state["an"]
    rec = [x for x in an if day - pol["k"] < x <= day]
    bef = [x for x in an if day - pol["k"] - pol["m"] < x <= day - pol["k"]]
    out = {"enough": bool(rec and bef), "rows": [], "alpha": ALPHA / len(CHAMBERS) if pol["bonf"] else ALPHA, "flagged": [], "rec": rec, "bef": bef}
    if not out["enough"]:
        return out

    def ctrl(c, j):
        ms = [m for c2 in CHAMBERS if c2 != c for m in [day_mean(state["data"][j][c2])] if m is not None]
        return median(ms) if ms else None

    for c in CHAMBERS:
        rR, rB, row = [], [], {"key": c}
        for j in rec:
            cc = ctrl(c, j)
            rR += [v - cc for v in state["data"][j][c]["vals"] if cc is not None]
        for j in bef:
            cc = ctrl(c, j)
            rB += [v - cc for v in state["data"][j][c]["vals"] if cc is not None]
        if len(rR) < MIN_N or len(rB) < MIN_N:
            row["skip"] = True
            out["rows"].append(row)
            continue
        phi = max(0.0, (lag1(rR) + lag1(rB)) / 2)
        neR, neB = max(len(rR) * (1 - phi) / (1 + phi), 2), max(len(rB) * (1 - phi) / (1 + phi), 2)
        vR, vB = sd(rR) * sd(rR) / neR, sd(rB) * sd(rB) / neB
        se = math.sqrt(vR + vB)
        eff = mean(rR) - mean(rB)
        t = eff / se
        df = (vR + vB) * (vR + vB) / (vR * vR / (neR - 1) + vB * vB / (neB - 1))
        p = t_p2(t, df)
        row.update(phi=phi, eff=eff, se=se, t=t, df=df, p=p, flag=abs(eff) >= pol["delta"] and p <= out["alpha"])
        out["rows"].append(row)
        if row["flag"]:
            out["flagged"].append(c)
    return out


def find_causes(tables, state, c, day, pol):
    """원인 후보: 마스크 교체(이력 표, 비교한 구간 전체) · 이벤트(이벤트 표, 최근 구간과 그 하루 전). 후보일 뿐 확정이 아닙니다."""
    wm, we, w1 = (day - pol["k"] - pol["m"]) * DAY, (day - pol["k"]) * DAY - DAY, day * DAY
    out = [{"kind": "마스크 교체", "ts": r["ts"], "rank": 0} for r in state["reps"] if r["ch"] == c and wm <= r["ts"] <= w1]
    rk = {"센서 교정": 1, "PM": 2, "세정": 3, "인터락": 4}
    ev = tables["events"]
    for r in ev[(ev.key == c) & (ev.start_m >= we) & (ev.start_m <= w1)].itertuples():
        out.append({"kind": r.kind, "ts": int(r.start_m), "rank": rk[r.kind]})
    return sorted(out, key=lambda x: (x["rank"], x["ts"]))


# ---- 3. 요청: 표 → 사람 승인 → 가드(리페어 동시 한도) → 정책 ----------------------------
def base_state(tables, mid, t):
    s = "stock"
    for r in tables["mask_hist"][tables["mask_hist"].mask_id == mid].itertuples():
        if r.from_m <= t - 1 < r.to_m:
            s = "in_use" if r.state == "IN_USE" else "cleaning" if r.state == "WASH" else "stock"
    return s


def request_transition(cur, to):
    """0206 requestTransition 의 판정: 표에 있는가 → 사람 승인이 필요한가."""
    if (cur, to) not in MASK_TRANS:
        return "not_in_table"
    return "needs_human" if MASK_TRANS[(cur, to)] else "ok"


def n_repair(state):
    return sum(1 for s in state["mstate"].values() if s == "repair")


def new_req(state, day, kind, ch, mask, text, rev, extra=None):
    state["req_n"] += 1
    r = {"id": "R-" + ("0" if state["req_n"] < 10 else "") + str(state["req_n"]), "day": day, "kind": kind, "ch": ch, "mask": mask, "text": text,
         "reversible": rev, "human": False, "verdict": None, "reason": "", "status": None}
    r.update(extra or {})
    return r


def request(tables, state, req, pol, day):
    """요청 한 건을 판정합니다. 기록만 하는 요청은 허용, 표에 없으면 거절, 사람 승인이 필요하면 대기열, 리페어는 동시 한도 가드."""
    if req["kind"] in ("baseline", "correct"):
        req.update(verdict="ok", status="done", reason="기록만 남기는 요청이라 설비 상태를 바꾸지 않습니다")
        return req
    if req["kind"] == "spec":
        req["human"] = True
        if pol["spec_reject"]:
            req.update(verdict="auto", status="rejected", reason="정책: spec 변경은 자동 반려")
        else:
            req.update(verdict="queue", status="pending", reason="ESTC 표 밖의 일이며 spec 은 사람이 정합니다")
        return req
    cur = state["mstate"].get(req["mask"]) or base_state(tables, req["mask"], day * DAY)
    rt = request_transition(cur, "repair" if req["kind"] == "repair" else "scrapped")
    if rt == "not_in_table":
        req.update(verdict="table", status="rejected", reason=f"표에 {cur} → 이 전이가 없습니다")
    elif rt == "needs_human":
        req.update(human=True, verdict="queue", status="pending", reason="되돌릴 수 없는 전이라 사람의 승인이 있어야 합니다")
    elif n_repair(state) >= pol["repair_cap"]:
        req.update(verdict="guard", status="rejected", reason=f"리페어 동시 한도 {n_repair(state)}/{pol['repair_cap']} 가 찼습니다")
    elif pol["repair_human"]:
        req.update(human=True, verdict="queue", status="pending", reason="정책: 리페어도 사람 승인")
    else:
        state["mstate"][req["mask"]] = "repair"
        state["repair_until"][req["mask"]] = day + REPAIR_DAYS
        req.update(verdict="ok", status="done", reason="표에 있고 가드를 통과했습니다")
    return req


def apply_decisions(state, day, pol, decisions):
    """어제 올린 요청에 대한 사람의 결정을 오늘 아침에 반영합니다."""
    done = []
    for r in state["queue"]:
        if r["status"] != "pending" or r["day"] != day - 1 or r["id"] not in (decisions or {}):
            continue
        r["decided_day"], r["decision"] = day, decisions[r["id"]]
        if r["decision"] == "reject":
            r.update(status="rejected", verdict="rejected", reason="학습자가 반려했습니다")
        elif r["kind"] == "repair" and n_repair(state) >= pol["repair_cap"]:
            r.update(status="rejected", verdict="guardlate", reason="리페어 동시 한도가 차서 실행하지 못했습니다")
        else:
            if r["kind"] == "repair":
                state["mstate"][r["mask"]] = "repair"
                state["repair_until"][r["mask"]] = day + REPAIR_DAYS
            elif r["kind"] == "scrap":
                state["mstate"][r["mask"]] = "scrapped"
            elif r["kind"] == "spec":
                state["spec"] = r["proposed"]
            r.update(status="done", verdict="applied", reason=f"학습자가 승인해 {day}일 아침에 실행했습니다")
        done.append(r)
    return done

def decide(tables, state, day, finding, pol):
    """결정: 마스크 교체는 기준 측정, 변경점은 원인 후보와 지표 초과 건수로 조치 후보를 고릅니다.
    S15 표에는 77점 격자가 없어 보정 후 지표를 근사하지 못하므로 '측정 지표 초과 건수'만으로 리페어·제외 후보를 고르는 단순 규칙입니다."""
    decs, reqs = [], []
    for r in state["reps"]:
        if r["to"] in state["base_req"]:
            continue
        state["base_req"][r["to"]] = 1
        state["mstate"].setdefault(r["to"], "in_use")
        q = new_req(state, day, "baseline", r["ch"], r["to"], f"{r['ch']} 의 새 마스크 {r['to']} 기준 측정을 요청", True)
        reqs.append(request(tables, state, q, pol, day))
        decs.append({"ch": r["ch"], "text": f"마스크 교체({r['from']} → {r['to']})를 이력 표에서 확인 → 기준이 없는 마스크로 수명을 내지 않고 기준 측정을 요청"})
    causes = {}
    flagged_new = []
    for c in CHAMBERS:
        if c not in finding["flagged"]:
            state["open"].pop(c, None)
            continue
        if c in state["open"]:
            continue
        state["open"][c] = day
        flagged_new.append(c)
        cs = find_causes(tables, state, c, day, pol)
        causes[c] = cs
        row = [x for x in finding["rows"] if x["key"] == c][0]
        mask = state["known"][c]
        E = N = 0
        for j in finding["rec"]:
            mets = state["data"][j][c]["mets"]
            N += len(mets)
            E += sum(1 for m in mets if m > state["spec"])
        if cs and cs[0]["kind"] == "마스크 교체":
            decs.append({"ch": c, "text": f"{c} 변경점의 원인 후보 = 마스크 교체 → 리페어가 아니라 기준 측정(위 요청)으로"})
            continue
        share = E / N if N else 0
        if E >= pol["ex_n"] and share >= pol["scrap_ratio"]:
            decs.append({"ch": c, "text": f"{c} 지표 초과 {E}/{N}장({round_half(share * 100)}%) — 되돌릴 수 없는 마스크 제외 후보"})
            reqs.append(request(tables, state, new_req(state, day, "scrap", c, mask, f"{c} 마스크 {mask} 제외를 요청", False), pol, day))
        elif E >= pol["ex_n"]:
            decs.append({"ch": c, "text": f"{c} 지표 초과 {E}/{N}장 → 리페어 후보"})
            reqs.append(request(tables, state, new_req(state, day, "repair", c, mask, f"{c} 마스크 {mask} 리페어를 요청", True), pol, day))
        else:
            decs.append({"ch": c, "text": f"{c} 지표 초과 {E}/{N}장 — 리페어까지는 아님 → 보정값 입력 후보"})
            sign = "−" if row["eff"] >= 0 else "+"
            reqs.append(request(tables, state, new_req(state, day, "correct", c, mask, f"{c} 보정값 {sign}{abs(row['eff']):.3f} ppm 입력을 요청", True, {"corr": -row["eff"]}), pol, day))
    # spec 변경 제안
    rcs = [x for x in state["an"] if day - pol["k"] < x <= day]
    all_m = [m for j in rcs for c in CHAMBERS for m in state["data"][j][c]["mets"]]
    ex2 = sum(1 for m in all_m if m > state["spec"])
    share_all = ex2 / len(all_m) if all_m else 0
    pend = any(q["kind"] == "spec" and q["status"] == "pending" for q in state["queue"])
    if share_all >= pol["spec_share"] and not pend and state["last_spec"] + SPEC_GAP <= day:
        prop = r3(quantile(all_m, SPEC_Q))
        state["last_spec"] = day
        top, top_e = None, -1
        for c in CHAMBERS:
            e3 = sum(1 for j in rcs for m in state["data"][j][c]["mets"] if m > state["spec"])
            if e3 > top_e:
                top, top_e = c, e3
        if prop > state["spec"]:
            q = new_req(state, day, "spec", None, None, f"spec 을 {state['spec']:.3f} → {prop:.3f} µm 으로 올리자고 요청", False,
                        {"proposed": prop, "spec0": state["spec"]})
            decs.append({"ch": None, "text": f"최근 {len(rcs)}일 전체 유리의 {round_half(share_all * 100)}%가 spec 을 넘음(그 가운데 {round_half(100 * top_e / ex2)}%가 {top}) → spec 변경 요청(되돌릴 수 없음)"})
            reqs.append(request(tables, state, q, pol, day))
    return decs, reqs, causes, flagged_new


def round_half(x):
    return math.floor(x + 0.5)

def fmt_val(f, plain=False):
    if isinstance(f["value"], str):
        return f["value"]
    s = f"{f['value']:.{f['dec']}f}"

def minute_text(m):
    return (pd.Timestamp(T0) + pd.Timedelta(minutes=int(m))).strftime("%Y-%m-%d %H:%M")


def validate(raw, facts):
    """0411 의 검사 V1~V6. 반환 = {규칙: 실패한 문장 번호 목록}."""
    fb = {x["id"]: x for x in facts}
    res = {k: [] for k in ("V1", "V2", "V3", "V4", "V5", "V6")}
    try:
        obj = json.loads(raw)
        ss = obj["sentences"]
        assert ss and all(isinstance(x["text"], str) and isinstance(x["cites"], list) and x["type"] in TYPES for x in ss)
    except Exception:
        res["V1"].append(None)
        return res
    for i, x in enumerate(ss):
        used = set()
        for m in SLOT.finditer(x["text"]):
            c = m.group(1).strip()
            if re.fullmatch(r"f\d+", c) and c in fb:
                used.add(c)
            else:
                res["V3"].append(i)
        rest = SLOT.sub(" ", x["text"])
        rest = NAME_RE.sub(lambda m: " " * len(m.group(0)), rest)
        rest = re.sub(r"\d+일(?:간)?", lambda m: " " * len(m.group(0)), rest)
        if re.search(r"\d+(?:[.,]\d+)*", rest):
            res["V2"].append(i)
        if any(u not in x["cites"] for u in used) or any(c not in fb for c in x["cites"]) or (x["type"] == "원인" and not x["cites"]):
            res["V4"].append(i)
        has_ev = any(c in fb and fb[c]["kind"] == "event" for c in x["cites"])
        has_rel = any(c in fb and fb[c]["kind"] == "relation" for c in x["cites"])
        if x["type"] == "원인" and not has_ev:
            res["V5"].append(i)
        if has_ev and not has_rel and any(w in x["text"] for w in REL_WORDS):
            res["V6"].append(i)
    return res


def has_batchim(s):
    c = s[-1]
    if "가" <= c <= "힣":
        return (ord(c) - 0xAC00) % 28 != 0
    if c.isdigit():
        return c in "013678"
    return c in "lmnLMN"


def render(raw, facts):
    """자리 {{fN}} 를 값으로 바꿉니다(조사 이·가·은·는·을·를 는 받침에 맞춰 고침)."""
    fb = {x["id"]: x for x in facts}
    out = []
    for x in json.loads(raw)["sentences"]:
        text, res, pos = x["text"], "", 0
        for m in SLOT.finditer(text):
            res += text[pos:m.start()]
            pos = m.end()
            fct = fb[m.group(1).strip()]
            rest = text[m.end():]
            plain = (not fct["unit"]) or rest.lstrip().startswith(fct["unit"])
            piece = fmt_val(fct, plain)
            if not plain and len(fct["unit"]) == 1 and fct["unit"] in "건장일":
                piece = fmt_val(fct, True) + fct["unit"]
            j = re.match(r"([이가은는을를])(?=$|[\s.,;)])", rest)
            if j:
                pair = {"이": "이가", "가": "이가", "은": "은는", "는": "은는", "을": "을를", "를": "을를"}[j.group(1)]
                piece += pair[0] if has_batchim(piece) else pair[1]
                pos = m.end() + 1
            res += piece
        out.append(res + text[pos:])
    return out

def agent_step(tables, state, day, pol, decisions, hist):
    """하루 한 바퀴: 관찰 → 점검 → 분석 → 결정 → 요청 → 보고. 점검이 허용 수를 넘게 실패하면 분석하지 않고 알림만 냅니다."""
    for mid in [m for m, d in state["repair_until"].items() if d == day and state["mstate"].get(m) == "repair"]:
        del state["mstate"][mid]
        del state["repair_until"][mid]
    decided = apply_decisions(state, day, pol, decisions)
    obs = observe(tables, day, hist)
    hist.append((obs["n_fdc"], obs["n_ppa"]))
    analyzed = len(obs["fails"]) <= pol["tol"]
    finding, decs, reqs, causes, flagged_new = {"enough": False, "flagged": []}, [], [], {}, []
    if analyzed:
        state["data"][day] = obs["ch"]
        state["an"].append(day)
        for c in CHAMBERS:
            cur = obs["mask"][c]
            if cur and cur[0] != state["known"][c]:
                state["reps"].append({"ch": c, "from": state["known"][c], "to": cur[0], "ts": cur[1], "seen": day})
                state["known"][c] = cur[0]
        finding = analyze(state, day, pol)
        decs, reqs, causes, flagged_new = decide(tables, state, day, finding, pol)
        state["queue"].extend(reqs)
    facts, raw = build_report(state, day, obs, analyzed, finding, flagged_new, causes, reqs, decided)
    v = validate(raw, facts)
    return {"day": day, "fails": obs["fails"], "analyzed": analyzed, "flagged": flagged_new, "decisions": decs, "requests": reqs, "decided": decided,
            "fp": obs["fp"], "n_fdc": obs["n_fdc"], "n_ppa": obs["n_ppa"], "spec": state["spec"], "facts": facts, "raw": raw, "valid": all(not x for x in v.values()),
            "render": render(raw, facts), "finding": finding}


def run_agent(tables, policy=None, decisions=None):
    """14일을 하루씩 돌립니다. decisions = {요청 id: 'approve' 또는 'reject'} — 사람의 결정은 요청 다음 날 아침에 반영됩니다."""
    pol = dict(POLICY, **(policy or {}))
    first = {c: mask_at(tables, c, 1)[0] for c in CHAMBERS}
    state = {"spec": SPEC, "data": {}, "mstate": {}, "repair_until": {}, "known": dict(first), "reps": [], "open": {}, "base_req": {}, "queue": [], "req_n": 0, "last_spec": -99, "an": []}
    hist, recs = [], []
    for day in range(1, 15):
        recs.append(agent_step(tables, state, day, pol, decisions, hist))
    return recs, state["queue"], pol

def summarize(recs, queue):
    reqs = [q for r in recs for q in r["requests"]]
    cause_n = sum(1 for r in recs for s in json.loads(r["raw"])["sentences"] if s["type"] in ("원인", "원인 미확인"))
    an = sum(r["analyzed"] for r in recs)
    hum = sum(1 for q in reqs if q["human"])
    return {"analyzed": an, "stopped": len(recs) - an, "decisions": sum(len(r["decisions"]) for r in recs), "requests": len(reqs), "ok": sum(q["verdict"] == "ok" for q in reqs),
            "refused": sum(q["verdict"] in ("guard", "table", "auto") for q in reqs), "queued": sum(q["verdict"] == "queue" for q in reqs), "pending_end": sum(q["status"] == "pending" for q in queue),
            "report_pass": sum(r["valid"] for r in recs), "alerts": len(recs) - an, "approvals": hum, "cause_sentences": cause_n, "human_items": len(recs) - an + hum + cause_n}
