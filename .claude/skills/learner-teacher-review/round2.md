# 2라운드 브리프

## 학습자 (같은 학습자에게 SendMessage 로 이어서 — 맥락 유지)
교사 답(토론 파일의 T1)과 `git diff <대상 파일>` 로 고친 곳을 다시 읽고, 질문마다 아래 줄을 덧붙이세요.
`R1 납득` 또는 `R1 재질문: 이유(무엇이 아직 막히는가)`.
고친 곳을 읽다 새로 막힌 데가 생겼으면 편 끝에 `R+1 [유형] §N 「인용」 — 질문` (최대 3개). 숫자는 이번에도 직접 다시 계산해 확인합니다. 파일은 고치지 않습니다.

## 교사 (같은 교사에게 이어서)
재질문과 R+ 만 다시 판정해 `T2 [보강|배치|기각] 답: ... / 고친 곳: ...` 을 덧붙이고 고칩니다. 규칙·검증은 1라운드와 같습니다. 토론은 여기서 끝납니다 — 그래도 풀리지 않으면 "Advisor 판정 요청: 이유"로 남깁니다.
